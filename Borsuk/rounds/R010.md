# R010 — P10: Hadwiger partitions with canonical normals (own analysis, 2026-11-28)

Node: P10. Claim: a Hadwiger-type colouring fails only on "bad" diametral pairs; this gives a necessary condition for counterexamples and the shape of a possible proof. Verdict: framework recorded; no proof yet.

- Finite X ⊂ ℝ⁴, diam 1, diameter graph G. For x let U(x) = {x − y : y ∈ N(x)} ⊂ S³ (unit vectors; angular diameter ≤ 60°, since partners are ≤ 1 apart), ν(x) the centre and θ_x the radius of its smallest enclosing cap (θ_x ≲ 38°). Colour x by the cell of ν(x) in a rotated simplex Voronoi partition of S³ (cells of angular diameter 131.8°). An edge xy is monochromatic only if θ_x + θ_y ≥ 48.2° ("bad edge"), because angle(ν(x), ν(y)) ≥ 180° − θ_x − θ_y.
- Corollary (necessary condition): in a 6-chromatic diameter graph in ℝ⁴, for every rotation some bad edge is monochromatic; in particular the bad edges (both ends with partner spread, θ_x, θ_y ≥ 10.2°) cannot be 5-coloured compatibly with any rotated Voronoi colouring of the good vertices. Use as pruning rule in D10/D11 searches.
- Bodies: the same holds with normal cones N(x) (θ_N ≤ arccos(1/(2R)), R009). Bad pairs are pairs of two singular points (edges, ridges, vertices of Meissner type); their family has dimension ≤ 3 but each bad pair can be monochromatic for a positive-measure set of rotations when θ_x + θ_y is large (two Reuleaux-simplex vertices: 75.6°), so the measure argument of R009 does not extend; finitely many such pairs (Jung corner) are handled by alignment (R004: 0.874).
