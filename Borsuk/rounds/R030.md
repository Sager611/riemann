# R030 — P14: multi-fan certificates (own idea + computation, 2026-11-28)

- Multi-fan lemma (own, elementary). Let Ω be compact and F₁, …, F_m simplex fans (closed cones K_{i,1..5} from an apex). Let Zᵢ = {(x, y) ∈ Ω² : x, y in one cone of Fᵢ, |x − y| ≥ 1}, covered by finitely many region pairs (A, B) ∈ 𝓡ᵢ (Zᵢ ⊂ ⋃ A × B). If no choice (Aᵢ, Bᵢ) ∈ 𝓡ᵢ, i = 1..m, has all cross minimum distances ≤ 1 (mindist(Aᵢ ∪ Bᵢ, A_l ∪ B_l) componentwise), then every compact X ⊂ Ω with diam X = 1 is split by some Fᵢ into 5 parts of diameter < 1. Proof: if Fᵢ fails, some cone holds a pair of X at distance 1, which lies in some Aᵢ × Bᵢ; all points of X are pairwise ≤ 1, so the chosen region pairs would satisfy the CSP. This uses diam X = 1 (the 2-level gain) with a finite certificate.
- Sampled test, extreme type-3 body Ω₃ (ρ = 1/3; Borsuk/code/p14_twofan.py; 4,800 samples): 12 locally optimal fans with max pieces 1.0022–1.0168 and 3–58 sampled critical pairs each; every two fans are jointly blockable, but the joint CSP over all 12 (one critical pair per fan, 21,766 incompatibility clauses) is UNSAT: no sampled diameter-1 set blocks all 12 fans. So 12 fans would split every diameter-1 subset of the hardest type-3 outer body, although no single fan and no single 5-partition of Ω₃ does (β₅(Ω₃) ≥ 0.97).
- Running: fuzz test (critical pairs ≥ 0.995, compatibility ≤ 1.005) on Ω₃ and plain tests on H(0.8,0,0,0), H(1,0,0,0) = u*, H(0.6,1,0,0) with 12–16 fans.
- If the CSP stays UNSAT with fuzz, a rigorous pipeline is feasible: per parameter box Q (Tolmachev's 4-parameter family), (i) optimise ~12–16 fans, (ii) enclose each critical zone by a certified pair branch-and-bound over boxes of the cone pieces (box–box max distance), (iii) solve the CSP on region pairs (box–box min distance) with kissat + DRAT.
