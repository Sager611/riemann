- New unconditional zero-density estimate for ring class L-functions: for a negative discriminant D, Σ over the ring class characters χ of D of N(σ; t) (zeros β+iγ with β ≥ σ, |γ − t| ≤ 1) ≪_ε |D|^{2σ(1−σ)+ε}(|t|+3)^3. Every published density bound for this family is weaker in |D| for each σ in (1/2, 1) (Pascadi–Thorner 2025, Kowalski–Michel 2002). Method classical (Carlson detector + weighted large sieve over primitive ideals); the statement is new. Paper proof, not refereed, not Lean. - Least primes represented by forms, for almost all discriminants (unconditional): for every A > 1 (sharp for D < 0: the principal class has no degree-one prime of norm below |D|/4; GRH gives A = 1 for every D (Sardari 2018); earlier steps here: A > 1.6536, 3/2, (3+√69)/10 ≈ 1.1307, the last also for D > 0 and sectors), all but O(X^{1−c}) non-square discriminants Δ ≡ 0, 1 (mod 4) with |Δ| ≤ X, fundamental or not, negative or positive, have degree-one prime ideals in every (narrow, if Δ > 0) ring class of the order of discriminant Δ in every interval (x, x + x|Δ|^{−κ}] with x ≥ |Δ|^A (for fundamental D < 0 also in prescribed sectors); so every primitive binary quadratic form of discriminant Δ, positive definite or indefinite, represents a prime ≤ 2|Δ|^A, and for almost all n (not only squarefree n) x² + ny² has a prime in every such interval (c, κ > 0 depend on A; intervals of length H ≤ x). Previous: |D|^{20/3+ε} with a density-zero exceptional set, definite forms only (Ditchen 2013); for indefinite forms only a single class was known on average (ny² − x² represents a prime < n for almost all n, via the prime-plus-a-square theorem), not every class. Signs (special case): for A > (23 − 3√5)/8 ≈ 2.0365 (first 3) every class has primes with a_f(p) > 0 and primes with a_f(p) < 0, so every primitive form of discriminant D represents primes p, p′ ≤ 2|D|^A with a_f(p) > 0 > a_f(p′); one-sided a_f(p) > −α p^{(k−1)/2} (α > 0) needs only A > 1 (first 9/4; 1 is the GRH value of the method). - Thin-family large sieve and least primes for CM fields (unconditional): for a fixed totally real field F ≠ Q of degree n and CM extensions K/F, a content-weighted large sieve over the class group characters of K with constant ≈ N + √d_K (via a relative lattice lemma; the regulator factor of F is unnecessary), zero density Σ_χ N(σ; t, χ) ≪ (d_K Tⁿ)^{2(1−σ)/(3−2σ)+ε} per unit window, and: for every A > 1 (sharp: the principal class has no degree-one prime of norm below d_K/(4ⁿd_F²), the key lemma of Miller–Peckner 2012; earlier steps here: 3/2, then (3+√69)/10 ≈ 1.1307 with a family large sieve over pairs (K, χ ∈ Ĉl_K) at family size X^{3/2} [CM2](Riemann/Deep/CM2/NOTE.md), reviewed correct in substance; then every A > 1 by counting the pairs over all elements of each order O_F + 𝔣O_K (a relative Lemma P), which removes the N³/X term and gives Σ_K N_K(σ) ≪ X^{2−σ+ε}, the density hypothesis on average over K [CM3](Riemann/Deep/CM3/NOTE.md), reviewed correct for detector sequences, 5 independent checks OK), almost all CM fields K/F with prime (or rough) relative discriminant have degree-one prime ideals in every ideal class in every interval (x, x + x d_K^{−κ}] with x ≥ d_K^A.
