## 2. Statements
- **P1 (Pavlov's weight is ζ off the line).** For a block B of consecutive zeros, F_B(z) = sin πz ∏_{j∈B}(z − λ_j)/(z − j) (generating function of B completed by ℤ) satisfies log\|F_B(λ(t) + iy)\| = log\|ζ(1/2 + y/L(t) + it)\| + a + bt + r(t), r smooth (zeros outside B, Γ-factor). Proof: Hadamard product and λ(t + iη) = λ(t) + iηL(t) + O(η²/t). So Pavlov's criterion (a separated B is a CIS iff \|F_B(x + iy)\|² ∈ A₂; the A₂ constant and the separation control the Riesz bounds) is a statement about \|ζ\|^{±2} on σ = 1/2 + y/L.
- **P2 (Pavlov–Carlson).** The long-window A₂ constant ⟨w⟩⟨1/w⟩ of w = \|ζ(σ + it)\|² tends to ζ(2σ)²/ζ(4σ) (⟨w⟩ → ζ(2σ), ⟨1/w⟩ → Σμ²(n)n^{−2σ} = ζ(2σ)/ζ(4σ); Carlson): unconditionally for σ > B = 0.87338 (M(x) ≪ x^{B+ε}; standard, not re-proved here), under RH for σ > 1/2; a zero on Re s = σ makes it infinite. In unfolded units the unconditional lines are y > (B − 1/2)L = 0.0594 log(T/2π), receding from the zeros; on bounded lines (what a uniform CIS needs) the constant is a positive times a negative moment at distance y/L (Gonek's regime); Selberg's CLT makes it grow (Carlson's formula continued: 3L²/(2π²y²) for 1 ≪ y ≪ L, heuristic): the zero set is not a uniform Riesz basis at any height. Finite Pavlov constant on every line σ > 1/2 ⟺ RH, trivially: it is the zero-free region.
- **P3 (Avdonin = Turing).** Exact identity (simple zeros): Σ_{n=a}^{b−1} S_n = ∫_{γ_a}^{γ_b} S dλ + (S_b² − S_a²)/2 − (S_b − S_a)/2. So Avdonin's block mean of λ_n − n over N zeros is −(1/N)[∫S dλ + bounded] ≈ −(L/N)ΔS₁: the 1/4-in-the-mean condition holds on N-blocks iff \|ΔS₁\| < N/(4L) − O(1), i.e. any explicit Turing bound \|S₁\| ≤ α log t + β gives it for N ≥ 8L(α log T + β) + O(1). Block sums have sd → √(2 Var S₁)·L, Var S₁ = (1/2π²)Σ_{p,m} 1/(m⁴p^m log²p) = 0.0791.
- **P4 (Kadec stability: an off-line pair is a gap).** Two points: off-line λ ± ib has normalized overlap 2πb/sinh 2πb, on-line λ ± b has sinc 2πb, so λ_min = y²/6 − 7y⁴/360 vs y²/6 − y⁴/120 (y = 2πb), equal up to relative O(b²); b = (β − 1/2)L. Every Riesz/frame/CIS bound is continuous under such moves (Kadec–Pavlov stability), so none separates an off-line pair from an on-line gap 2b.
- **P5 (band-limited Wirtinger, N8 large gaps).** Bui–Milinovich/Hall use the zero set only through Wirtinger, ∫\|f′\|² ≥ (π/κ)²∫\|f\|². With Landau density 1 and the band of f = Z\|M\|² (normalized spectrum in [−(1 + 2ϑ)π, (1 + 2ϑ)π]) the infimum R (Bloch-periodic models) at κ = 3.324 gives R/(π/κ)² = 1.09 for an isolated maximal gap, 1.045 / 1.026 / 1.012 / 1.010 / 1.005 for runs of 2 / 3 / 5 / 8 / 11 (ϑ = 1/4); ϑ = 1/2: 1.063 → 1.003; band [−π, π]: 1.22–1.50 → 1.011. Runs of maximal gaps closed by a cluster (or, unconditionally, by off-line zeros) are extremal and no input excludes them: no record (a run-free hypothesis would give Λ > 3.324·√1.09 ≈ 3.47; float).
