## Independent test (code_audit.py, logs/code_audit.log; 84 s; peak 94 MB by getrusage, top ≤ 78 MB while sampled)
1. **Moment tables:** 36 random entries (6 per kernel: triangle and trapezoid, δ_max = 10^{−9}, 0.025, 0.15) recomputed at 256 bits from the definition p∫_{λ_i}^∞ G(λ)λ^{p−1}dλ, with G written out piece by piece (sinc / s₁ / 1/y and the δ_max term, breakpoints explicit), Arb's rigorous integrator on each analytic piece and the exact C₂/λ² tail; none of cert.py's G code is used. All 36 lie below the stored value; stored/definition = 1.0015–1.0021 (the grid's loss). 36 stored G(λ_i) ≥ the 256-bit G(r^i); all 300 p-grid balls contain j/200.
2. **KLN rows:** cert.py's module re-executed at 256 bits (every constant recomputed); 20 random (row, σ) pairs, both RH heights: the 128-bit affine log A and B overlap the 256-bit values; c₁ > 0 and q₁ ≥ 0 in all 39 rows.
3. **Cells:** 14 cells — 10 random cells of the θ = 0.856 scan (6 in [165, 215), 4 elsewhere), 2 random ones of Ingham3's unchanged pipeline (θ = 0.857), and the worst cell of each — recomputed without tables or moment majorants: x-powers at L_a and the kernel at δ(L_b), as in the certificate; S and F(σ) from their definitions (14 log 14·G(14δ) + ∫G(δt)(1 + log t)dt; N(σ,T₀)G(δT₀) + ∫G(δt)dN(σ,t) with KLN's exact shape), the t-integrals by Arb's integrator with the far tails bounded above in closed form; the σ-integral by 2-point Gauss–Legendre per σ-cell for σ ≥ 0.8 and the midpoint rule below (not rigorous in σ; estimated error ~10^{−4} against a margin of 2%). Every direct value ≤ the certified bound: certified/direct = 1.017–1.037 (worst cells: 0.9509 ≤ 0.9711 for θ = 0.856, 0.9161 ≤ 0.9319 for θ = 0.857).

Fixed in this audit (no result changed): the grid index in both moment lookups was a floor of a float and is now checked exactly (λ_i ≤ λ₀); A_max, B_max and the CS maxima used float keys and are now exact maxima. Both came from Ingham3's code.
