# E1 — simple critical zeros in every window (T, T + T^θ], θ > 1/2
santiaudit, 12 Nov 2026. Builds on Santibáñez-Leal, Zenodo 23134787 v0.03 ("SL"; audited: REPORT.md, FULLPROOF.md). Only SL §3.5 is replaced.

## 1. Statement
Notation as in SL: N(T,H) zeros with T < γ ≤ T+H (multiplicity); S(T,H) simple zeros with β = 1/2; L = log T.
**Theorem E1.** For every fixed θ ∈ (1/2, 1),
  liminf_{T→∞} S(T,T^θ)/N(T,T^θ) ≥ h(θ; κ1) ≥ h(1/2; κ1) = 0.0055353042386405370584… > 0,
h(θ;k) = (3 + k − √((1−k)(9 − k − 8c(θ))))/4, c(θ) = 2 − θ/2 − cot(θ/√2)/√2 (Wang), κ1 = 0.0844779079697484032032447… (§4).
**Theorem E1-M (moment).** SL Thm 1.2 (shifted mollified moment, any fixed real Q, Q(0)=1, R > 0, error O(H/L)) holds for 0 < ν < (3θ − 1)/4 (< 1/2 for θ < 1).
Range used: ν = 3/25 < (3θ − 1)/4 ⟺ θ > 37/75 = 0.4933…, so for every θ > 1/2. With ν = 1249/10000 (θ > 3749/7500): h ≥ 0.0074290981966.
Uniformity: liminf is for fixed θ (constants depend on θ through J, η); the lower bound h(1/2;κ1) is uniform in θ ∈ (1/2,1).

## 2. Proof of the new off-diagonal bound (replaces SL §3.5)
Setting (SL (10)–(14), all exact; (10) checked numerically, FULLPROOF §4). Gaussian moment of width H at T; shifts α, β ≪ 1/L;
z = α − β, d = α + β; mollifier h = gq, k = gp, (p,q) = 1, gp, gq ≤ y = T^ν, coefficients |b| ≤ max_{[0,1]}|P| ≪ 1.
Profile (SL l.386): A(ξ) = χ(ξ/T)·A_{−1,j}(ξ), A_{−1,j}(ξ) = ξ^{−β}(−2πiξ)^j Φ_j((T − 2πξ)/H), j < J, χ ∈ C_c^∞ a fixed central cutoff,
  Φ_j(w) = (j!√π)^{−1}∫ e^{−y²+(1−2β)y/H} e^{2iwy}(e^{2y/H} − 1 − 2y/H)^j dy.
Oscillatory dual term (SL (14)), for each n ≥ 1:
  D(g,p,q,n) = b_{gq}b_{gp}·(4π/(gpq))·(q/p)^{−z/2}n^{−z/2}σ_{−α,β}(n)e(∓p̄n/q)·𝒯(n),
  𝒯(n) = (2πi)^{−1}∫_{(σ)} Γ(u−d/2)Γ(u+d/2)cos(πu)(pq/(4π²n))^u Ã(1−u−z/2) du.
**Step 1 (x-space form).** 𝒯(n) = −π∫_0^∞ A(ξ)ξ^{−z/2} B(X(ξ)) dξ, X(ξ) = 4π√(nξ/(pq)), B = sin(πd/2)J_d + cos(πd/2)Y_d.
 Proof. Mellin transforms (DLMF 10.22.43–44): ∫_0^∞ J_d(x)x^{s−1}dx = (2^{s−1}/π)Γ((s+d)/2)Γ((s−d)/2)sin(π(s−d)/2),
 ∫_0^∞ Y_d(x)x^{s−1}dx = −(2^{s−1}/π)Γ((s+d)/2)Γ((s−d)/2)cos(π(s−d)/2); so B̃(s) = −(2^{s−1}/π)Γ((s+d)/2)Γ((s−d)/2)cos(πs/2),
 absolutely convergent for |Re d| < Re s < 1/2 (B ≪ x^{−|Re d|}(1 + |log x|) at 0, ≪ x^{−1/2} at ∞). With s = 2u:
 𝒢(Y) := (2πi)^{−1}∫_{(σ)}ΓΓcos(πu)Y^{−u}du = −πB(2√Y) for σ ∈ (|Re d|/2, 1/4).
 Move the u-line of (14) from Re u > 1 (absolute convergence of the dual series) to such σ: Γ(u ± d/2) has poles only at Re u ≤ |Re d|/2,
 and Ã(1−u−z/2) is entire, rapidly decreasing in |Im u| uniformly in vertical strips (A ∈ C_c^∞(0,∞)), so no poles, no horizontal terms.
 Mellin–Parseval with G(ξ) = 𝒢(4π²nξ/(pq)) (G(ξ)ξ^{σ−1} ∈ L¹(0,∞)) and F = Aξ^{−z/2} ∈ C_c^∞ (F̃ integrable on the line):
 (2πi)^{−1}∫F̃(1−u)G̃(u)du = ∫F G (Fubini). Numerically (e1_dual_identity.log): Mellin vs x-space agree to 1e−8…1e−13. ∎
**Step 2 (Hankel form).** B(X) = √(2/(πX))·(−i/2)[e^{i(X−π/4)}a_+(X,d) − e^{−i(X−π/4)}a_−(X,d)] (SL §3.6; from H^{(1,2)}_d = J_d ± iY_d),
 a_±(X,d) = Γ(d+1/2)^{−1}∫_0^∞ e^{−t}t^{d−1/2}(1 ± it/(2X))^{d−1/2}dt (SL §3.6: DLMF 13.4.4, 13.6.10, 10.27.8; Re d > −1/2, X ≥ 1).
 Since |1 ± it/(2X)| ≥ 1, |(1 ± it/(2X))^{d−1/2}| ≤ e^{π|Im d|/2} and (t/(2X))/|1 ± it/(2X)| ≤ 1: X^k∂_X^k a_± = O_k(1) uniformly for |d| ≤ 1/4.
**Step 3 (profile bounds).** y ↦ e^{−y²+(1−2β)y/H}[H²(e^{2y/H}−1−2y/H)]^j is Schwartz with every seminorm O_j(1) uniformly in H ≥ 1, |β| ≤ 1
 (e^{−y²+2j|y|/H} ≤ C_j e^{−y²/2}), so Φ_j(w) = H^{−2j}Ψ_j(w), Ψ_j^{(k)}(w) ≪_{j,k,K}(1+|w|)^{−K}.
 Put w = (T−2πξ)/H, E_K(ξ) = (1+|w|)^{−K}. On supp χ(ξ/T) (ξ ≍ T, Re β ≪ 1/L): ∂_ξ^k A(ξ) ≪_{j,k,K} (T/H²)^j H^{−k}E_K(ξ)
 (a ξ-derivative costs 2π/H on Ψ_j, ≪ 1/T on ξ^{j−β} and χ(ξ/T)). Also ∂_ξ^k ξ^{−z/2} ≪ ξ^{−k}.
 The phase X(ξ) has no stationary point: X' = X/(2ξ) > 0, X^{(k)} = c_k X/ξ^k. Put X0 = X(T/2π) = 2√(2π)·√(nT/(pq)).
 On supp χ(ξ/T): X ≍ X0, X' ≍ X0/T, (1/X')^{(k)} ≪ (T/X0)T^{−k}; with Step 2, ∂_ξ^k[X^{−1/2}a_±(X)] ≪ X0^{−1/2}T^{−k}.
 X0 ≥ 4π√(c1T/y²) → ∞ since ν < 1/2 (Step 2 applies, X ≥ 1).
**Step 4 (integration by parts, no stationary phase).** For G = Aξ^{−z/2}X^{−1/2}a_±(X): ∂^kG ≪ (T/H²)^j X0^{−1/2}H^{−k}E_K.
 Write e^{±iX} = (±iX')^{−1}(e^{±iX})'; A has compact support (no boundary terms), so ∫Ge^{±iX}dξ = (±i)^K∫(𝒟^K G)e^{±iX}dξ,
 𝒟G = (G/X')' = G'/X' + G·(1/X')'. Each 𝒟 costs ≪ (T/X0)·H^{−1} (derivative of G: H^{−1}; of 1/X': T^{−1} ≤ H^{−1}). Hence, with ∫E_K dξ ≍ H,
  |𝒯(n)| ≪_{j,K} (T/H²)^j · H · X0^{−1/2} · min{1, (T/(H X0))^K} ≪ (T/H²)^j H (pq/(nT))^{1/4} (1 + √(n/N0))^{−K},
 N0 := pqT/H² (H X0/T = 2√(2π)·√(n/N0)). Per-n sizes and the decay beyond N0 observed numerically (§5).
**Step 5 (summation).** |σ_{−α,β}(n)| ≤ d(n)n^{|Re α|+|Re β|} ≪ n^{ε}, |(q/p)^{−z/2}n^{−z/2}| ≪ (pqn)^{ε}. For K ≥ 3:
 Σ_{n≥1} n^{−1/4+ε}(1+√(n/N0))^{−K} ≪ (1+N0)^{ε}·N0^{3/4} if N0 ≥ 1, ≪ N0^{K/2} ≤ N0^{3/4} if N0 < 1.
 Per (g,p,q): Σ_n|D| ≪ (1/(gpq))(T/H²)^j H (pq/T)^{1/4} N0^{3/4} T^{ε} = (T/H²)^j g^{−1} T^{1/2+ε} H^{−1/2}  [(pq)^{1/4+3/4−1} = 1].
 Σ over g ≤ y, p, q ≤ y/g: Σ_g y²/g³ ≤ ζ(3)y². Total oscillatory dual ≪_{J,K} T^{1/2+ε}H^{−1/2}y² (j < J, T/H² ≤ 1).
 Main term ≍ H (√πH·c(P,Q,R,ν) for the Gaussian weight; SL §3.7). Relative error T^{1/2+2ν−3θ/2+ε}: power-small iff ν < (3θ−1)/4. ∎
Other branches as in SL (unchanged): ε = +1 primal profile ≪ (H/T)^A; K-Bessel (cos(πd/2)) branch O(H(y²/T)^σ), any σ (ν < 1/2);
 Estermann residues = Young's diagonal main term (ν < 1/2; SL §3.7); Taylor remainder (SL (11)) O(T^{1+ν+ε}(T/H²)^J) ≪ H T^{−δ} for J > (1+ν−θ+δ)/(2θ−1).
 Shift derivatives (Cauchy circles of radius ≍ 1/L) cost L^{O(1)}. Compact windows (SL §3.7): Gaussians of width s0 = T^{θ−η}, η > 0 small
 with θ−η > 1/2 and ν < (3(θ−η)−1)/4; the mixture has absolute mass O(H). This proves E1-M.
Comparison: SL §3.5 bounds the same dual by Cauchy–Schwarz in t (Lemma 3.1, collision factor R ≈ N), giving T M/H² + T M³/H^{5/2}; it never
 uses the per-n size H X0^{−1/2}: in the Mellin picture the u-integral has a stationary point at |t| ≍ X0 whose √X0 gain the L¹/L² norm (15) loses.

## 5. Falsification
- Where the new bound fails: exponent 1/2 + 2ν − 3θ/2 ≥ 0 ⟺ ν ≥ (3θ−1)/4; for ν = 3/25 at θ ≤ 37/75 = 0.49333. Binding for E1 is θ > 1/2
  (Taylor step (T/H²)^J; for θ < 1/2 even p = q = 1 has N0 = T/H² > 1). Detector side: κ(ν) > k*(θ) needs, with κ ≈ 0.71733ν and ν < (3θ−1)/4,
  θ > 0.49384 (onsets.log) — so 1/2 is the method's barrier on both sides, not an artefact of ν = 3/25.
- Per-term sharpness (e1_dual_size.log, scipy, real shifts α = 0.01, β = 0.02, A = A_{−1,0}): T ∈ {400,…,25600}, H = T^{≈0.6}, pq ∈ {4,…,256},
  N0 ∈ {1,…,64}: max_{n≤N0}|𝒯(n)|/(H X0^{−1/2}) ∈ [0.11, 0.58] (bound attained up to a constant); |𝒯(n)|/max at n = 4N0: ≤ 1.6e−3, at 8N0: ≤ 4.4e−6;
  S = Σ_n d(n)|𝒯(n)| over H(pq/T)^{1/4}N0^{3/4}: 0.074 … 0.665, growing like log N0 (the d(n) average); per-(g,p,q) ratio (4π/pq)S/√(T/H): 0.93 … 8.4.
  No case exceeds the claimed scaling; the trivial bound loses only the (unused) cancellation in n, p, q.
- Identity (e1_dual_identity.log): Mellin form (14) on Re u = 0.15 vs Step 1 x-space form, (T,H,pq) = (60,12,3), (200,25,6), n = 1,2,5,9:
  relative differences 3e−13 … 2e−8 (quadrature limit at the smallest values). Peaks ≤ 89 MB.
- Inputs unchanged from the audited SL proof; no new hypothesis (no RH, no pair-correlation conjecture, no simplicity).
