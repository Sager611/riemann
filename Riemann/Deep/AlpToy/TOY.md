## Item 1 — function-field toy (note item 3 and footnote 3)
Statement (remark.txt l. 152–156, fn 3 l. 166–171): "qN = M^k + R, using x1·x2 + ··· + xk−1·xk"; fn 3: "Σ_{h,x1..xk} t(x1)···t(xk)·e_q(h(x1x2+···+x_{k−1}x_k)), sum over h first for the left-hand side … Bertini gives a definite sign from middle cohomology, one off the one on M^k, which is the zero-mode on the right-hand side with R square-root-quality … by iterating Parseval k times, opposite signs meaning no cancellation of inverse roots, QED".
Lean: no counterpart found (decls.txt: no path-quadric / sign-only Weil names; Development/WeilBound/ is p-adic Hodge material). Tested as stated in the note.
Reading: summing over h first gives LHS = q·N, N = Σ_{Q(x)=0} Π t(x_i) (weighted count on the path quadric); h = 0 gives M^k, M = Σ_x t(x); R = Σ_{h≠0} S(h), S(h) = tᵀ(F_h D_t)^{k−2}F_h t with F_h = [e_q(hxy)] (so F_h/√q unitary) ⇒ iterated Parseval |S(h)| ≤ ‖t‖₂² q^{(k−1)/2} ‖t‖_∞^{k−2}.
Method (code/item1_ff_toy.py, logs/item1.log, peak < 10 MB): N exact (integer DP over (x_last, partial Q mod q)); S(h) by transfer matrices (complex float64); q prime 3..31, k = 2..6, t = 1+χ(f) (affine point weights of y² = f(x)) and t = χ(f); curves E1: y²=x³+x+1, E2: y²=x³+2x+3, C2: y²=x⁵+x+3 (genus 2); 265 (curve,q,t,k) cases (E2 mod 3 skipped for t=χ(f): χ(f) ≡ 0 on F_3).
Numbers:
- Identity: max |Σ_h S(h) − qN| = 2.4e−7, max |Σ_{h≠0} S(h) − (qN − M^k)| = 2.4e−8, max |Im R| = 8e−9: holds (it is a tautology once R := h≠0 part; the content is the bound on R and the sign).
- Parseval bound: max_h |S(h)|/(‖t‖₂² q^{(k−1)/2}‖t‖_∞^{k−2}) = 1.000 (attained only where f is affine-linear on F_3, the Gauss-sum eigenvector case), never exceeded. |R| ≤ 17.4·q^{(k+3)/2} for t = 1+χ(f) (Parseval constant ≈ 2^{k−1}), ≤ 0.45·q^{(k+3)/2} for t = χ(f): square-root quality relative to the h-sum (q^{k+1} terms), as claimed.
- Sign: no pointwise definite sign. sign((−1)^{k−1}R) for t=1+χ(f): k=2: 11+/16−, k=3: 24+/3−, k=4: 5+/22−, k=5: 25+/2−, k=6: 10+/17−; for t=χ(f) ≈ 50/50 at every k (also sign of qN). So the "definite sign" can only be the virtual sign of the middle-cohomology inverse roots across the tower F_{q^n}, not a sign of qN − M^k at one q; not testable at q ≤ 31 without the tower (not done).
- Deduced bound (what the sketch gives): |R_n| ≤ 2^{k−1} q^{n(k+3)/2} for all n, plus "no cancellation" of the M^k term (−1)^k α^k ⇒ |α| ≤ q^{1/2+3/(2k)} for each k ≥ 4 (trivial for k ≤ 3), → √q as k → ∞. Examples (affine trace a = Σχ(f) = −Σα): E1/F_29: a = 6, |a| ≤ 2·29^{1/2+3/(2k)} = 38.1, 29.6, 25.0 (k = 4,5,6) vs Weil 10.8, true 6. E2/F_31: a = 0, bounds 40.4, 31.2, 26.3 vs Weil 11.1. C2/F_31 (g = 2): a = −1, bounds 4·31^{…} = 80.7, 62.4, 52.6 vs Weil 22.3. Consistent; each finite k is weaker than Weil, the limit is Weil.
Verdict item 1: REPRODUCED (identity + square-root bound on R; smallest case q = 3, k = 2); the sign step is a cohomological claim, not checkable pointwise.

## Item 4 — Gz (note item 5)
Statement: note item 5 (remark.txt l. 160–162): "definitively switch to Λ aka Σ_{n≤X} Λ(n)·(X/n − 1) + −X log X + (1+γ)·X; Guinand–Weil had the sign". Lean (Formalism/StatementOC.lean:11–13, quoted): `def Sz (x : ℝ) : ℝ := ∑ n ∈ Finset.Icc 1 ⌊x⌋₊, Λ n * (x / n - 1)`, `def Gz (x : ℝ) : ℝ := Sz x - x * Real.log x + (1 + Real.eulerMascheroniConstant) * x`. Same object.
Exact explicit formula (own derivation: Sz(X) = X∫_1^X ψ(t)t^{−2}dt, insert ψ = t − Σρ t^ρ/ρ − log 2π − ½log(1−t^{−2}); constants Σ_ρ 1/(ρ(1−ρ)) = 2+γ−log 4π and Σ_k 1/(2k(2k+1)) = 1−log 2 cancel the X-terms):
  Gz(X) = log 2π − Σ_{k≥1} X^{−2k}/(2k(2k+1)) + Σ_ρ X^ρ/(ρ(1−ρ)).
So "the sign": on RH every zero enters with the positive weight 1/|ρ|², and |Gz(X) − log 2π + r(X)| ≤ (2+γ−log 4π)√X = 0.046191418·√X for all X ≥ 1 (equality at X = 1; reviewer: 0.0461914 rounds down) (RH ⇔ Gz(X) = O(X^{1/2+ε})).
Method (code/item4_gz_sieve.py, logs/item4_1e9.log; peak 176 MB, 32 s): segmented sieve to 10⁹ (2²²-blocks), all prime powers; Gz is continuous and concave between consecutive prime powers, so per interval the extrema are the endpoints and X* = exp(L_j + γ); float64 with per-block fsum bases (abs. error ≲ 10⁻³, vs √X-scale 3·10⁴).
Numbers (X ∈ [16, 10⁹]):
- max (Gz − log 2π)/√X = +0.024694 at X = 34,186,499; min = −0.022681 at X = 319,439 (53% and 49% of the RH bound 0.046191418). max |Gz|/√X ≤ 0.0646 for X ≥ 2¹⁰ (log 2π/√X dominates small X; Gz(1) = 1+γ).
- Per dyadic bin 2^20..2^29: max ∈ [0.0127, 0.0247], min ∈ [−0.0185, −0.0119]; no drift (finite data).
- Sign pattern: 114 sign changes of Gz − log 2π on [1, 10⁹] (nodes = prime powers), positive at 49.2% of nodes; the first zero alone gives ≈ 2·log(10⁹)·γ₁/(2π) ≈ 93 (period 2π/γ₁ = 0.445 in log X).

Verdict item 4: REPRODUCED (normalisation and sign as stated; smallest case X = 1: Gz(1) = 1+γ = log 2π − (1−log 2) + (2+γ−log 4π), exact).

## Item 3 — Weil functional on indicators (note items 4, 6)

So W was normalised here, the standard way: W(f,g) = Σ_ρ f̂(ρ)ĝ(1−ρ), f̂(s) = ∫_0^∞ f(x)x^{s−1}dx (Weil's criterion: RH ⇔ W(f,f̄*) ≥ 0). For 1_(0,a]: f̂ = a^s/s, so W(1_(0,a],1_(0,b]) = b·H(a/b) (a ≥ b), H(y) = Σ_ρ y^ρ/(ρ(1−ρ)) = Gz(y) − log 2π + r(y) (item 4 formula): the prime side is EXACT for y ≤ 10⁷.
Method (code/item3_weil.py, logs/item3.log; peak 184 MB): zeros: Odlyzko's first 10⁵ (T₀ = 74920.83, .scratch/alptoy/zeros1.txt); tail bound Σ_{|γ|>T₀} 1/|ρ|² ≤ 4.413e−5 (N(T₀) = 10⁵ exact + Trudgian's N(T) error term); primes ≤ 10⁷ (all prime powers).
Numbers:
- W(1_(0,1]) = H(1) = 2+γ−log 4π = 0.0461914179 (unconditional identity); zeros: 0.0461472907, difference 4.413e−5 = tail bound. W(1_(0,1/X]) = H(1)/X (dilation). Cross term = H(X)/X.
- Explicit formula check H_prime = H_zero on 1507 points y ∈ [1, 10⁷]: max |difference|/√y = 4.413e−5 ≤ tail bound (attained at y = 1).
- Item 6: W(1_(0,1] + c·1_(0,1/X]) = H(1)(1 + c²/X) + 2c·H(X)/X. With c = κX^η, η ∈ {0.1,0.25,0.4,0.5,0.6,0.75}, κ ∈ {0.1,1,10}, 4000 X ∈ [2,10⁷]: min W/H(1) = 0.764 > 0 in all 18 cases. - k×k Gram matrices of 1_(0,x_i]/√x_i (k ≤ 8, x_i ∈ [10⁻⁷, 1]; 20 geometric + 200 random families): all positive definite, certified by Weyl (λ_min ≥ 6.2e−3 vs float error ‖E‖_F ≤ 7.4e−10, margin ≥ 1.4e7). W(1_S) for S a finite union of intervals is a signed sum of these entries, so W(1_S) ≥ 0 holds for every such S with these endpoints.
Verdict item 3: REPRODUCED as numerics (smallest case S = (0,1]: W = 0.0461914 > 0). Caveat: every inequality tested is implied by RH below height T₀ plus the tail; on the zero side PSD is automatic (Σ_ρ|f̂(ρ)|²), so the content is the prime-side normalisation, which matches exactly.
