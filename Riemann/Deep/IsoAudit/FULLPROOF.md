# FULLPROOF — the chain behind liminf B_0(T,c)/N(T) ≥ p(c) (isolated-zeros page), with source lines

Sources: [La] = Lamzouri arXiv 2610.26841v2 (IsolatedZeros2.tex, still the latest version on 19 Nov 2026; abs page lists v1 19 Oct, v2 26 Oct). [D] = Riemann/Deep/IsoZero/DERIVATION.md (line numbers of that file). [BCY] = arXiv 1002.4127. Each step: statement, source, audit status.

## A. Setting
A1. B_0(T,c) ([La] l.211–212): zeros ρ_n, n ≥ 2, 0 < γ_n ≤ T, min(γ_{n+1}−γ_n, γ_n−γ_{n−1}) > 2πc/log T; ordinates listed with multiplicity, so ρ and 1−ρ̄ (same ordinate) kill each other: counted zeros are simple and on the line. [D] §0 matches. OK.
A2. Z_T = {−i(ρ−½)log T/2π : 0<γ≤T} with multiplicity, conjugation invariant, real ⇔ β = ½ ([La] l.577–600). For ρ = β+iγ: z = γL − i(β−½)L, |Im z| = |β−½|L. OK.
A3. Counted set I_1 (x ∈ Z_T real simple, |x − Re z| > τ for all other z) gives c-isolated zeros with τ = c, since |γL − γ'L| > c ⇔ |γ−γ'| > 2πc/log T; losses: n = 1 and the top zero (upper neighbour above T is not in Z_T): B_0 ≥ |I_1| − 2 ([D] l.12–14). OK.

## B. Hilbert-space inequality ([La] Pro:IsolatedZeros proof, l.285–468)
B1. f_z(u) = η(u)e^{−2πiuz}, g_z = (f_z+f_z̄)/2, h_z = (f_z−f_z̄)/(2i) (l.287–291); ‖f_x‖² = 1, ‖g_z‖² − ‖h_z‖² = 1 (l.298); ΣK(z−s)² = ∬|F|², F = Σ_x m f_x⊗f_x + 2Σ m(g⊗g − h⊗h) (l.305–317). Re-derived: ‖g_z‖² = (1+K(2iy))/2, ‖h_z‖² = (K(2iy)−1)/2. OK.
B2. The signed term −h⊗h is handled by Bessel, Σ_j⟨h,ψ_j⟩² ≤ ‖h‖², with g ∈ U (l.393–402), so each complex pair contributes ≥ 2m to Σ_W α (l.405). All vectors satisfy conj φ(u) = φ(−u), so inner products and Gram–Schmidt coefficients are real (l.369–374). OK.
B3. Bessel for ψ_j(u)ψ_j(v), y² ≥ 4y−4 (j ≤ D_U), y² ≥ 2y−1 (D_U < j ≤ D_V) (l.376–391): ΣK² ≥ 2Σ_Uα + 2Σ_Vα − 3D_U − D_V. If the spans had smaller dimension the bound only improves; the paper proves equality (l.365–367). OK.
B4. Pairs: Σ_{y∈G}⟨f_y,ψ⟩² ≥ ½⟨P,ψ⟩², ‖P‖² = 2+2K(y_2−y_1) ≥ 2+2κ_0; triples: ≥ ⅓⟨Q,ψ⟩², ‖Q‖² ≥ 3+4κ_0+2κ_1 (l.413–436). OK (|w_3−w_1| ≤ 4τ).
B5. l.440, l.444 ⇒ l.451. [D] (E) (l.42) is l.451 before substituting N = d+2a+3b+M_R+M_S (l.448): checked by expansion, identical. (E') (l.47) = (E) − 2N: checked, β_T = (6 − 16κ_0/3 − 8κ_1/3)/3. OK.

## C. Explicit error terms ([D] §2, replacing [La] Pro:IsolatedSMALL l.511–573)
C1. Monotonicity ([D] l.51): K'(u) = −4π∫_0^{1/2} x f(x) sin(2πux)dx < 0 on (0,1] (sin(2πux) > 0 for 0 < ux < ½); so κ_00 = K(τ), κ_0 = K(2τ), κ_1 = K(4τ) when 4τ ≤ 1. Same for f_ε ≥ 0. OK.
C2. Clusters ([D] l.53): −4aε_0 − 3bβ_T ≥ −λ(2a+3b) for λ ≥ max(2ε_0, β_T, 0). OK. (β_T ≈ −2/3 for small τ: triples never bind.)
C3. Witnesses ([D] l.56–59; [La] l.328, 531–549): x ∈ I_2 has a witness in R_2 ∪ S within τ; a witness serves ≤ 1 point of I (points of I are > 2τ apart from R_1). R_2 witness: s_x ≥ K(x−x_m)² ≥ K(τ)² (f_{x_m} ∈ U, unit) — needs 2K(τ)² ≥ 1 (asserted in cert.py tau_data). OK.
C4. Complex witness ([D] l.61–65; [La] l.553–559): ⟨f_x,g_z⟩ = ∫f cos(2πδt)cosh(2πyt)dt, |δ| ≤ τ, |t| ≤ ½ ⇒ cos(2πδt) ≥ 1 − (2πδt)²/2 ≥ 1 − π²τ²/2 = 1 − θ̄ pointwise; f ≥ 0, cosh > 0 ⇒ ⟨f_x,g_z⟩ ≥ (1−θ̄)K(iy) > 0, squaring keeps direction (θ̄ < 1 asserted); ‖g_z‖² = (1+K(2iy))/2 ([La] l.559). So 2s_x − 1 ≥ −H_τ(y). OK.
C5. Combination ([D] l.67–77). 2S_0 − d ≥ −|I_1| + Σ_{I_2R}(2K(τ)²−1) − Σ_{I_2S}H_τ; dropped terms 2(M_R−2r), 2(M_S−2q), Σ_{I_2R}(…) are ≥ 0 and sit on the large side. Budget: N = d+|C|+M_R+M_S, d = |I_1|+|I_2R|+|I_2S|, M_S ≥ 2q ≥ 2|I_2S| (injective pairs) ⇒ |C| ≤ N − |I_1| − 3|I_2S|; λ ≥ 0 ⇒ −λ|C| ≥ −λ(N−|I_1|) + 3λ|I_2S|. Hence the FINITE inequality, for every finite conjugation-invariant multiset, every λ ∈ [λ_C, 1):
  (1−λ)|I_1| ≥ (2−λ)N − Σ_{z,s}K(z−s)² − Σ_{distinct pairs ℓ}(H_τ(y_ℓ) − 3λ)^+.            (F)
  Re-derived step by step: OK. (F) is tight for N = 1 (one real point: both sides 1−λ).
C6. Checks (2.6): τ → 0 gives 2 − C − Dα_0 ([La] l.816); λ = 1/3 gives 5/2 − 3C/2 ([La] Pro:IsolatedZeros). Re-derived: OK.

## D. Hinge lemma ([D] §3.1–3.3, §3.7)
D1. Conrey, Crelle 399 (1989) Thm 2 as quoted by [BCY] l.338–346: ∫_1^T|Vψ(σ_0+it)|²dt ~ c(P,Q,R)T, σ_0 = ½ − R/log T, θ < 4/7, P(0)=0, P(1)=1; for Q ≡ 1: c_1 = 1 + θ^{−1}∫_0^1e^{2Rv}dv∫_0^1(P'+θRP)². [D]'s own c(A,B) at A = B = −R minus c_1 equals 2∫PP' − 1 = 0: algebra re-checked by hand. (TeX check: section E below.)
D2. Transfer ([D] l.94–101): |ζ(σ⁺+it)| = |χ(σ⁺+it)||ζ(σ⁻+it)| (1−σ⁺ = σ⁻, ζ(s̄) = conj ζ(s)); ψ⁺(σ⁺+it) = A(t) exactly; |χ|² = (t/2π)^{−2R/log T}(1+O(1/t)); split at T^{1−δ}; the low part is Conrey at height U = T^{1−δ} with R_U = R(1−δ), θ_U = θ/(1−δ) < 4/7, same polynomial, so O(U) = o(T) (the O(1/t) factor is bounded, harmless). δ → 0: limsup ≤ e^{−2R}c_1. OK.
D3. Littlewood on [σ⁺,2]×[1,T] for ζψ⁺ ([D] l.103–107): ζψ⁺(2+it) = Σ b_m m^{−2−it}, b_1 = 1, b_m → 0 for fixed m ≥ 2, dominated by d(m)m^{−2+o(1)} ⇒ right edge o(T); Re(ζψ⁺)(2+iT) → 1 so horizontal arguments are O(log T) (Titchmarsh §9.4); Jensen ∫log|f| ≤ (T/2)log((1/T)∫|f|²). Gives ∫_{σ⁺}^1 ν(σ,T)dσ ≤ (T/4π)log c_+ + o(T) (zeros of ψ⁺ only add). OK.
D4. Optimal P ([D] l.116–119): ∫(P'+bP)² = ∫P'² + b + b²∫P², min b coth b (P = sinh bx/sinh b), so inf c_+ = c*(R) = 1 + (1−e^{−2R})/(e^{2θR}−1); polynomials with the same end values approach it (c_1 is continuous in H¹). Re-derived: OK. c* decreasing in θ, so θ → 4/7 is a sup of valid bounds. OK.
D5. Hinge ([D] l.124–128): β − σ⁺ = (y−ρ)/L with y = (β−½)L, R = 2πρ; Σ_{β>1/2}(y−ρ)^+ = L∫_{σ⁺}^1ν ≤ (B(ρ)+o(1))N, B = log c*(2πρ)/4π, using TL ~ N(T). No on-line proportion used. OK.
D6. Use ([D] l.131–137): h = (H_τ − 3λ)^+ = 0 on (0, ρ_max]; for ρ ≤ ρ_max, h(y) ≤ α_ρ(y−ρ)^+ with α_ρ = sup_{y>ρ}h/(y−ρ); each distinct pair ℓ ↔ one zero with β > ½, |y_ℓ| = (β−½)L; sum over distinct ≤ sum with multiplicity. (F) ⇒ (1−λ)|I_1| ≥ (2−λ−C−α_ρB(ρ)−o(1))N. OK.
