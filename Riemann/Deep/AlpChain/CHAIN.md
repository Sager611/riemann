## 0. Objects
- Gz y = Σ_{n≤y} Λ(n)(y/n−1) − y log y + (1+γ)y (Formalism/StatementOC.lean:11-13). Explicit formula [classical]: residue of −ζ'/ζ(s)·y^s/(s(s−1)) at s=1 is y(log y−1−γ), so
  (E0) Gz(y) = −Σ_ρ y^ρ/(ρ(ρ−1)) + log 2π − Σ_{k≥1} y^(−2k)/(2k(2k+1)), absolutely convergent (Σ 1/|ρ|² = 2+γ−log 4π ≈ 0.0462), so |Gz(y)| ≤ 0.047y + 2 unconditionally, and Gz(y) = O(√y) on RH. Check: max |Gz(y)|/√y = 0.0646 on [10³, 4·10⁶] (logs/landau_window_toy.log).
- Gchi χ y = ramp_χ(y) + y·L'/L(1,χ) for χ ≠ 1 (Development/AutomorphicArithmetic/DedekindLFunctions/CharFamily.lean:15-20): same normalisation, the pole of −L'/L(s,χ)/(s(s−1)) at s=1 cancels.
- Gm F y = Σ_i a_i Re Gchi(χ_i, y), a_i > 0, F a finite CharFamily (CharFamily.lean:24-36).
- ASK, MAIN, De, GPsi, primVal on the host group E0 × H, E0 = (Z/2)², Phi = {g : g.1.1 = 0} (Formalism/SizeWindowBrackets/FirstPrimeNeSecondPrime.lean:61-96; Formalism/ThickAverageLoss/PartnersToFactorsAt.lean:13-29).

## The chain (numbered inequalities; every constant explicit)
(L1) windowed Landau: ∀Y₀ ∃Y ≥ Y₀ ∀y ∈ [Y, Y^(1+δ)]: Gm F y ≤ C y^θ  ⇒  L(s,χ_i) ≠ 0 for Re s > θ, all i. (§1)
(L2) orthogonality: ASK − MAIN = De, exactly. (§2)
(L3) thick/thin split: Σ_{t∈TT,j<m}(ASK − MAIN) ≤ x^(Cε)·EB(x)  ⇒  GmA(x) ≤ x^(1/2+(C+3)ε) + SigA(x). (§3)
(L4) slopes ⇒ upper bound: DIV + SlopesN + SlopeIneq + Losses ⇒ mean ASK ≤ mean Main + ErrX (Bost slope inequality). (§4)
(L5) multiplicity: m lifts, per-lift numbers ⇒ DIV with errors ≍ |TT|·a·La + m(B0+Nc)x^ε. (§5)
(L6) bookkeeping: EB/(m·nT·b·dens) ≤ x^(1/2+O(ε)) with m ∈ [x^(1/2−ε), x^(1/2+ε/2)]. (§6)
(L7) inputs not derived here: VWin, ThinScales and the host conditions, the producers of SizeData₂/LinkDIV on the cone. (§7)

## 1. (L1) Windowed Landau theorem — [classical method; this windowed form new: derived here]. Agree.
Lean (Development/AutomorphicArithmetic/DedekindLFunctions/LandauTheorems/ZeroFreeOfRpowWindow.lean:11-14, on-cone):
    theorem zeroFree_of_rpow_window (F : CharFamily) {θ δ C : ℝ} (hθ : 0 < θ) (hθ1 : θ < 1) (hδ : 0 < δ)
        (h : ∀ Y₀ : ℝ, ∃ Y : ℝ, Y₀ ≤ Y ∧ ∀ y ∈ Set.Icc Y (Y ^ (1 + δ)), Gm F y ≤ C * y ^ θ) :
        ZeroFree F θ :=
      lemmaL F hθ hθ1 hδ (windowHyp_of_rpow F hδ h)
ZeroFree F θ := ∀ i, ∀ s, θ < Re s → L(χ_i, s) ≠ 0 (CharFamily.lean:38-39). lemmaL (LandauTheorems/lemmaL.lean:13) accepts the weaker WindowHyp (CharFamily.lean:41-46): g ≤ R on the window with ∫_W R y^(−θ−1) dy ≤ Y^η for every η > 0 (losses Y^(o(1)) allowed).
Paper proof (u = log y, g(u) = Gm F (e^u), W = [U, (1+δ)U], Φ(s) = ∫₀^∞ g(u)e^(−su)du for Re s > 2):
 (a) Poles. Re Gchi(χ,·) = (Gchi(χ,·)+Gchi(χ̄,·))/2, so Φ = Σ_i (a_i/2)(Φ_χi + Φ_χ̄i), Φ_χ(s) = −L'/L(s,χ)/(s(s−1)) + L'/L(1,χ)/(s−1) (ζ: −1/(s−1)² + (1+γ)/(s−1)), regular at s=1. Poles in Re s > 0 = zeros ρ, residue c_ρ = −(Σ_i a_i(m_χi(ρ)+m_χ̄i(ρ))/2)/(ρ(ρ−1)) ≠ 0 (positive weights: no cancellation); for real β ∈ (0,1): c_β = (…)/(β(1−β)) > 0. This is PoleData.pole (LandauZeroFreeCriterion.lean:15-23). Growth |g(u)| ≤ C₀e^(2u) is trivial.
 (b) Taylor coefficients a_k(z) := (−1)^k Φ^(k)(z)/k! = (1/k!)∫ g u^k e^(−zu) du, Re z = σ > 2. On W, g ≤ R with R ≥ 0, so h = R − g ≥ 0 there and |∫_W g u^k e^(−zu)| ≤ ∫_W (R+h)u^k e^(−σu); hence |A(z)| + A(σ) ≤ 2∫_W R u^k e^(−σu)/k! for the window parts A. Since u^k e^(−(σ−θ)u)/k! ≤ (σ−θ)^(−k), this is ≤ 2e^(ηU)(σ−θ)^(−k).
 (c) Tails. Off W, |g| ≤ C₀e^(2u) and u^k e^(−(σ−2)u)/k! is a Gamma(k+1, σ−2) density times (σ−2)^(−k−1): Chernoff with rate I(t) = t−1−log t gives tail mass ≤ C₁σ^(−k) for a k ≥ U centred in W once min(I(t₁),I(t₂)) > log(σ/(σ−2)) (δ = 1/2: centre t = 1.22, rate min(I(1/1.22), I(1.5/1.22)) = 0.018523 > log(110/108) = 0.018349, so σ = 110 works). Lean: landau_tails (LandauTheorems/landauTails.lean:80-82), assembled in landau_window_key (landauWindow.lean:40-45): |a_k(σ+iγ)| + a_k(σ) ≤ C'e^(ηU)/(σ−θ)^k.
 (d) Contradiction. If some zero has Re ρ₀ > θ: either a real zero β > θ is the unique zero in a ball B(σ, r), σ−β < r ≤ σ−θ — then a_k(σ) ~ c_β(σ−β)^(−k−1) > 0 beats e^(ηU)(σ−θ)^(−k) for η < log((σ−θ)/(σ−β)) (k ≥ U); or B(σ, D) is zero-free (D ≤ σ−θ) and some zero has σ − Re ρ₁ < D — then a point z = σ+iγ has a unique nearest zero ρ at distance < D (landau_dichotomy, LandauDichotomy.lean:24-28; landau_nearest, LandauNearest.lean:36-39), |a_k(z)| ≍ |c_ρ||z−ρ|^(−k−1), while |a_k(σ)| = O((D−ε)^(−k)) by Cauchy on the zero-free ball: again a contradiction. The sign of c_β is where 'real zeros are caught': a real zero makes g large POSITIVE, so an UPPER bound suffices.
Literature: Landau 1905 (one-sided bound on all of [y₀,∞) + Mellin positivity ⇒ real singularity at the abscissa) and Pringsheim's theorem are the classical core; localized one-sided oscillation is classical in kind (Kaczorowski–Pintz, Acta Math. Hungar. 1986/87; [unchecked]: statement not re-read). Window length: any fixed δ > 0 works, at the cost σ ≍ 1/δ² (rate I ≈ δ²/8); la = 3/2 (CharacterBoxes/EveryCharacter.lean plugWin) is δ = 1/2.
 Numbers (code/landau_tails_check.py, logs/landau_tails_check.log; exact incomplete Γ, 40 digits): with k = round(1.22(σ−2)U), log(T·σ^k) at U = 1…1000 is −6.2 … −32.9 for σ = 110 and −9.3 … −2058 for σ = 200 (bounded: the lemma holds), but grows to +1079 for σ = 60 (rate 0.0185 < log(60/58) = 0.034: fails). Chernoff threshold matches: rate 0.01852 vs log(110/108) = 0.01835.

## 2. (L2) Orthogonality ASK − MAIN = De — [classical: finite Fourier analysis on E0 × H]. Agree; exact check PASS.
Lean (Formalism/SizeWindowBrackets/FirstPrimeNeSecondPrime.lean:98-101; proof colour_balance, ChainSlopeWindows/StronglyIrreducible.lean:695, on-cone via ch_top):
    def AskMainBalance : Prop :=
      ∀ (D : ArithData H), HostFacts D → ∀ (ell : AddChar (E0 × H) ℂ → ℂ) (a : ℝ) (t : H) (w : E0 × H → ℝ),
        0 < a → (∀ ρ, InPhi ρ → 0 < w ρ) → ∀ N : ℕ, (∀ ρ, InPhi ρ → a / w ρ ≤ N) →
          (ASK D N a t w : ℂ) - MAIN ell a w = De D ell a t w
with MAIN = a(log a − 1 − γ + ell(chC) − mean_{ρ∈Phi} log w ρ) (:89-91), De = (1/|Phi|)Σ_{g∉Phi}Σ_ψ conj ψ(g)·w(partner t g)·GPsi(ψ, a/w(partner t g)) (:93-96), GPsi(0,·) = Gz.
Paper proof: (i) the ψ = 0 term: w·Gz(a/w) = Σ_n Λ(n)(a/n − w)^+ − a log a + a log w + (1+γ)a; averaging over g ∉ Phi and using that partner t = cconj + g + topPl t is a bijection {g ∉ Phi} → Phi (PartnerBij) gives the −MAIN terms except ell; (ii) the y·ell ψ terms sum to (a/|Phi|)Σ_{ψ≠0} ell ψ Σ_{g∉Phi} conj ψ(g) = −a·ell(chC) (ColourSum: Σ_{g∉Phi} conj ψ(g) = |Phi|, −|Phi|, 0 for ψ = 0, chC, else); (iii) the Λ-terms: (1/|Phi|)Σ_ψ conj ψ(g) primVal(ψ, p^i) = 2·[i·frob p = g] for p ∉ {2, q1, d} (inertia trivial, |G|/|Phi| = 2), = [g − i·frob d ∈ {0, sgc0}] for p = d, and is supported on Phi for p ∈ {2, q1} (inertia and Frobenius in Phi); this reproduces 2 log p·askP and log d·askD; (iv) a/w ≤ N makes the truncations n ≤ N, p ≤ N, i ≤ N harmless.
Exact check (code/colour_balance_exact.py, logs/colour_balance_exact.log): values in Q(i) ⊗ formal symbols {log p, γ, log a, log w_ρ, ell ψ} (so ell is fully arbitrary), H = Z/1, Z/2, Z/4, q1 = 3, d = 7, random Frobenius, nontrivial inertia at 2 inside Phi, w ∈ [1, 3], a ∈ [13, 90], N ≤ 46: ASK − MAIN − De = 0 identically in 18/18 instances. Controls: nontrivial inertia at the unramified p = 5 (HostFacts.unram violated) or +γ in MAIN each leave a nonzero coefficient. So HostFacts is load-bearing and MAIN is the true main term (alpcore Test C saw the same on real primes to 2·10⁶).

## 3. (L3) From the gap to the window bound, and (L6) the exponent — [new: derived here]. Agree.

          GmA D ell Kp c x ≤ x ^ ((1 : ℝ) / 2 + (C + 3) * ε) + SigA D ell A0 Kp x
gapA u0 = Σ_{t∈TT}Σ_{j<m}(ASK − Re MAIN) (SplitInertia.lean:50-54); EB := errorBracketSizeWindows = nT·aE(1+m²/k) + m(2n·m·b·x^ε + nT2·k·b·x^ε/(n·n·x^(−ε))) (Formalism/SizeWindowBrackets/ErrorFormsWeakWindowsFalse.lean:133-135); RestSize: aE ≤ 2xb, x^(−ε/8)n/2 ≤ nT, x^(−ε) ≤ nT2/n, x^(1/2−ε) ≤ m, k ≤ n²x^(1/2−ε) (SChain.lean:53-58); GmA = Σ_{ψ∈Kp} wtA(c,ψ) Re GPsi(ψ,x), SigA = Σ_{ψ∈PsiA∖Kp} |GPsi(ψ,x)| (SplitInertia.lean:34-41).
Paper derivation. By (L2), ASK − MAIN = De. Split ρ = partner t g ∈ Phi (|Phi| = 2n) into thick ρ (|T2| of them; b ≤ w ≤ b+η+1, so a_t/w = x + O(1 + xη/b) since |a_t/b − x| ≤ 1) and thin ρ (w ≤ 2b', so a_t/w ≥ X'/3 and ThinScales gives w|GPsi| ≤ a_t θ). Replacing w by b on thick places costs ≤ 3(a_t/b)(η+1) per term (LipW), the thin part ≤ 4n·a·θ per (t, j); CostWindows (2f(x+1)θ ≤ 1/x, 6f(x+1)(η+1) ≤ b/x, SChain.lean:50-51) makes both negligible against N0·x^(1/2) (N0 below). Thick places: partner t g = thickPl(t'+u0) = ((0,1), t'+u0) forces g = ((1,0), t'+u0−t), so with w = b the thick part of De, averaged over u0 ∈ A0, is (b/2n)Σ_ψ GPsi(ψ, a_t/b)·Σ_{t'∈T2} mean_{u0∈A0} conj ψ((1,0), t'+u0−t) = (nT2·b/(2n))·Σ_{ψ|A0 = 1} ψ(sgc0)·ψ((0,0),t)·GPsi(ψ, a_t/b) (using T2 ⊂ A0; sgc0 = ((1,0),0) has order 2). For A0 = H this is ThickPartTranslateMean (GrowthBoundGivesRiemannHypothesis.lean:44-50): (δ2·b/2)·Gsig, Gsig = G(0) + G(psC) − G(chC) − G(chpsC) (:33-34). Exact check of both forms (code/thick_translate_exact.py, logs/thick_translate_exact.log): coefficient of every GPsi(ψ,·) equal in Q(i), 20/20 (H = Z/1, Z/2, Z/4; A0 = {0,2} ⊂ Z/4). Summing over t ∈ TT with CharsA (Σ_t ψ(0,t) = c·|TT| + O(M x^(−1+ε)|TT|) for kept ψ nontrivial on H, |c| ≤ 1; ψ(sgc0) = 1 on Kp) gives
  mean_{u0∈A0} gap = N0·(GmA(x) + R) + (thin, Lipschitz, CharsA errors), |R| ≤ SigA(x), N0 := m·nT·b·nT2/(2n);
the characters with ψ(sgc0) = −1 (chC, chpsC, …) land in R with the wrong sign, hence the separate SigA. So GmA(x) ≤ x^(Cε)·EB/N0 + SigA + errors/N0, and EB/N0 = T1 + T2 + T3 with, under exactly the hypotheses of ch_core:
  T1 = 2n·aE(1+m²/k)/(m·b·nT2) ≤ 4x^(1/2+2ε)(1 + m/x)   [aE ≤ 2xb, n/nT2 ≤ x^ε, m ≥ x^(1/2−ε), xm ≤ k]

Agree on the exponent. Remainders (added after the reviewer, logs/reviewer_chain.md; f = fPl H = |Phi| = 2n): Lipschitz (w ∈ [b, b+η+1] → b): ≤ 6|T2|(x+1)(η+1) per (t,j), /N0 ≤ 12n(x+1)(η+1)/b ≤ 1/x by CostWindows; thin (w ≤ 2b' ⇒ a_t/w ≥ X'/3 for x ≥ 3, ThinScales): ≤ 4n(x+1)bθ per (t,j), /N0 ≤ 8n·x^ε(x+1)θ ≤ 2x^(ε−1); CharsA (|Σ_t ψ(0,t) − c|TT|| ≤ M x^(−1+ε)|TT|, |GPsi(ψ,x)| ≤ x(log x + 1 + Ko), #Kp ≤ M): /N0 ≤ M²x^ε(log x + 1 + Ko); shift a_t/b → x (|a_t/b − x| ≤ 1; ∂_y ramp = Σ_{n≤y} Λ(n)primVal(ψ,n)/n with |primVal| ≤ 1 and Σ_{n≤y}Λ(n)/n ≤ log y + 3 (Mertens), ∂_y(y·ell ψ) = ell ψ; for ψ = 0, ∂_y Gz = Σ_{n≤y}Λ(n)/n − log y + γ): |GPsi(ψ,y) − GPsi(ψ,x)| ≤ log(x+1) + 3 + max(Ko, CE log x), summed over #PsiA ≤ M characters. ### 4b. Bost slope inequality — [classical]. Agree for HN.SlopeIneq; Data.SlopeIneq [unchecked].
Lean (Formalism/HarderNarasimhan/Statement.lean:91-100; proved: slope_inequality_general, HarderNarasimhanProofs/SlopeIneq.lean:507; ShiftInvariance.lean:43):
    def SlopeIneq : Prop :=
      ∀ (R V W E F : Type*) … (ρ : V →+ E) (ρ' : W →+ F) (L : Submodule R V) (M : Submodule R W), IsLat ρ L → IsLat ρ' M →
        ∀ (φ : L →ₗ[R] M) (C : ℝ), 0 < C → (∀ x : L, ‖ρ' (φ x : W)‖ ≤ C * ‖ρ (x : V)‖) →
        (φ ≠ 0 → muMin ρ L - Real.log C ≤ muMin ρ' ((LinearMap.range φ).map M.subtype) ∧
          muMin ρ L ≤ muMax ρ' M + Real.log C) ∧
        (Function.Injective φ → L ≠ ⊥ → muMax ρ L ≤ muMax ρ' M + Real.log C)
deg = −log covol (Z-lattice, √det Gram), slope = deg/Z-rank (Formalism/LatticeSlopes/Statement.lean:15-25); muMax over nonzero R-submodules, muMin over quotients by saturated R-submodules (HarderNarasimhan/Statement.lean:28-33).
