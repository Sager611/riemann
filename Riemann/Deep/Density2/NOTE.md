## 0. Notation

- K quadratic, discriminant d_K; f ≥ 1; O = Z + fO_K; D = f²d_K. I_K(f) = fractional O_K-ideals prime to f; m(𝔞),
  primitive ideals (m(𝔞) = 1), d_k: as in [C] §0. 𝔞̄ = conjugate ideal. ‖c‖²_ε := Σ_𝔞 m(𝔞)^{1+2ε}|c_𝔞|².
- A Hecke character χ on I_K(f) is **Z-trivial** if χ((m)) = 1 for every m ∈ Z with (m,f) = 1. Then χ(m𝔞) = χ(𝔞), and
  χ̄(𝔞) = χ(𝔞̄) because 𝔞𝔞̄ = (N𝔞).
- K imaginary: G = Cl(O) = I_K(f)/P_{K,Z}(f) [Cox Prop 7.22], h = |G|, w = |O^*| ∈ {2,4,6},
  L_D := L(1,χ_{d_K})Π_{p|f}(1 − χ_{d_K}(p)/p). Class number formula for orders [Cox Thm 7.24 + Dirichlet]:
  h = w|D|^{1/2}L_D/(2π). Also L_D ≤ (log|d_K| + 2)(1 + log f) ≤ 4log²(3|D|).
- K real, D > 0 not a square: G⁺ = Cl⁺(O) = I_K(f)/P⁺_{K,Z}(f), where P⁺_{K,Z}(f) is generated by the (α) with α ∈ O,
  α ≡ a (mod fO_K), a ∈ Z, (a,f) = 1, N(α) > 0 (proof of Cox 7.22 verbatim, with narrow equivalence). h⁺ = |G⁺|;
  η > 1 the least unit of O of norm +1; η ≥ (3+√5)/2, so log η ≥ 0.962. Class number formula for orders:
  h⁺ log η = 2h(O)R(O) = D^{1/2}L_D (L_D as above, ≤ 4log²(3D)); hence h⁺ ≤ 1.04 D^{1/2}L_D.
- N(σ;t,χ*) := #{ρ = β+iγ : L(ρ,χ*) = 0, β ≥ σ, |γ − t| ≤ 1}, with multiplicity; T := |t| + 3.

## 1. Lattice counts

**Lemma 1 (sectors).** Let Λ ⊂ C be a lattice of covolume V, R > 0, 0 < φ ≤ π, θ₀ ∈ R, and
S = {re^{iθ} : 0 < r ≤ R, θ₀ ≤ θ < θ₀ + φ}. Then S contains at most 1 + R²φ/V primitive vectors of Λ.

*Proof.* Primitive vectors with equal arguments are equal, so those in S have arguments θ₁ < … < θ_k in [θ₀, θ₀ + φ).
For consecutive p_i, p_{i+1} we have 0 < θ_{i+1} − θ_i < π, so det(p_i, p_{i+1}) > 0; it lies in VZ, hence is ≥ V. The
triangles conv(0, p_i, p_{i+1}) have area ≥ V/2 and disjoint interiors, and lie in the closed circular sector of radius R
and angle φ, which is convex (φ ≤ π) of area R²φ/2. So (k − 1)V/2 ≤ R²φ/2. □

**Lemma 2 (ring classes by angle; K imaginary).** For C ∈ G fix an integral 𝔠 ∈ C^{−1} prime to f; L_C := O ∩ 𝔠 ⊂ C.
- (i) The integral 𝔟 ∈ C prime to f are exactly the (β)𝔠^{−1} with β ∈ L_C prime to f; β is unique up to O^* = μ_w;
  N𝔟 = |β|²/N𝔠; and 𝔟 is primitive iff β is a primitive vector of L_C.
- (ii) covol(L_C) = N𝔠|D|^{1/2}/2.
- (iii) For N ≥ 1, θ₀ ∈ R and 0 < φ ≤ 2π/w, the number of primitive 𝔟 ∈ C prime to f with N𝔟 ≤ N and
  arg β ∈ θ₀ + [0, φ) + (2π/w)Z is ≤ 1 + 2φN/|D|^{1/2}. In particular (φ = 2π/w) a class contains at most
  1 + 4πN/(w|D|^{1/2}) primitive ideals of norm ≤ N.

*Proof.* (i) 𝔟𝔠 ∈ P_{K,Z}(f) is integral, so 𝔟𝔠 = (β) with β ∈ O_K, β ≡ a (mod fO_K), a ∈ Z, (a,f) = 1; thus
β ∈ O ∩ 𝔠. Conversely such β give integral ideals in C. If (β) = (β′) with β, β′ ∈ L_C, then u = β′/β ∈ O_K^* and
u ≡ a′a^{−1} (mod fO_K), so u ∈ O^*. For (m,f) = 1: 𝔟 ⊂ mO_K ⟺ β ∈ m𝔠 ⟺ β ∈ mL_C (if β = mγ, γ ∈ 𝔠, then
γ ≡ m^{−1}a (mod f), so γ ∈ O); m(𝔟) is prime to f ([C] §0); and β ∈ mL_C with p | (m,f) would give β ∈ pO_K,
impossible since β is prime to f. (ii) [𝔠 : O ∩ 𝔠] = [𝔠 + O : O] = [O_K : O] = f, because 𝔠 + O ⊇ 𝔠 + fO_K = O_K;
covol(𝔠) = N𝔠|d_K|^{1/2}/2. (iii) The condition does not depend on the choice of β in its μ_w-orbit, and each orbit has
exactly one element with arg β ∈ θ₀ + [0, 2π/w). Apply Lemma 1 with R² = N·N𝔠, V = N𝔠|D|^{1/2}/2. □

**Lemma 3 (hyperbolic count; K real).** For C ∈ G⁺ fix an integral 𝔠 ∈ C^{−1} prime to f; L_C := O ∩ 𝔠, embedded
in R² by β ↦ (β, β′). Then covol(L_C) = N𝔠D^{1/2}; the integral 𝔟 ∈ C prime to f are the (β)𝔠^{−1} with β ∈ L_C prime
to f and N(β) > 0, β unique up to O^*_+ = ±η^Z; primitivity corresponds as in Lemma 2; and

  #{𝔟 ∈ C primitive, prime to f, N𝔟 ≤ N} ≤ (log η + 1)(1 + 2.351N/D^{1/2}).

*Proof.* The first assertions are proved as in Lemma 2 (now N(β) > 0, units of norm +1, covol(O_K) = d_K^{1/2}). Each orbit
±η^Z·β has exactly one element with β > 0, β′ > 0, 1 ≤ β/β′ < η² (since ηη′ = 1). Put X := N·N𝔠, J := ⌈log η⌉ and
cover [1, η²) by the [e^{2j}, e^{2j+2}), j < J. The piece R_j = {(u,v) : u,v > 0, uv ≤ X, e^{2j} ≤ u/v < e^{2j+2}} lies
in the triangle with vertices 0, P = X^{1/2}(e^j, e^{−j}), Q = X^{1/2}(e^{j+1}, e^{−j−1}), because {uv ≥ X, u,v > 0} is
convex and contains the chord PQ. This triangle is convex, contains 0 and has area (X/2)(e − e^{−1}). The argument of
Lemma 1 (primitive points ordered by slope; consecutive ones span triangles of area ≥ V/2 inside 0PQ) gives at most
1 + X(e − e^{−1})/V ≤ 1 + 2.351N/D^{1/2} primitive points in R_j. Sum over j. □

## 2. Weighted large sieves

Throughout, 0 < ε ≤ 1/2, N ≥ 1, and c_𝔞 is supported on (𝔞,f) = 1, N𝔞 ≤ N.

**Definition.** K imaginary, M ≥ 0: 𝒜(D,M) is the set of Z-trivial Hecke characters χ of K of conductor dividing fO_K
whose ∞-type ℓ_χ (χ((α)) = (α/|α|)^{ℓ_χ} for α ≡ 1 mod^× fO_K) satisfies |ℓ_χ| ≤ M.

Facts. (i) A Hecke character χ mod fO_K is Z-trivial iff χ((β)) = (β/|β|)^{ℓ_χ} for every β ∈ O prime to f. [Write
χ((β)) = χ_f(β)(β/|β|)^ℓ with χ_f a character of (O_K/fO_K)^*. Z-triviality means χ_f(m) = 1 for all m ∈ Z prime to f
(take m > 0; m ≡ −1 gives χ_f(−1) = 1), so the unit −1 forces (−1)^ℓ = 1; for β ≡ a (mod f), χ_f(β) = χ_f(a) = 1.
Conversely take β = m.] (ii) ℓ_χ ∈ wZ, and for each ℓ ∈ wZ the χ ∈ 𝒜 with ℓ_χ = ℓ form one coset χ_ℓĜ: the map
(β) ↦ (β/|β|)^ℓ on P_{K,Z}(f) is well defined because u^ℓ = 1 for u ∈ O^*, extends to I_K(f) in h ways, and each
extension is a Grössencharacter mod fO_K of ∞-type ℓ. So |𝒜(D,M)| = h(2⌊M/w⌋ + 1) and 𝒜(D,0) = Ĝ. (iii) For ℓ ≠ 0,
L(s,χ*) is the L-function of the CM newform θ_{χ*} of weight |ℓ| + 1 and level |d_K|N𝔣_χ, with gamma factor
Γ_C(s + |ℓ|/2) = Γ_R(s + |ℓ|/2)Γ_R(s + |ℓ|/2 + 1).

**Lemma 4 (anticyclotomic large sieve).**

  Σ_{χ∈𝒜(D,M)} |Σ_𝔞 c_𝔞χ(𝔞)|² ≤ (11.3/ε) L_D (N + |D|^{1/2}(M+6)/(2π)) ‖c‖²_ε ≤ (46/ε) log²(3|D|) (N + |D|^{1/2}(M+6)) ‖c‖²_ε.

For M = 0 the constant improves to ε^{−1}L_D(2N + (w/2π)|D|^{1/2}). Both terms are attained up to constants: c supported
on the primitive ideals of one class gives ≥ h, and c ≡ 1 on all primitive ideals of norm ≤ N gives ≫ L_D N for N large.

*Proof.* Write 𝔞 = m𝔟, 𝔟 primitive. Z-triviality gives Σ_𝔞 c_𝔞χ(𝔞) = Σ_𝔟 B_𝔟χ(𝔟), B_𝔟 = Σ_m c_{m𝔟}, and
Σ_𝔟|B_𝔟|² ≤ ζ(1+2ε)‖c‖²_ε ≤ ε^{−1}‖c‖²_ε (Cauchy–Schwarz as in [C] Lemma 2). By Fact (ii) and orthogonality on Ĝ,

  Σ_{χ∈𝒜}|Σ_𝔟 B_𝔟χ(𝔟)|² = h Σ_{C∈G} Σ_{ℓ∈wZ, |ℓ|≤M} |Σ_{𝔟∈C} B_𝔟 χ_ℓ(𝔟)|².

For 𝔟 ∈ C, χ_ℓ(𝔟) = χ_ℓ(𝔠)^{−1}(β_𝔟/|β_𝔟|)^ℓ (Lemma 2(i), Fact (i)). With ℓ = wk, K₀ := ⌊M/w⌋ and
ψ_𝔟 := w·arg(β_𝔟)/2π ∈ R/Z (well defined), the inner sum is Σ_{|k|≤K₀}|Σ_{𝔟∈C} B_𝔟 e(kψ_𝔟)|². Let L := 2K₀ + 2 and
F(x) := L^{−1}(sin πLx/sin πx)² = Σ_{|k|<L}(1 − |k|/L)e(kx) ≥ 0 (Fejér). As 1 − |k|/L ≥ 1/2 for |k| ≤ K₀,

  Σ_{|k|≤K₀}|Σ B_𝔟 e(kψ_𝔟)|² ≤ 2Σ_{𝔟,𝔟′}|B_𝔟||B_𝔟′|F(ψ_𝔟 − ψ_𝔟′) ≤ 2Σ_𝔟|B_𝔟|² · max_𝔟 Σ_{𝔟′}F(ψ_𝔟 − ψ_𝔟′).

Now F ≤ L and F(x) ≤ 1/(4L‖x‖²), and the 𝔟′ with ‖ψ_𝔟′ − ψ_𝔟‖ ∈ [j/L, (j+1)/L) lie in two arcs of length 1/L. So
Σ_{𝔟′}F ≤ 2A_C L(1 + Σ_{j≥1}1/(4j²)) ≤ 2.83 A_C L, where A_C is the largest number of primitive 𝔟 ∈ C (N𝔟 ≤ N) with ψ_𝔟
in an arc of length 1/L. Such an arc is a sector of angle φ = 2π/(wL) = π/(w(K₀+1)) in arg β, modulo 2π/w; Lemma 2(iii)
gives A_C ≤ 1 + 2πN/(w(K₀+1)|D|^{1/2}). Altogether the left side is at most
11.3 h(K₀+1)(1 + 2πN/(w(K₀+1)|D|^{1/2})) Σ|B_𝔟|² = 11.3 (h(K₀+1) + L_D N) Σ|B_𝔟|², by h = w|D|^{1/2}L_D/2π, and
h(K₀+1) ≤ |D|^{1/2}L_D(M + w)/2π. For M = 0 skip the Fejér step: the left side is hΣ_C|Σ_{𝔟∈C}B_𝔟|² ≤ h·max_C π_C·Σ|B|²
with π_C ≤ 1 + 4πN/(w|D|^{1/2}) (Lemma 2(iii)). □

Remarks. (1) The weight cannot be dropped ([C], remark after Lemma 2). For the angular family all rational ideals (n)
have angle 0: for Q(i), K₀ = 100, N = 2000 the unweighted norm is 8906, against 1988 on primitive ideals and the bound
19058 (qa1.py). (2) qa3.py computes the exact left side on primitive ideals for D ∈ {−23, −36, −56, −71, −100, −147,
−191, −1999}, M ≤ 40: at most 0.11 of the bound, and of size ≍ N + |D|^{1/2}M.

**Lemma 5 (narrow ring classes; K real).**

  Σ_{χ∈Ĝ⁺} |Σ_𝔞 c_𝔞χ(𝔞)|² ≤ (4.8/ε) L_D (N + D^{1/2}) ‖c‖²_ε ≤ (20/ε) log²(3D) (N + D^{1/2}) ‖c‖²_ε.

*Proof.* Characters of G⁺ are Z-trivial ((m) is generated by m, of norm m² > 0). As in Lemma 4 with M = 0 the left side is
≤ h⁺·max_C π⁺_C·ε^{−1}‖c‖²_ε, and by Lemma 3, h⁺π⁺_C ≤ (h⁺log η + h⁺)(1 + 2.351N/D^{1/2})
≤ 2.04 D^{1/2}L_D (1 + 2.351N/D^{1/2}) ≤ 4.8 L_D (N + D^{1/2}). □

## 3. Carlson's argument for Z-trivial families and their twists

**Proposition 6.** Let K be quadratic, f ≥ 1, D = f²d_K, M₀ ≥ 0 and 𝔔 := |D|(M₀+3)². Let 𝒵 be a finite set of Z-trivial
Hecke characters on I_K(f), of conductor dividing fO_K (times infinity), whose primitive characters have gamma factors
Γ_R(s+μ₁)Γ_R(s+μ₂) with Re μ_j ≥ 0, |μ_j| ≤ M₀ + 1. Assume

  (LS)  Σ_{ξ∈𝒵}|Σ_𝔞 c_𝔞ξ(𝔞)|² ≤ (B/ε)(N + Λ)‖c‖²_ε for all ε, N, c as in §2, with B ≤ 50log²(3𝔔) and Λ ≤ 2𝔔^{1/2}.

Let ψ₀ be a finite-order Hecke character on I_K(f) of conductor dividing fO_K (times infinity), and ℱ := ψ₀𝒵. Then for
every ε > 0, t ∈ R and 0.6 ≤ σ ≤ 1,

  Σ_{χ∈ℱ} N(σ;t,χ*) ≤ C(ε) 𝔔^{2σ(1−σ)+ε} T^{1+ε},

with C(ε) depending only on ε; and Σ_{χ∈ℱ}N(0;t,χ*) ≤ c₀|ℱ|log(16𝔔T²).

*Proof.* The changes to [C] (Lemma 4, Lemma 5 and the proof of Theorem 1), in order.

1. *Large sieve for ℱ.* Apply (LS) to the coefficients c_𝔞ψ₀(𝔞).

2. *Second moment.* For 1 ≤ X ≤ 𝔔 and u ∈ R,

  Σ_{χ∈ℱ, χ≠1} |L(1/2+iu,χ) M_X(1/2+iu,χ)|² ≤ C(ε) 𝔔^ε (X𝔔^{1/2}(|u|+3))^{1+ε}.   (2.1)

[C] Lemma 4, steps 1, 3 and 5 (the factor E_χ, the splitting 𝔞 = 𝔢𝔞′ with 𝔢 | f^∞, the 𝔢-sum, d(f) ≤ C(ε)|D|^ε) are
unchanged. Step 2 (grouping by conductor) is replaced by a decoupling that also absorbs the χ-dependent gamma factors.
Put s = 1/2+iu and U := M₀ + |u| + 3 ≤ (M₀+3)(|u|+3). For χ ∈ ℱ the AFE (F5) holds with A = A(χ*) ≤ |D| and
V_{s,χ}(y) = (2πi)^{−1}∫_{(2)} y^{−w}e^{w²}γ_χ(s+w)γ_χ(s)^{−1}dw/w; the contour shifts of [IK, Prop 5.4] (to Re w = B₁,
and to Re w = −1/4 for small y) give, for r = 0, 1, 2 and every B₁ ≥ 1, uniformly in χ ∈ ℱ,

  |(y∂_y)^r V_{s,χ}(y)| ≤ C(B₁) min(1, (y/U)^{−B₁}).

Fix φ ∈ C_c^∞((1/2,2)) with Σ_j φ(v/2^j) = 1 for v > 0. For 𝔢 | f^∞ and j ≥ 0 let Φ_j(v) := φ(v/2^j)V_{s,χ}(N𝔢v/√A).
Two integrations by parts in log v bound its Mellin transform: |Φ̂_j(τ)| ≤ μ_j(1+|τ|)^{−2} with

  S_{1,𝔢}(χ) = Σ_{j≥0} (2π)^{−1}∫ Φ̂_j(τ) P_j(χ, u+τ) dτ,  P_j(χ,u′) := Σ_{2^{j−1}<N𝔞′<2^{j+1}, (𝔞′,f)=1} χ(𝔞′)N𝔞′^{−1/2−iu′},

and Cauchy–Schwarz with weights μ_j(1+|τ|)^{−2} gives
|S_{1,𝔢}M_X|² ≤ C(Σ_jμ_j)Σ_jμ_j∫(1+|τ|)^{−2}|P_j(χ,u+τ)M_X(s,χ)|²dτ. For χ = ψ₀ξ, P_j·M_X = Σ_𝔟 c_𝔟ξ(𝔟) with c_𝔟
independent of ξ, |c_𝔟| ≤ d(𝔟)N𝔟^{−1/2}, N𝔟 < 2^{j+1}X. Step 1 and [C] Lemma 3 give

## 4. The theorems

**Theorem A (anticyclotomic family).** Let K be imaginary quadratic, f ≥ 1, D = f²d_K, M ≥ 0 and 𝔔 := |D|(M+3)². For
ε > 0, t ∈ R, T = |t| + 3:
- (a) Σ_{χ∈𝒜(D,M)} N(σ;t,χ*) ≤ C(ε) 𝔔^{2σ(1−σ)+ε} T^{1+ε} for 0.6 ≤ σ ≤ 1;
- (b) Σ_{χ∈𝒜(D,M)} N(σ;t,χ*) ≤ C 𝔔^{1/2} log³(3𝔔) log T for every σ.

Summing over unit windows, Σ_χ #{ρ : β ≥ σ, |γ| ≤ T} ≤ C(ε)𝔔^{2σ(1−σ)+ε}T^{2+ε}. M = 0 is [C] Theorem 1, now with T^{1+ε}
per window instead of T³.

*Proof.* (a) Proposition 6 with 𝒵 = 𝒜(D,M), ψ₀ = 1, M₀ = M (shifts |ℓ|/2, |ℓ|/2 + 1 ≤ M/2 + 1, Fact (iii)); (LS) is
Lemma 4 with B = 46log²(3|D|) and Λ = |D|^{1/2}(M+6) ≤ 2𝔔^{1/2}. (b) |𝒜(D,M)| = h(2⌊M/w⌋+1) ≤ |D|^{1/2}L_D(M+3)/π
and [IK, Prop 5.7]. □

The family has h(D)(2⌊M/w⌋+1) ≍ 𝔔^{1/2±o(1)} members and analytic conductors ≤ 𝔔: a thin family, and Theorem A is
Carlson's exponent 4σ(1−σ) measured in the family size. For ℓ ≠ 0 the L-functions are those of CM newforms (Fact (iii)), so
Theorem A is a zero-density theorem for CM forms in the joint level and weight aspect.

**Corollary A1 (Gaussian angles).** Let λ_k((α)) := (α/|α|)^{4k} on Z[i]. For K₀ ≥ 1 and 0.6 ≤ σ ≤ 1:
Σ_{|k|≤K₀} N(σ;t,λ_k) ≤ C(ε) K₀^{4σ(1−σ)+ε} T^{1+ε}.
(D = −4, w = 4, M = 4K₀.) Ricci's thesis (1976; Thm 2.2 of Huang–Liu–Rudnick, arXiv 1903.04005) gives
Σ_{0<k≤K₀}N(σ,T,λ_k) ≪ T K₀^{(10/3)(1−σ)}(log K₀)^B for T = o(K₀). Corollary A1 is stronger exactly when 4σ < 10/3, i.e.
σ < 5/6 (for T ≤ K₀^δ, δ small). It does not improve the sector results: Ricci's "all sectors of angle ≥ X^{−3/10}" and
Huang–Liu–Rudnick's "almost all sectors of angle ≥ X^{−3/5}" are fixed by σ ≥ 5/6, where 4σ ≥ 10/3 (at σ = 5/6 both
density exponents equal 10/3, and 1/(4σ) = 3/10, 1/(2σ) = 3/5).

**Theorem B (narrow ring classes of real quadratic orders).** Let K be real quadratic, f ≥ 1, D = f²d_K. For 0.6 ≤ σ ≤ 1,

  Σ_{χ∈Ĉl⁺(O)} N(σ;t,χ*) ≤ C(ε) D^{2σ(1−σ)+ε} T^{1+ε},

and the left side is ≤ c₀h⁺log(16·9DT²) for every σ.

*Proof.* Proposition 6 with 𝒵 = Ĉl⁺(O), ψ₀ = 1, M₀ = 0, (LS) = Lemma 5 (B = 20log²(3D), Λ = D^{1/2}). Gamma factors: for
α ≡ 1 mod^× fO_K, χ((α)) = 1 if N(α) > 0 (then (α) ∈ P⁺_{K,Z}(f)), and the (α) with N(α) < 0 form one coset of
P⁺_{K,Z}(f), on which χ is a fixed sign; so χ((α)) = sgn(N α)^a, a ∈ {0,1}, and the gamma factor is Γ_R(s+a)². □

Theorem B beats the trivial bound h⁺log D exactly when h⁺ > D^{2σ(1−σ)+ε}. This holds for every σ > 1/2 + δ when the
regulator is small, e.g. D = n² + 4 (log ε_D ≍ log D, so h⁺ ≫_ε D^{1/2−ε} by Siegel).

**Theorem C (bounded modulus).** Let K be quadratic, 𝔪 ⊂ O_K nonzero, q := min(𝔪 ∩ Z_{≥1}), and 𝒳(𝔪) the finite-order
Hecke characters of K of conductor dividing 𝔪 (all signatures if K is real). For 0.6 ≤ σ ≤ 1,

  Σ_{χ∈𝒳(𝔪)} N(σ;t,χ*) ≤ C(ε) φ(q) (q²|d_K|)^{2σ(1−σ)+ε} T^{1+ε}.

For bounded q (e.g. 𝔪 | qO_K with q fixed) this is |d_K|^{2σ(1−σ)+ε}; [C] Theorem 7 had (|d_K|N𝔪)^{3(1−σ)+ε} (K imaginary).

*Proof.* 𝔪 | qO_K. Restriction to I_K(q) maps 𝒳(𝔪) injectively (every ray class mod 𝔪 contains ideals prime to q) into
the characters of the narrow ray class group mod qO_K, and does not change χ*. For such χ and α prime to q write
χ((α)) = χ_f(α)χ_∞(α), with χ_f a character of (O_K/qO_K)^* and χ_∞(α) = 1 (K imaginary, finite order) or
sgn(α)^{a₁}sgn(α′)^{a₂} (K real). For m ∈ Z_{≥1} prime to q, r(χ)(m) := χ((m)) = χ_f(m) defines a character of (Z/qZ)^*.
If r(χ₁) = r(χ₂), then χ := χ₁χ̄₂ is Z-trivial, so χ_f(m) = 1 for all m prime to q (in particular χ_f(−1) = 1), the unit
−1 gives (−1)^{a₁+a₂} = 1, so a₁ = a₂, and for β ∈ O_q := Z + qO_K prime to q, β ≡ a (mod q), with N(β) > 0 if K is real:
χ((β)) = χ_f(a)·sgn(N β)^{a₁} = 1. Thus χ is a character of G(q) := Cl(O_q) (K imaginary) or Cl⁺(O_q) (K real), and 𝒳(𝔪)
lies in at most φ(q) cosets ψ₀Ĝ(q). Apply Proposition 6 to each coset with f = q, D = q²d_K, M₀ = 0 and (LS) from Lemma 4
(M = 0) or Lemma 5. □

The same coset argument extends Theorem A to all Hecke characters mod 𝔪 of ∞-type ≤ M (cosets of 𝒜(q²d_K, M); in
Proposition 6 allow ψ₀ of ∞-type ≤ M and take M₀ = 2M: Steps 1–4 use only |ψ₀| = 1 and the bound on the gamma shifts).

## 5. General number fields (item b)

**Proposition 7 (the primitive-ideal lemma fails in degree 3).** Let m ≥ 2 with d := m³ + 1 squarefree, K = Q(θ), θ³ = d.
Suppose that for all coefficients c supported on N𝔞 ≤ N,

  Σ_{χ∈Ĉl_K}|Σ_𝔞 c_𝔞χ(𝔞)|² ≤ Δ(N + |d_K|^{1/2}) Σ_𝔞 w(𝔞)|c_𝔞|²,

with weights w(𝔞) = 1 whenever 𝔞 lies in no nO_K, n ≥ 2. Then at N = d, Δ ≥ c d^{1/3}/log²d (c > 0 absolute, effective).

*Proof.* For 0 ≤ x ≤ m, N(θ − x) = d − x³ ∈ [1, d]; these m+1 norms are distinct and θ has coefficient 1, so the ideals
(θ − x) are distinct, principal, and lie in no nO_K. With c = 1 on them every χ gives the sum m+1, so
h_K(m+1)² ≤ Δ(d + |d_K|^{1/2})(m+1). Here 3d² ≤ |d_K| ≤ 27d². m − θ is a unit (N(m − θ) = m³ − d = −1) with
|θ − m| = 1/(θ² + θm + m²) ≥ 1/(3m² + 3), so R_K ≤ log(3m² + 3); K has no quadratic subfield, so its residue satisfies
κ_K ≫ 1/log|d_K| effectively (Stark 1974); and h_K = κ_K|d_K|^{1/2}/(2πR_K) ≫ d/log²d. Hence
Δ ≥ h_K(m+1)/(d + 6d) ≫ d^{1/3}/log²d. □

cubic.gp (bnfinit, m ≤ 60): h_K(m+1)/(d + |d_K|^{1/2}) reaches 1.03 at m = 36, 1.51 at m = 42 and 54; asymptotically
it grows like d^{1/3}/log²d. So the step "primitive ideals are sparse in every class", which drives Lemmas 2–5, is false in
degree 3: elements of the binary sublattice Z + Zθ crowd into the principal class.

**What would suffice.** Let 𝒫_K(M) := #{(𝔞,𝔞′) : [𝔞] = [𝔞′] in Cl_K, N𝔞, N𝔞′ ≤ M} and

  (P_K, Δ):  𝒫_K(M) ≤ Δ·M(M + |d_K|^{1/2})/h_K for all M ≥ 1.

**Proposition 8 (conditional; sketch).** Let K have degree n. If (P_K, Δ) holds, then for 0.6 ≤ σ ≤ 1

  Σ_{χ∈Ĉl_K} N(σ;t,χ) ≤ C(n,ε) Δ |d_K|^{2σ(1−σ)+ε} T^{n/2+1+ε}.

*Sketch.* In [C] Lemma 4 and Theorem 1 the large sieve is applied only to dyadic blocks P/2 < N𝔞 ≤ P with |c_𝔞| ≤ c₀d_r(𝔞),
and its output is then bounded by the flat sum Σ|c|² ≤ c₀²P^{1+ε}. For such blocks
Σ_χ|Σc_𝔞χ(𝔞)|² = h_KΣ_C|Σ_{𝔞∈C}c_𝔞|² ≤ h_Kc₀²max d_r²·𝒫_K(P) ≤ C(n,r,ε)c₀²P^{1+2ε}Δ(P + |d_K|^{1/2}), the same as a large
sieve with constant Δ(P + |d_K|^{1/2}). The rest is Proposition 6 with the AFE of a degree-n Hecke L-function (length
|d_K|^{1/2}(|u|+3)^{n/2}), d(𝔞) ≤ C(n,ε)N𝔞^ε, and h_K ≤ C(n)|d_K|^{1/2}log^{n−1}|d_K|. □

Status: (P_K) holds for quadratic K with Δ ≪_ε (M|D|)^ε (write 𝔞 = n𝔟, Cauchy–Schwarz over n, and Lemma 2 or 3). It is
not refuted by Proposition 7 (there the principal class adds only (m+1)² ≤ d^{2/3} pairs). For degree ≥ 3 we found no proof:
(P_K) is an L² equidistribution of ideal classes at norm ≈ |d_K|^{1/2}. Equivalently, 𝒫_K(M) = Σ_γ I(M/H(γ)), summed over
principal fractional ideals (γ) = 𝔫𝔡^{−1} with H(γ) := max(N𝔫, N𝔡) ≤ M, I(x) := #{𝔞 : N𝔞 ≤ x}; so (P_K) is a uniform
Schanuel-type count of elements of bounded height. We did not check whether the uniform counts of Masser–Vaaler or Widmer
are strong enough at height |d_K|^{1/2}. Proposition 8 is not uniform in the degree either: its constants depend on n
(d_r(𝔞) ≤ C(n,r,ε)N𝔞^ε, gamma factors).

**Remark 9 (no t-aspect version of Lemma 4).** For K = Q(i) the "optimal" hybrid mean value
Σ_{|k|≤M}∫_{−T}^{T}|Σ_{N𝔞≍N}c(𝔞)λ_k(𝔞)N𝔞^{−it}|²dt ≪ (NMT)^{o(1)}(N + MT)Σ|c(𝔞)|², which Stucky (arXiv 2008.11325, §1) notes
is unavailable, is false. Take 1 ≤ T ≤ N^{1/2}/40, M = TN^{1/2}/2, and c = 1 on the R ≥ N^{1/2}/(20T) − 1 primitive ideals
(a + i), N^{1/2} ≤ a ≤ N^{1/2}(1 + 1/(20T)). Their angles differ by ≤ 1/(20TN^{1/2}) and their log-norms by ≤ 1/(10T) + 1/N,
so for |k| ≤ M, |t| ≤ T all phases 4k·arg(a+i) − t log(a²+1) lie in an interval of length ≤ 1/4, and the left side is
≥ (2M+1)(2T)(0.96R)² ≥ 3.6MTR·Σ|c|². With R ≥ N^{1/2}/(40T) this is ≥ 0.04TN·Σ|c|², against N + MT ≤ N + T²N^{1/2}; at T = N^{1/4} the ratio is
≫ N^{1/4}. (Ricci's trivial bound MT + N·min(M,T) is attained here up to a constant.) So the thin-family large sieve needs
the t-aspect to be bounded.

## 6. Least primes

### 6.1 Unconditional: none
Every bound above carries a factor 𝔔^ε (from ζ(1+2ε) in the weight, k-th powers with k ≤ 100/ε, and d(f)^{14}), so it gives
nothing within O(1/log 𝔔) of σ = 1, where a Linnik-type argument needs a log-free density estimate. No unconditional
least-prime bound follows. Lead: in Zaman's thesis (Toronto 2017; Thm 5.1.2 and Ch. 7) the log-free density
N(1 − λ/𝓛) ≪ e^{162λ} is the stated bottleneck of the record |D|^{455}; a log-free form of Theorem A (M = 0) near σ = 1
would have exponent ≈ 2 in place of 162. Making that rigorous needs explicit constants throughout (not attempted).

### 6.2 Conditional (separate list)
- **Cor B′ (assume (L)).** Every primitive indefinite binary quadratic form Q of nonsquare discriminant D > 0 represents a
  prime p ∤ D with p ≤ C(ε)·min(D^{2B♭+ε}, (h⁺(D)log 3D)^{1/δ♭+ε}); 2B♭ = 1.7498, 1/δ♭ = 7.993.
  *Proof.* [C] Theorem 2 with Theorem B in place of [C] Theorem 1, h⁺ in place of h, (F6) for finite-order Hecke characters
  of real quadratic fields, and the dictionary for D > 0: replace Q by an equivalent form (a,b,c) with a > 0; then
  𝔞_Q = Za + Z(−b+√D)/2 is an invertible O-ideal of norm a, N(xa + y(−b+√D)/2) = a·Q(x,−y), so a prime 𝔭 ⊂ O_K of norm
  p ∤ D in the narrow class of (𝔞_QO_K)^{−1} gives p = Q(x,−y). The second bound uses the trivial zero count only. □
  Before: p(Q) ≪ D^{O(1)} (Weiss), explicitly ≪ d_K^{455}f^{684} (Zaman's Thm 7.4.1 applied to the ring class field);
  (L) with the trivial count alone gives (h⁺log D)^{7.99}, i.e. up to D^{4.0}.
- **Cor C′ (assume (L)).** For K quadratic, 𝔪, q as in Theorem C, every narrow ray class mod 𝔪 contains a degree-one prime 𝔭
  with N𝔭 ≤ C(ε)max((q²|d_K|)^{2B♭+ε}q^{1/δ♭}, (q²|d_K|^{1/2})^{5/2+ε}); for bounded q, N𝔭 ≪_q |d_K|^{1.7498}
  (was (|d_K|N𝔪)^{3+ε}, [C] Theorem 8, K imaginary). Proof: [C] Theorem 8 with Theorem C.
- **Cor A′ (assume (Hu)).** For K imaginary quadratic, a ring class C and an arc I of angles (mod 2π/w), C contains a prime
  ideal 𝔭 with arg β_𝔭 ∈ I and N𝔭 ≤ C(ε)(|D|^{1/2}/|I|)^{7/2+ε} (smooth angular weight with frequencies |ℓ| ≤ |I|^{−1}x^η,
  then Theorem A). For Q(i) this is |I| ≥ X^{−2/7+ε}: weaker than Ricci's unconditional X^{−3/10+ε}. Only the joint

## 8. Dead ends (NOGO)

- General K, degree ≥ 3: Z-primitive ideals are not sparse in a class (Proposition 7); the L² replacement (P_K) is open.
- Hybrid t-aspect version of Lemma 4: false (Remark 9).
- Huxley/Halász–Montgomery for ring class families: every off-diagonal sum Σ χχ̄′(𝔞)… has conductor ≍ |D|, so there is no
  subdivision gain; Halász–Montgomery beats the large sieve threshold |D|^{1/2} only if σ > 1.
- Fourth moment as a Class II input: the large sieve gives Σ_χ|L(1/2,χ)|⁴ ≪ |D|^{1+ε} only, which does not improve 2σ(1−σ).
- Sector problems for Gaussian primes: the new range σ < 5/6 is not the binding one (Cor A1).
- Other thin families (item e): holomorphic newforms of weight k and level 1 (≍ k forms, conductor ≍ k²) are thin, but the
  optimal large sieve provably fails there (Iwaniec–Li 2007, cited by Pascadi–Thorner), so the mechanism does not transfer;
  weight-aspect densities (e.g. arXiv 1109.1771) use the Petersson formula instead. Narrow ring class characters times
  hyperbolic Grössencharacters of real quadratic fields: the large sieve constant becomes N + D^{1/2}(M+1), larger than the
  square root of the conductor by up to log ε_D, so the family is thin only when the regulator is small.
- Unconditional least primes: blocked by the 𝔔^ε loss near σ = 1 (§6.1).
