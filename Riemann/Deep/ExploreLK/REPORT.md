## 1. Transfer (tool → node)
- Tool (d)+(b): real entire functions of exponential type σ with only real zeros (Laguerre–Pólya ∩ Paley–Wiener). Ingredients: Bernstein,
  Duffin–Schaeffer comparison functions cos σx − a, Turán-type reverse inequalities, and Landau–Kolmogorov interval/trace inequalities
  as the deterministic step.
- Node N8, small gaps: μ = liminf (γ_{n+1} − γ_n)L/2π. Record ½ under RH (Bondarenko–Heap; DPC Thm A, unconditional only via the
  multiplicity convention). Barrier: Alternative Hypothesis (AH), DPC's method stops at ½.
- Local model, in normalised units x = tL/2π: Z(T + 2πx/L) ≈ Σ_n 2n^{−1/2} cos(θ(T) + (L/2 − log n)·2πx/L). This has exponential type π, and its second-moment
  spectral measure is uniform on [0, π] (weights 1/n, uniform in log n). Under RH all zeros are real, with density 1. Its strip zero
  density (2π)/(2π) = 1 equals the real density, which makes the model plausible; it is not proved that the truncated sum is real-rooted.
  The barrier below does not need Z to be in the class: it shows that ζ's inputs do not separate the class from gap-≥δ members.
- Inputs (normalised, ⟨Z²⟩ = 1):
  - m_j := ⟨Z^{(j)2}⟩ = π^{2j}/(2j+1), unconditional (∫_T^{2T}Z^{(j)2} ~ T L^{2j+1}/(4^j(2j+1))).
  - d := the zero sum per unit length of Z′(γ)², equal to π²/3 (Gonek 1984 under RH: Σ_{γ≤T}|ζ′(ρ)|² ~ T L⁴/24π). Hence d/m_1 = 1:
    the mean of Z′² at zeros equals its mean over all t.

## 2. Statements
- S1 (exact, elementary; s1_check.py). The Duffin–Schaeffer comparison function f_δ(x) = cos πx − cos(πδ/2) has type π, real simple zeros
  at ±δ/2 + 2ℤ (gaps δ, 2 − δ) and d/m_1 = 2 sin²(πδ/2). This equals ζ's Gonek value 1 exactly at δ = ½, where the gaps are {½, 3/2},
  an AH configuration. That is the approximation-theory face of the AH barrier. f_δ has a DC term, so it does not match m_0 with the other
  moments (see §3).
- E(δ; I), the cone test. Is ζ's input vector v_Z(I) in the closed convex cone generated by v(f), over real trig polynomials f of type ≤ π
  (normalised) with only real zeros and every cyclic gap ≥ δ? The cone, not the set, is the right object:
  - all inputs are quadratic in f;
  - a positive mixture of such f, each with a random shift, is a stationary, a.s. real-rooted, type-π, gap-≥δ process whose energy-weighted
    statistics are the mixture;
  - Z's mean values are energy-weighted averages of local windows with lognormal amplitudes.
- Theorem B (barrier; certified in §3.4). v_Z(I) lies in the cone in these settings. Every column is normalised to m_0 = 1; D enters as m_0·D.
  - Density-1 columns only (s = 1: type exactly π, zero density exactly 1):
    - δ = 9/10, I = (m_0..m_6, d, D(α) at α = ¼, ½, ¾, 1, 3/2, 2), with Z's continuum values;
    - δ = 4/5, I = (the flat discrete spectrum at period N, d = m_1) for N = 24, 48, 96.
  - Columns rescaled by s ∈ [½, 1] (type sπ ≤ π, zero density s ≤ 1):
    - δ = 9/10, I = (m_0..m_J, d, D at the same α) for J = 6, 10;
    - δ = 4/5, I = (m_0..m_J, d) for J = 6, 8, 10.
  Only the listed moment sets and shift grids are covered.
  Consequence: no criterion Φ(v) ≥ 0 that is linear (or concave and 1-homogeneous, hence closed under mixtures) and valid for all
  real-rooted type-π functions with gaps ≥ δ is violated by ζ's inputs. This covers every per-gap or per-window summation and every
  Hall/BM/MO-type mean-value criterion built on these inputs. So no Bernstein/Turán/Landau–Kolmogorov argument with them and RH proves μ < δ.

### 3.6 Why it fails: decoupling of energy-weighted and unweighted statistics
- Every input above is quadratic in Z, i.e. energy-weighted. ζ's energy sits on a vanishing fraction of windows (log|ζ| has variance ~ ½ log log T).
  Local regimes therefore carry two independent weights: a length weight λ_i for zero counts and pair correlation, and an energy weight λ_iA_i².
- Heuristic, not proved: the two feasibility problems should decouple. Take the union of the regimes and give each regime a tiny weight in the
  problem it does not serve; the combined ceiling would then be ≥ min(9/10, point-process ceiling) ≥ ½. The last step uses AH mimicry of the
  band-limited pair-correlation data (Lagarias–Rodgers 1907.03391, 1905.12123).
- Reviewer objections, accepted:
  - "tiny weights" gives approximation, not exact joint matching;
  - density-1 regimes are needed (the rescaled ones have density s < 1);
  - type-π realisations of the AH processes were not built;
  - mimicry covers only band-limited statistics.
  So this is a mechanism and a conjectural ceiling (≥ ½), not a theorem.
- What B does show: on these inputs the method class is blind below 9/10. Inputs outside the class carry the small-gap information that MO,
  CGG and DPC use: mollified or twisted moments (|ζM|² ≈ 1 removes the amplitude freedom). This report does not prove that every improvement needs them.


## 4. Adversarial (iv)
- The class assumes RH (all zeros real). Davenport–Heilbronn has off-line zeros (ExploreHelio/results/dh_zeros.json: 9 below 420), so it is outside
  the class, and a positive-definite model without real-rootedness is outside it too. The barrier is the converse statement: ζ's structural inputs
  do not single ζ out against hard-core models with all gaps ≥ 4/5 (full period-N spectrum) or ≥ 9/10 (listed inputs), which are not ζ. Nothing in this report claims a property of ζ beyond its inputs.
- S1 is a property of an abstract function. It meets ζ only through Gonek's ratio, at the AH spacing; it is a reading of the AH barrier, not a new fact about ζ.
