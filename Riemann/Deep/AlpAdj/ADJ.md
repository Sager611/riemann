## 4. The conclusions: AdZero is Bloch–Kato, OrdZero is Greenberg fixed-weight ordinary (OZ:14-72)
- AdZero V ρ (OZ:68-72): ∀ form P with IsForm ρ P, ∀ R with IsAdExt ρ P R, ∀ z ∈ Z¹(Γ, R) with Af.IsBK l (R∘toGS) (z∘toGS): z is a coboundary.
  - IsAdExt (AV/WeakShimuraTheory/EigenbasisLifts/IsTanZero.lean:31-34): R(g) = ad ρ(g) on G₀, R(c)X = −P⁻¹XᵀP: the Clozel–Harris–Taylor adjoint ad~ρ of G_{L+,S} (scalars = the character η_{L/L+}).
  - IsBK (AV/AutomorphicForms/BlochKatoSelmerVanishes.lean:135-140): away: at every finite w ∤ l, z|I_w is a coboundary (unramified); above: at every place over l, z|G_w ∈ Loc.finiteCocycles = {c ∈ Z¹ : c ⊗ 1 is a coboundary in V ⊗ B_cris} (AV/PadicHodgeTheory/FiniteCohomology.lean:112-114) = Bloch–Kato H¹_f.
  - So AdZero ⟺ H¹_f(L+, ad~ρ) = 0 (≅ H¹_f(L, ad ρ)^{c-inv}): the Bloch–Kato adjoint Selmer group, NOT an ordinary Selmer group. Same object as Allen 2016, Newton–Thorne, Thorne 2022 ('H¹_f(F+, ad r)').
- OrdZero r ρ ψ (OZ:62-64): same with the condition OrdCoc r ρ ψ z (OZ:31-34): ine: z = 0 on Ip u (u ∈ St); ord: OrdAt (OZ:22-27) at each v | l: after conjugating ρ|G_w to upper triangular with diagonal ψ v, z − (coboundary of some X) is upper triangular on G_w with diagonal entries 0 on inertia. = Greenberg's FIXED-WEIGHT ordinary condition (graded pieces unramified); no condition at v0 (harmless for pure ρ: H¹(I_{v0}, ad)^{Frob} ≅ ad^{Frob = p}... = 0 when Frobenius eigenvalue ratios have absolute value 1).
- DenseThresholdMainCase concludes OrdZero (no Par); AdjointLiftingTheorem concludes AdZero (with Par). The residual datum r and the ring B enter only the HYPOTHESES (x.IsRep, x.Arith, flag, Free, Par); the conclusions depend only on (V, ρ).
