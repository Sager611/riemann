## 2. Statements (proofs here; tests in §3–§4)
- **P1 (transversality, exact).** If H_{t_c} has a double real zero a, then near (a, t_c) Weierstrass preparation gives H_t(z) = E(z,t)·((z − c(t))² − u(t)), E(a,t_c) ≠ 0, u analytic, and **du/dt(t_c) = 2**. Proof: at z = c, t = t_c the quadratic factor and its z-derivative vanish, so ∂_tH = −E·u̇ while −∂²_zH = −2E. (No zero ODE needed.) In zero coordinates u̇ = 2 + w(F(c+w) − F(c−w)), w = (z₂ − z₁)/2, F = 2Σ_{j≠1,2} 1/(z − z_j).
  Consequence: the collision face {u = 0} of any block in configuration space is crossed transversally (forward in t: complex → real); it meets no invariant set; a double zero at a given time is a codimension-one coincidence t_c(k) = t, not an invariant object.
- **P2 (continuable indices are blind).** Let D = D̄ be a block, isolating for all t in an interval through t_c, containing one zero pair and one zero of H_t′. By continuation its Conley index for the gradient-descent flow of |H_t|² is constant; with entrance boundary it is the pointed 0-sphere D ∪ {∗} ≃ S⁰, also Z/2-equivariantly (D G-contracts to its real centre). For ẋ = H_t(x) on D ∩ R the index is trivial iff H_t has the same sign at both ends — true for a real and for a conjugate pair. The Morse decomposition that tells them apart (two fixed minima + fixed saddle vs one free Z/2-orbit of minima + fixed saddle) degenerates at t_c: both minima and the saddle merge (H = H′ = 0). So: visible ⇒ not continuable; continuable ⇒ invisible.
- **P3 (all that Ważewski certifies).** On R: an isolating [a, b] for ẋ = H_t has nontrivial index iff H_t(a)H_t(b) < 0, and Ważewski then gives a zero — a sign change (Gram/Turing counting, Hardy–Selberg). On C: Poincaré–Hopf for the gradient field 2H·conj(H′) gives χ(index) = wind_∂D(H) − wind_∂D(H′) — the argument principle for H/H′ (Speiser, Levinson–Montgomery). A block certifies real zeros only when it isolates an odd number of them; a real pair inside one block (trivial index) is invisible and is certified only by splitting it with a sign change, i.e. by locating it (finite verification); a double zero gives no sign change at all.
- **P4 (forward block = mesh monotonicity).** For a finite real-rooted configuration (polynomial heat flow) with all gaps ≥ m: S_k := Σ_{j≠k,k+1} 1/((x_{k+1} − x_j)(x_k − x_j)) ≤ (2/m²)Σ_{j≥1} 1/(j(j+1)) = 2/m², with equality only in the infinite-lattice limit; so the minimal gap obeys ġ = 4/g − 2gS ≥ 0 (lower Dini derivative of the minimum ≥ 0; the infinite case would need uniform-in-index control, and is vacuous for ζ anyway). The block {all gaps ≥ m} is forward invariant and the lattice turns its exit inequality into an equality: no growth rate. For ζ the global mesh is 0 (density log x/4π → ∞), so the bound is vacuous; window versions leak through the window ends.
- **P5 (backward block = Lehmer-pair comparison).** To first order in u and in the far field (frozen far zeros give u̇ = 2 − 4uΣ_far((c − z_j)² − u)⁻¹), the constant-S model u̇ = 2 − 4S u gives the exit time through {u = 0}: t_c ≈ −(1/(4S))·log(1/(1 − 2S u₀)), S = Σ_far 1/(c − z_j)² (Csordas–Smith–Varga's Lehmer-pair inequality).
