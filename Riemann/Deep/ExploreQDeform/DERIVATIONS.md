# explore16 derivations (q-deformation → RH tree)

Normalisation (GORZ): 8 ξ(1/2 + z) = Σ γ(n) z^{2n}/n!, F(w) = Σ γ(n) w^n/n! = 8 ξ(1/2 + √w); zeros w_ρ = (ρ − 1/2)²; RH ⟺ F ∈ LP (all zeros negative) ⟺ every J^{d,n}(X) = Σ_j C(d,j) γ(n+j) X^j is hyperbolic (Pólya–Schur).

## 1. Laguerre / theta family (T1)
P_s(X) = Σ_j C(d,j) e^{s j²} γ(n+j) X^j.
- e^{−t j²} (t ≥ 0) is a multiplier sequence (Laguerre), so {s : P_s hyperbolic} = (−∞, s*(d,n)]; RH ⟺ s*(d,n) ≥ 0 for all d, n.
- Theta form: q = e^{−τ}, q^{j²} = E[e^{i j √(2τ) G}] (G standard normal), so (P ⊙ q^{j²})(X) = E[P(X e^{i√(2τ)G})]; for F: F_q(z²) = 8 E[ξ(1/2 + z e^{i√(τ/2) G})], a Gaussian average of ξ over rotations about s = 1/2. The kernel is the Jacobi theta function, i.e. the weight whose orthogonal polynomials on the unit circle are the Rogers–Szegő polynomials.
- Cylinder heat flow: X = −e^v, R(v) = P(−e^v); multiplier e^{−τ j²} ⇔ R_τ = e^{−τ ∂_v²} R (backward heat, 2πi-periodic in v). Zeros of R_τ: v̇_k = R''/R' = d + Σ_{j≠k} coth((v_k − v_j)/2) [R = C e^{dv/2} Π_j sinh((v − v_j)/2)]. A conjugate pair σ ± iβ: Im v̇ = −cot β, so β² ≈ β₀² − 2τ (de Bruijn); the exact finite form is Piotrowski–Sorensen–White 1802.02641 Thm 2.5: zeros in |arg(−X)| ≤ Δ go to |arg(−X)| ≤ Δ', cos Δ' = min(1, cos Δ / q) (sharp in degree 2: 1 + 2q cos Δ X + q⁴X² has cos(arg) = cos Δ / q), and their periodic-strip corollary (exp(−α²D²/2) is periodic-strip decreasing on exponential polynomials, A* = arccos(min{1, e^{α²/2} cos A})). Real neighbours x_j: Im coth((x + iβ)/2) = −sin β/(cosh x − cos β) < 0 — the screening term of explore15 (S = Σ 1/(γ − γ_j)² ↔ Σ 2/x_j²).
- Jensen truncation vs Gaussian damping: J^d(F)(X/d) = F ⊙ λ, λ_j = d!/((d−j)! d^j) = Π_{i<j}(1 − i/d) = exp(−j(j−1)/(2d) − Σ_{m≥2} Σ_{i<j} (i/d)^m/m), leading Gaussian τ_d = 1/(2d). PSW threshold q = e^{−τ_d} ≤ cos Δ ⇔ d ≤ 1/(−2 log cos Δ) = Δ^{−2} − 1/6 + O(Δ²); Chasse: 1/sin²Δ = Δ^{−2} + 1/3 + O(Δ²). Same leading order, but no operator factorisation: the residual λ_j e^{j(j−1)/(2cd)} is not a multiplier sequence (q5: Σ C(d,j)·residual·X^j has non-real zeros for c = 1 at every d ≥ 3, for c = 2 from d = 6, c = 4 from d = 32).
- Jensen–Laguerre constant Λ_JL := −inf_{d,n} s*(d,n). Λ_JL ≥ 0: F ⊙ e^{εk²} (ε > 0) has divergent Taylor series, hence is not LP, hence some J^{d,n} ⊙ e^{εj²} is not hyperbolic. Λ_JL ≤ −log cos Δ₀ by PSW (F = limit of its real partial products, zeros in the sector), Δ₀ = sup_ρ |arg(−w_ρ)| ≤ atan(2aT/(T² − a²)), a = 0.37338196661320752 (Lean-checked half-plane), T = 3·10^12 (RH verified): Δ₀ = 2.48921311075·10⁻¹³, −log cos Δ₀ = 3.09809·10⁻²⁶. RH ⟺ Λ_JL = 0. 1/(2·3.09809·10⁻²⁶) = 1.61389709728·10²⁵ = 1/sin²Δ₀ to 12 digits: the N6 record (Chasse), same information.

## 2. q-binomial families (T2)
- q = e^{−ε}: [k]_q/k = 1 − ε(k−1)/2 + O(ε²), so log([d j]_q / C(d,j)) = −(ε/2) j (d − j) + O(ε²) = −(εd/2) j + (ε/2) j² + O(ε²). Hence the Rogers–Szegő–Jensen polynomial RS_q = Σ [d j]_q γ(n+j) X^j = (J^{d,n} ⊙ e^{+ε j²/2})(e^{−εd/2} X)·(1 + O(ε²)): anti-damping; real-rootedness is lost at ε_RS ≈ 2 s*(d,n) (measured ratio ε_RS/(2s*) = 1.005–1.026, Xi and DH). In the GORZ scaling the Gaussian coefficient δ² becomes δ² − ε/2; when negative, the Hermite limit is rotated (zeros on a tangent line to a circle) — this is the local form of Rogers–Szegő's circle.
- Exact Rogers–Szegő: H_n(cos θ | q) = Σ_k [n k]_q e^{i(n−2k)θ} = e^{inθ} RS_n(e^{−2iθ}); the circle zeros come from q-Hermite orthogonality (2x H_n = H_{n+1} + (1 − q^n) H_{n−1}). For non-constant γ there is no recurrence in d: the reversed Jensen polynomials x^d J^d(1/x) = F(D) x^d form an Appell sequence; the only orthogonal Appell sequence is Hermite (Angelesco–Shohat), the only orthogonal q-Appell ones are Al-Salam–Carlitz (Al-Salam 1967; generating function (t;q)_∞(at;q)_∞/(xt;q)_∞, geometric zeros), so the GORZ Hermite limit is the only orthogonality available.
- Schur–Szegő family: (−X;q)_d = Σ [d k]_q q^{k(k−1)/2} X^k has negative zeros, so by Schur's composition theorem SS_q = Σ [d k]_q q^{k(k−1)/2} γ(n+k) X^k is real-rooted for all q ∈ [0, 1] whenever J^{d,n} is (190/190 checks). First order: log([d k]_q q^{k(k−1)/2}/C(d,k)) = −(ε/2) k (d − 1) + O(ε²), a pure rescaling.
- Dimitrov–Shapiro (2606.17864): B_q(Σ a_k z^k/k!) = Σ a_k q^{k(k−1)/2} (1 − q)^k/(q;q)_k z^k preserves LP, B_q f → f as q → 1. For F: b_k = γ(k) q^{k(k−1)/2}(1 − q)^k/(q;q)_k, b_k²/(b_{k−1} b_{k+1}) = T_k q^{−1}(1 − q^{k+1})/(1 − q^k) ≥ T_k/q, T_k = γ(k)²/(γ(k−1)γ(k+1)) ≥ 1 (Turán; Csordas–Norfolk–Varga). Hutchinson ⇒ B_q F ∈ LP for every q ≤ 1/4, for any positive Turán sequence (DH too, T_k > 1 checked for k ≤ 139). RH ⟺ B_q F ∈ LP for all q < 1 (Hurwitz). First order B_q ≈ e^{−εk²/2}·e^{+εk²/4} = e^{−εk²/4}: net damping, weaker than LP.

## 3. Jensen polynomials as Laguerre mixtures (side identity, q = 1)
Normalise Φ by ξ(1/2 + z) = ∫_ℝ Φ(u) cosh(zu) du, i.e. Φ(u) = 2 Σ_n (2π²n⁴e^{9u/2} − 3πn²e^{5u/2}) e^{−πn²e^{2u}} > 0. Then γ(n) = 8 n! b_n/(2n)!, b_m = ∫_ℝ Φ(u) u^{2m} du; m!/(2m)! = 1/(4^m (1/2)_m), Σ_j C(d,j) y^j/(α+1)_j = (d!/(α+1)_d) L_d^{(α)}(−y). Hence
J^{d,n}(X) = 8 d! / (4^n (1/2)_n (n + 1/2)_d) · ∫ Φ(u) u^{2n} L_d^{(n − 1/2)}(−u² X/4) du,
a positive mixture of dilated Laguerre polynomials (orthogonal, real-rooted). Checked numerically (q6: γ(0)/8 = ξ(1/2) = 0.497120778188314; relative error ≤ 10⁻⁴⁰ at (d,n,X) = (3,2,−0.7), (4,1,−2.5), (5,3,−11)). Dilations over u ∈ (0, ∞) have no common interlacer, so hyperbolicity does not follow; probably classical (novelty not checked; not claimed).

## 4. DAHA 'RH' normalisation (T3)
q,t-Catalan C_n(q,t) = Σ_{Dyck} q^{area} t^{dinv} (symmetric). H0(q,t) = Σ_{q^a t^b ∈ C_n} q^{δ−a} t^b, δ = n(n−1)/2 (trefoil: 1 + qt; Cherednik's trefoil zeta (1 + q t² + a q t)/(1 − t) at a = 0 ✓). L(q,t) = H0(qt, t); FE (q t²)^δ L(q, 1/(qt)) = L. P_q(u) = L(q, u/√q) = Σ q^{(δ−a−b)/2} u^{δ−a+b}; RH ⟺ all 2δ zeros on |u| = 1; ω = 1/q (Cherednik: 'q = 1/ϖ₀').
- T(3,4): P_q = 1 + u² + √q u³ + u⁴ + u⁶, u^{−3}P = 8c³ − 4c + √q (c = cos θ); RH ⟺ √q < 8/(3√6) ⟺ q < 32/27 = 1.185185 (q3 ✓).
- q → 0: P_0 = (1 − u^{2δ+2})/(1 − u²) (Cherednik's S⁰), simple roots of unity. q = 1: P_1(u) = u^δ C_n(u^{−1}, u) = [2n n]_u/[n+1]_u (MacMahon q-Catalan), cyclotomic.
- Mechanism: the FE pairs u ↔ 1/ū, so a simple zero on the circle stays there until it collides with a neighbour (the zeta_offline_pair argument of R46); the RH set contains neighbourhoods of the two cyclotomic points; q_c is the first collision. At q = 2…5 (possible field sizes) it fails for every T(n, n+1), n ≥ 3. Caveat: this L(q,t) is the a = 0 specialisation; the Galkin–Stöhr zeta of the singularity is L(Γ,q,t) = Ĥ(q,t,a ↦ −t/q)|_{q↦qt} (trefoil: 1 − t + q t², on the circle for q ≥ 1/4), which needs the full a-dependence and was not computed.
