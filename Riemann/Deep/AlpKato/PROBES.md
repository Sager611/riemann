## P2 (LemmaK, probe b): kBound against published bounds (code/p2_bounds.py, logs/p2_bounds.log)
- CK is existential (DTC/KFinal.lean:11), so the question is the SHAPE log #H² ≤ (2D)^{(2en)^C}, i.e. log log #H² ≤ (2en)^C log 2D.
- Bayer-Fluckiger–Emery–Houriet 2014 (arXiv:1406.5953), verbatim from the full text: "for a finite abelian group A let us write card_ℓ(A) for the order of A/B, where B ⊂ A is the subgroup generated by elements of order ≤ ℓ. Theorem 1.1. Let F ≠ Q be a number field of degree d and with discriminant D_F. Then for any n ≥ 2 we have log card_ℓ K_n(O_F)_tors ≤ (2n+1)^{71n⁴d³} · d^{293n⁵d⁵} · |D_F|^{528n⁵d⁴}, where ℓ = max(d+1, 2n+2)." (exponents rendered from the PDF's superscript line). Here n_BEH = m = 2e, d = n, u = 2en, and F := log of the right side = 71m⁴d³ log(2m+1) + 293m⁵d⁵ log d + 528m⁵d⁴ log D: log log card_ℓ ≤ F ≤ 892·u⁶·log 2D (m⁴d³ ≤ u⁴, m⁵d⁵ = u⁵, m⁵d⁴ ≤ u⁵, log(2m+1) ≤ u, log d ≤ u, log 2D > 1). Small-torsion loss: #A ≤ card_ℓ(A)·ℓ^{rank A} and rank H²(O_L[1/l], Z_l(e+1)) ≤ dim H²(O_L[1/l], μ_l) = r_l(Pic O_L[1/l]) + s − 1 ≤ log₂ h_L + n (μ_l ⊂ L), h_L ≤ √D(1 + log √D)^{n−1}. Grid check e ≤ 40, n ≤ 80, log D ∈ [log 3, 10⁶]: BEH + loss ≤ kBound(C) for every C ≥ 10 (fails on the grid for C ≤ 9); analytically C = 11 (u ≥ 4, 4⁵ > 893). So BEH ⇒ ∃ CK, LemmaK CK, given H² ≅ K_{2e}(O_L) ⊗ Z_l.
- Soulé 2003 does NOT imply it: Prop. 4 (i) log log k(m) ≤ 2^20 m⁴ log m n^{4n} √D log(D)^{n−1} is weaker than kBound(24) for n = 4 once log D > 12.85, for n ≥ 6 essentially always; and his Thm 3 covers only p ≥ max(4(e+1)−1, n+2), while LemmaK concerns only l ≤ n+1 (P4). Imaginary quadratic: Prop. 4 (iii) log log k(m) ≤ 1120 m⁴ log m log D has the kBound shape.
- Emery 2013 (arXiv:1303.6132, Thm 1.3): log #(K₂(O_F) ⊗ Z[1/6w_F]) ≤ C(d)D² log^{d−1} D, F totally imaginary: e = 1 only and it inverts exactly the l with μ_l ⊂ F, so it does not cover LemmaK either.
- Actual sizes are tiny: K₂(Z[i]) = K₂(Z[ζ₃]) = 0 (Tate), so H²(Z[i,1/2], Z₂(2)) = H²(Z[ζ₃,1/3], Z₃(2)) = 0; kBound is not tested by any table entry.

## P4 (LemmaK, probe c): uniformity in l — LemmaK lives entirely at small primes (logs/p5_twist_small_l.log)
