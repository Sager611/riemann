**Theorem A (answer below the diagonal).** Let 2 ≤ k < m < n and m + k < n. Then
⟨r_n, r_m, r_k⟩ = S_n if and only if

**Theorem B (the whole line n = m + k + 1, 2 ≤ k < m, any parity).**
1. The orbits of G are O_c = {x : x ≡ ±c (mod g)}, 0 ≤ c ≤ g/2; there are ⌊g/2⌋ + 1 of them.

```lean
/-- The underlying function of the prefix reversal r_i on Fin n. -/
def revFun (n i : ℕ) (x : Fin n) : Fin n :=
  if h : x.val < i ∧ i ≤ n then ⟨i - 1 - x.val, by omega⟩ else x

/-- The prefix reversal r_i as a permutation of Fin n. -/
def rev (n i : ℕ) : Perm (Fin n) where
  toFun := revFun n i
  invFun := revFun n i
  left_inv := revFun_revFun n i
  right_inv := revFun_revFun n i

/-- G(n; m, k) = ⟨r_n, r_m, r_k⟩ ≤ S_n. -/
def G (n m k : ℕ) : Subgroup (Perm (Fin n)) :=
  Subgroup.closure {rev n n, rev n m, rev n k}

/-- The underlying permutations of the q-gon action. -/
def dihedralPermFun (q : ℕ) : DihedralGroup q → Perm (ZMod q)
  | r i => Equiv.addRight i
  | sr i => (Equiv.neg (ZMod q)).trans (Equiv.subRight i)

/-- D_{2q} = DihedralGroup q acting on the vertices ZMod q of the q-gon:
r i : x ↦ x + i (rotations), sr i : x ↦ -x - i (reflections). -/
def dihedralPerm (q : ℕ) : DihedralGroup q →* Perm (ZMod q) where
  toFun := dihedralPermFun q
  map_one' := by
    rw [DihedralGroup.one_def]; ext x; rw [dihedralPermFun_r, Perm.one_apply, add_zero]
  map_mul' := by
    rintro (i | i) (j | j) <;> ext x <;>
      simp only [r_mul_r, r_mul_sr, sr_mul_r, sr_mul_sr, Perm.mul_apply, dihedralPermFun_r,
        dihedralPermFun_sr] <;> ring

/-- DihedralGroup q acting on the base ZMod q → DihedralGroup α by f ↦ f ∘ (d⁻¹ · ). -/
def wreathAct (α q : ℕ) : DihedralGroup q →* MulAut (ZMod q → DihedralGroup α) where
  toFun d :=
    { toFun := fun f i => f ((dihedralPerm q d)⁻¹ i)
      invFun := fun f i => f (dihedralPerm q d i)
      left_inv := fun f => by funext i; simp
      right_inv := fun f => by funext i; simp
      map_mul' := fun f g => rfl }
  map_one' := by ext f i; simp
  map_mul' := by intro a b; ext f i; simp [mul_inv_rev, Perm.mul_apply]

/-- The wreath product D_{2α} ≀ D_{2q} for the q-gon action. -/
abbrev Wreath (α q : ℕ) := (ZMod q → DihedralGroup α) ⋊[wreathAct α q] DihedralGroup q

/-- The imprimitive action of D_{2α} ≀ D_{2q} on ZMod q × ZMod α:
(f, d) · (i, u) = (d i, f (d i) u). -/
def wreathPerm (α q : ℕ) : Wreath α q →* Perm (ZMod q × ZMod α) where
  toFun w := Equiv.prodShear (dihedralPerm q w.right) (fun i => dihedralPerm α (w.left (dihedralPerm q w.right i)))
  map_one' := by
    ext ⟨i, u⟩ <;> simp [Equiv.prodShear]
  map_mul' := by
    intro a b
    ext ⟨i, u⟩ <;> simp [Equiv.prodShear, SemidirectProduct.mul_left, SemidirectProduct.mul_right,
      wreathAct_apply, Perm.mul_apply]
```

```
Prefix reversals are a classical family of involutions arising in permutation sorting and the study of Cayley graphs. Let \(S_n\) denote the symmetric group on \(\{1,\ldots,n\}\). For each \(2\le i\le n\), define the prefix reversal \(r_i\in S_n\) by
\[
r_i(j)=
\begin{cases}
i+1-j, & 1\le j\le i,\\
j, & i<j\le n.
\end{cases}
\]
Equivalently,
\[
r_i=\prod_{j=1}^{\lfloor i/2\rfloor}(j\;\;i+1-j).
\]
Thus, \(r_i\) reverses the first \(i\) positions and fixes all remaining positions. The problem of sorting a permutation using as few prefix reversals as possible has attracted considerable attention. Gates and Papadimitriou \cite{William1979} established bounds on the maximum number of reversals required, and Chitturi et al. \cite{Chitturi2009} subsequently improved the upper bound. Bulteau, Fertin, and Rusu \cite{Laurent2015} proved that finding an optimal sorting sequence is NP-hard. These results concern the length of a sorting sequence when all prefix reversal lengths are available.
[...]
Since every prefix reversal of length less than \(n\) fixes the position \(n\), any generating triple must contain \(r_n\). The problem therefore reduces to determining when
\[
G_{n}:=\langle r_n,r_m,r_k\rangle=S_n,
\qquad 2\le k<m<n.
[...]
\begin{theorem}\label{m+k<n}
    If $m+k<n-1$, then $\left \langle r_{n},r_{m},r_{k} \right \rangle <S_{n}$. Moreover, if n is even and $m+k<n$, then $\left \langle r_{n},r_{m},r_{k} \right \rangle <S_{n}$.
\end{theorem}

```
