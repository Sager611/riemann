## 0. Inputs and notation

- **(L)** Liu, arXiv 2610.26835, Thm `vi:thm:main` (source `.scratch/liu2/number_fields_v2.tex`, l. 10625).
  For every number field K and every finite-order Hecke character χ of K, L_K(s,χ) ≠ 0 for
  Re s > B♭. The pole of the principal character is allowed.
  B♭ = 0.874886647039964… is the root of 133488B⁴−376596B³+384534B²−167541B+26231 near 0.8749.
  Put δ♭ := 1−B♭ = 0.1251133529600358…, so 1/δ♭ = 7.992751983230945….
- **(O)** OpenAI, *The Quasi-Riemann Hypothesis*, 30 Sep 2026, Thm 1.1. Every Dirichlet
  L-function, including ζ, is zero-free for Re s > 7/8. This is also a special case of (L).
- **(H)** Huxley, Acta Arith. 26 (1975) 435–444, in the q-aspect form quoted in [CGL, p. 3].
  For 1/2 ≤ σ ≤ 1 and T ≥ 2: Σ_{χ mod q} N(σ,T,χ) ≪ (qT)^{12(1−σ)/5}(log qT)^{c}.
- **(CGL)** Chen–Gupta–Li, arXiv 2507.08296v2, Thm 1.2 ("in all cases"). For 1/2 < σ < 1, T ≥ 2
  and ε > 0: Σ_{χ mod q} N(σ,T,χ) ≪_ε (qT)^{ε}(q^{7/3(1−σ)}T^{2(1−σ)} + (qT)^{30/13(1−σ)}).
  Here N(σ,T,χ) counts zeros β+iγ of L(s,χ) with β ≥ σ and |γ| ≤ T, with multiplicity.
  *Uniformity and effectivity* (source checked, 2026-10-20). CGL state the bound as (qT)^{o(1)}(…),
  which by their ⪅ convention (§1, l. 270 of the source) means ≤ C(ε)(qT)^ε(…) for qT ≥ Q(ε), with
  C(ε), Q(ε) depending only on ε: uniform in q and T. For qT < Q(ε), (Z) bounds the left side by
  O_ε(1), so the bound holds for all q, T after enlarging C(ε). The source never says "effective" or
  "ineffective" (rg: 0 hits). Its proof (Guth–Maynard large values, Heath-Brown's double zeta sums,
  zero detection) uses no Siegel-zero or other ineffective input ("exceptional" occurs only in the
  introduction), so C(ε), Q(ε) are expected to be effective, but this is not asserted or checked.
- **(Z)** Zero count [Iwaniec–Kowalski, Prop. 5.7]. Let χ be a primitive Hecke character of E and
  A(χ) = Δ_E·N𝔣_χ. Then #{ρ : |Im ρ − t| ≤ 1} ≤ c₀(log A(χ) + n_E log(|t|+3)), with c₀ absolute.
- **(FE)** Hecke functional equation: Λ(s,χ) = A(χ)^{s/2}γ_χ(s)L(s,χ) = W(χ)Λ(1−s,χ̄), where γ_χ
  is a product of n_E factors Γ_R(s), Γ_R(s+1), Γ_C(s). Nontrivial zeros are symmetric under
  ρ ↦ 1−ρ̄. A half-plane Re s > 1−δ is therefore equivalent to δ ≤ Re ρ ≤ 1−δ for all nontrivial ρ.
- **(M)** Minkowski: Δ_K ≥ (π/4)^n(n^n/n!)², so n_K ≤ 2 log Δ_K for K ≠ ℚ. Also n_K ≤ 2 log(3Δ_K) always.
- **(CD)** Conductor–discriminant formula. For L/E abelian with group H:
  Σ_{χ∈Ĥ} log A(χ) = log Δ_L and |H|·n_E = n_L.
- **(BT)** Brun–Titchmarsh (Montgomery–Vaughan): π(y;q,a) ≤ 2y/(φ(q) log(y/q)) for y > q.

**Test function.** Fix f ∈ C_c^∞((1/2,1)) with f ≥ 0 and f ≢ 0. Put ‖f‖ = max f and
Φ(s) = ∫₀^∞ f(t)t^{s−1}dt. Φ is entire with Φ(1) > 0. Six integrations by parts give
|Φ(σ+it)| ≤ C_f(1+|t|)^{−6} on −1 ≤ σ ≤ 2. Constants C, c below depend only on this fixed f,
so they are absolute and effective unless a subscript says otherwise.

## 1. Uniform smooth explicit formula

**Lemma 1.** Let χ be a primitive finite-order Hecke character of a number field E (χ = 1 is
allowed). Suppose L(s,χ) has no zero with Re s > 1−δ, where 0 < δ ≤ 1/2. Then for x ≥ 1,

  S_χ(x) := Σ_𝔞 Λ_E(𝔞)χ(𝔞)f(N𝔞/x) = 1_{χ=1}·xΦ(1) − Σ_ρ x^ρΦ(ρ) + R,
  with |R| ≤ C(log A(χ)+n_E) and Σ_ρ |x^ρΦ(ρ)| ≤ C x^{1−δ}(log A(χ)+n_E).

*Proof.* Mellin inversion on Re s = 2 gives S_χ(x) = (2πi)^{−1}∫_{(2)}(−L'/L)(s,χ)x^sΦ(s)ds.
Shift the contour to Re s = −1/2. Choose horizontal segments at heights T_k → ∞ at distance
≫ 1/(log A + n_E log T_k) from all zeros; this is possible by (Z). On these segments
|L'/L| ≪ (log A + n_E log T_k)², and the decay of Φ makes their contribution vanish. This is
the argument of OpenAI's primitive-roots preprint, Lemma 9.2, done there for ζ_E; the Hecke case
is identical.

The residues crossed are:
- xΦ(1) at s = 1 when χ = 1;
- −x^ρΦ(ρ) at each nontrivial zero ρ;
- −m₀Φ(0) at s = 0, where 0 ≤ m₀ ≤ n_E and Φ(0) ≤ 2‖f‖.

The trivial zeros lie at nonpositive integers, so no other residue occurs. On Re s = −1/2, (FE) gives

  L'/L(s,χ) = −L'/L(1−s,χ̄) − log A − γ'_χ/γ_χ(s) − γ'_χ̄/γ_χ̄(1−s).

Here |L'/L(3/2−it,χ̄)| ≤ n_E·(−ζ'/ζ)(3/2), and the digamma terms are O(n_E log(|t|+3)) because their
arguments stay at distance ≥ 1/4 from the poles. So the left integral is ≤ C x^{−1/2}(log A+n_E).
Finally |x^ρ| ≤ x^{1−δ}, and by (Z),
Σ_ρ|Φ(ρ)| ≤ C_f Σ_{k∈ℤ}(1+|k|)^{−6}c₀(log A+n_E log(|k|+3)) ≤ C(log A+n_E). □

## 2. Main new result: Linnik's exponent is at most 7/3

**Proposition 2.** Assume:
- (i) every Dirichlet L-function is zero-free on Re s > 1−δ, for some fixed δ ∈ (0,1/2];
- (ii) there are A ≥ 2 and A' ∈ [0,3] such that for 1/2 ≤ σ ≤ 1−δ, T ≥ 1 and ε > 0:
  N(σ,T;q) := Σ_{χ mod q} N(σ,T,χ) ≤ C_ε(qT)^ε q^{A(1−σ)}T^{A'(1−σ)}.

Then for every η > 0 there are q₀(η) and c = c(η,δ) > 0, effective in terms of δ, η and the
constants C_ε of (ii), with the following property.
For q ≥ q₀, (a,q) = 1 and x ≥ q^{A+η},

  S(x;q,a) := Σ_{n≡a (q)} Λ(n)f(n/x) = (xΦ(1)/φ(q))·(1 + O_η(q^{−c})).

Consequently the least prime P(a,q) ≡ a (mod q) satisfies P(a,q) ≤ C_η q^{A+η} for all q ≥ 2.

*Proof.* By orthogonality, S = φ(q)^{−1}Σ_{χ mod q}χ̄(a)Σ_nΛ(n)χ(n)f(n/x).

Replace each χ by its primitive χ*, of modulus q* | q. This changes each inner sum by at most
‖f‖Σ_{p|q}Σ_{p^k≤x}log p ≤ ‖f‖ω(q)log x. Lemma 1, with E = ℚ, A(χ*) = q* ≤ q and hypothesis (i), gives

  S = xΦ(1)/φ(q) − φ(q)^{−1}Σ_χ χ̄(a)Σ_{ρ∈Z(χ*)}x^ρΦ(ρ) + O(log q·log x).

*Bounding the zero sum.* Let Z(T) := Σ_χΣ_{|γ|≤T}x^β. Each zero satisfies
x^β ≤ x^{1/2} + 1_{β≥1/2}∫_{1/2}^{β}x^σ log x dσ. Hypothesis (i) gives N(σ,T;q) = 0 for σ > 1−δ, so

  Z(T) ≤ x^{1/2}N(0,T;q) + log x·∫_{1/2}^{1−δ}x^σ N(σ,T;q)dσ.

By (Z), N(0,T;q) ≤ CqT log(3qT). We may assume η ≤ 1: the conclusion for η implies it for every
η' ≥ η. Take ε := ηδ/4 ≤ 1/8 in (ii); ε < 2 is needed below for the k-sum to converge. For 1/2 ≤ σ ≤ 1−δ we have 1−σ ≥ δ.
Writing x = q^{A+η}y with y ≥ 1,

  x^σN(σ,T;q) ≤ C_ε x(qT)^ε T^{3}(q^A/x)^{1−σ} ≤ C_ε x(qT)^ε T³(q^{−η}/y)^δ.

Since y^{−δ}log(q^{A+η}y) ≪_δ log q, this gives

  Z(T)/x ≤ Cq log(3qT)T x^{−1/2} + C_{η,δ}T^{3+ε}q^{−3ηδ/4}log q.

Then Σ_χΣ_ρ x^β|Φ(ρ)| ≤ Σ_{k≥0}C_f(1+k)^{−6}Z(k+1). Since ε ≤ 1/8 < 2, Σ_k(1+k)^{−6}(k+1)^{3+ε} ≤ Σ_k(1+k)^{−2.875} < ∞, so

  Σ_χΣ_ρ x^β|Φ(ρ)| ≤ x·[Cq log(3q)x^{−1/2} + C_{η,δ}q^{−ηδ/2}].

Because x ≥ q^{2+η}, the first bracket term is ≤ Cq^{−η/2}log 3q.

*Remaining terms.* Prime powers p^k with k ≥ 2 contribute ≤ ‖f‖Σ_{p^k≤x,k≥2}log p ≤ 3‖f‖√x.
Relative to x/φ(q) this is ≤ 3‖f‖q^{−η/2}. The O(log q·log x) term is negligible in the same way.
Hence, for q ≥ q₀(η),

  Σ_{p≡a, p prime}log p·f(p/x) ≥ (xΦ(1)/φ(q))(1 − C_{η,δ}q^{−c}) > 0,

so there is a prime p ≡ a (mod q) with x/2 < p < x. The finitely many q < q₀ are absorbed into C_η. □

**Theorem D (Linnik exponent).** Assume (O). Then for every η > 0,

  P(a,q) ≪_η q^{7/3+η}, using (CGL);
  P(a,q) ≪_η q^{12/5+η}, using only the published (H).

Effectivity: the (H) bound is effective (Huxley's proof has no Siegel-zero input). The (CGL)
bound is uniform in q and is effective if CGL's C(ε), Q(ε) are (see (CGL) in §0: expected, not
asserted). (O) is a qualitative zero-free region and adds no constant.

*Proof.* Take δ = 1/8 from (O).
- For (CGL): when T ≥ 1, q^{7/3(1−σ)}T^{2(1−σ)} + (qT)^{30/13(1−σ)} ≤ 2q^{7/3(1−σ)}T^{3(1−σ)}.
  For 1 ≤ T < 2, monotonicity in T reduces to T = 2. This gives (ii) with A = 7/3, A' = 3.
- For (H): (log qT)^c ≤ C_ε(qT)^ε gives (ii) with A = A' = 12/5.

Apply Proposition 2. □

**Theorem D' (prime number theorem in progressions, up to q ≤ x^{3/7−ε}).** Assume (O) and (CGL).
For every ε ∈ (0,1/10) there is c(ε) > 0 such that, uniformly for (a,q) = 1 and q ≤ x^{3/7−ε},

  ψ(x;q,a) = (x/φ(q))·(1 + O_ε(x^{−c(ε)})).

With (H) instead of (CGL), the same holds for q ≤ x^{5/12−ε}. The O_ε and c(ε) are effective
with (H), and with (CGL) if CGL's constants are (§0).

*Proof (sandwich).* Put η := ε/40, y := x^{1−η} and T₀ := x^{2η}. Take smooth weights
0 ≤ g₋ ≤ 1_{(y,x]} ≤ g₊ ≤ 1 such that:
- g₊ is supported in [y/2, x(1+x^{−η})] and equals 1 on [y,x];
- g₋ is supported in [y,x] and equals 1 on [2y, x(1−x^{−η})];
- the transitions have widths ≍ y near y and ≍ x^{1−η} near x.

Put G_±(t) = g_±(xt) and Φ_±(s) = ∫G_±(t)t^{s−1}dt. Then xΦ_±(1) = ∫g_± = x(1+O(x^{−η})).
G_± ∈ C_c^∞([y/2x, 2]), so Φ_± is entire. Write u := y/x = x^{−η}.

*Mellin bounds.* Integrating by parts m times,
|Φ_±(s)| ≤ |s(s+1)⋯(s+m−1)|^{−1}∫|G_±^{(m)}(t)|t^{σ+m−1}dt. The transition near t ≍ u has
length ≍ u and |G^{(m)}| ≪_m u^{−m}, so it contributes ≪_m u^σ; the one near t = 1 has length ≍ x^{−η}
and |G^{(m)}| ≪_m x^{ηm}, so it contributes ≪_m x^{η(m−1)}. If σ = −1/2, or −1/2 ≤ σ ≤ 2 and |t| ≥ 1, then
|s(s+1)⋯(s+m−1)| ≫_m (1+|t|)^m, hence

  |Φ_±(σ+it)| ≪_m (u^{min(σ,0)} + 1)·x^{ηm}(1+|t|)^{−m} ≤ x^{η/2+ηm}(1+|t|)^{−m}.      (B1)

By (O) and (FE), every nontrivial zero of every Dirichlet L-function has 1/8 ≤ β ≤ 7/8. On this
strip only, u^σ ≤ 1 and t^{σ−1} ≤ t^{−7/8} on (0,1], so

  |Φ_±(σ+it)| ≤ ∫_0^2 t^{σ−1}dt ≤ 16,  |Φ_±(σ+it)| ≤ C_m(x^η/|t|)^m (|t| ≥ 1),  1/8 ≤ σ ≤ 7/8.   (B2)

*Explicit formula per character.* Lemma 1's constant C depends on the fixed f, so it is not reused
for the x-dependent G_±. Redo its contour shift for a primitive χ* mod q* | q, from Re s = 2 to
Re s = −1/2. The horizontal segments vanish as T_k → ∞ because, for fixed x, (B1) with m = 2 gives
decay T_k^{−2} against |L'/L| ≪ log²(qT_k). Residues: xΦ_±(1) at s = 1 if χ* = 1; −x^ρΦ_±(ρ) at each
nontrivial zero; −Φ_±(0) at s = 0 only if χ* ≠ 1 is even, where |Φ_±(0)| ≤ ∫_{u/2}^2 dt/t ≤ 2 + η log x.
On Re s = −1/2, |L'/L| ≪ log(q(|t|+3)) as in Lemma 1, and (B1) with m = 2 gives
|x^sΦ_±(s)| ≪ x^{−1/2+5η/2}(1+|t|)^{−2}. Hence

  Σ_nΛ(n)χ*(n)g_±(n) = 1_{χ*=1}xΦ_±(1) − Σ_ρ x^ρΦ_±(ρ) + O(log x + x^{−1/2+3η}log 3q),

with an absolute O. Replacing χ by χ* costs ≤ ω(q)log 2x per character, as in Proposition 2.
Averaged over χ with weight φ(q)^{−1}, the remainders total O(log 3q·log x), which is
≤ (x/φ(q))·x^{−4/7}log²x because q ≤ x^{3/7}.

Run the zero-sum part of the proof of Proposition 2 with Φ_± in place of Φ, using (B2):
- Zeros with |γ| > T₀: take m := ⌈1/η⌉. By (Z) they contribute
  ≤ x^{7/8}·C_m x^{ηm}·Σ_{k≥T₀}k^{−m}·Cq log(qk) ≤ C_ε q x^{7/8−ηm+2η}log x ≤ C_ε q x^{−1/8+2η}log x ≤ x^{1/2}.
- Zeros with |γ| ≤ T₀ contribute ≤ 16Z(T₀). Take ε' := ε/100 in (CGL). Since q^{7/3} ≤ x^{1−7ε/3}
  and 1−σ ≥ 1/8,

  Z(T₀)/x ≤ CqT₀x^{−1/2}log x + C_{ε'}(qT₀)^{ε'}T₀³ x^{−7ε/24}log x
         ≤ Cx^{−1/14+ε/20}log x + C_ε x^{−ε/8}.

  The second step uses T₀³ = x^{3ε/20} and −7/24 + 3/20 + 1/100 < −1/8.

So Σ_{n≡a}Λ(n)g_±(n) = (x/φ(q))(1+O(x^{−c})). This sandwiches ψ(x;q,a) − ψ(y;q,a).
Finally, (BT) with y > q² gives ψ(y;q,a) ≤ 4y/φ(q) + 3√y, which is (x/φ(q))·O(x^{−η}).
For (H), repeat with 12/5 and T-exponent 12/5. □

**Remarks.**
1. Any half-plane with B ≥ 5/7 gives the same exponent; this covers all 2026 results (7/8, B♭,
   31/32, 1−10⁻⁶). The best known density exponent peaks at σ = 5/7, where Montgomery's 3/(2−σ)
   and CGL's 4/(1+σ) both equal 7/3. For Huxley the peak is 12/5 at σ = 3/4. A hypothetical
   B < 5/7 would give 3/(2−B) < 7/3.
2. CGL's own Corollary 1.4 (arXiv 2507.08296v2, p. 4) is Theorem D' made conditional on a "good
   zero-free region": η(q,T)·log x → ∞. Theorem (O) supplies exactly that with η ≡ 1/8 − 0.001.
   With h = x, its condition x/φ(q) ≥ x^{1/2+ε}q^{1/6} is q ≤ x^{3/7−ε'}. So D' also follows by
   citation. Our proof above is self-contained given the density theorem.
3. Records: GRH gives 2+ε. The best published value is 5 (Xylouris 2011). The best
   October 2026 value is 3.99 (Naslund, Hexagon 2610.00018, unconditional, computer-assisted,
   without QRH). The Siegel–Walfisz range was q ≤ (log x)^A, ineffective. The plain 7/8 error
   x^{7/8}log²x only reaches q ≤ x^{1/8}; OpenAI's 5 Oct Corollary 1.2 states this with 11/12.
4. The conditional implication "half-plane + density ⇒ L ≤ density exponent" may be folklore.
   Its unconditional consequence after (O) is not stated in any source we checked (§5).

## 3. The brief's Artin and Chebotarev candidates: all true, none new

### 3.1 Theorem A (brief a)
Let N/K be finite Galois and ρ a complex representation of G = Gal(N/K). Then L(s,ρ,N/K)
is holomorphic and zero-free on {Re s > B♭}∖{1}. It has a pole of order exactly ⟨ρ,1⟩ at s = 1,
and L(1,ρ) ≠ 0 when ⟨ρ,1⟩ = 0. By (FE), L(s,ρ) is holomorphic on Re s < 1−B♭ and zero-free
there except at its trivial zeros. So every possible Artin pole lies in 1−B♭ ≤ Re s ≤ B♭.

*Proof.*
1. Brauer induction: χ_ρ = Σ_i n_i Ind_{H_i}^G ψ_i, with n_i ∈ ℤ and ψ_i linear characters.
2. Artin formalism, exact at every prime including ramified ones:
   L(s,ρ) = Π_i L(s,ψ_i,N/N^{H_i})^{n_i}.
3. Artin reciprocity identifies each factor with a primitive finite-order Hecke L-function of
   K_i = N^{H_i}.
4. By (L), each factor is holomorphic and zero-free on Re s > B♭, except ζ_{K_i}, which has a
   simple pole at 1. For ψ_i ≠ 1 the factor is finite and nonzero at 1.
5. Hence ord_{s=1}L(s,ρ) = −Σ_i n_i⟨ψ_i,1⟩_{H_i} = −Σ_i n_i⟨Ind ψ_i,1⟩_G = −⟨χ_ρ,1⟩
   (Frobenius reciprocity).
6. Reflection: Λ(s,ρ) = W·Λ(1−s,ρ̄). For Re s < 1−B♭ the right side is holomorphic and nonzero
   except at s = 0, where it has a pole of order ⟨ρ,1⟩, and 1/γ_ρ is entire. At s = 0,
   1/γ_ρ vanishes to order ≥ ⟨ρ,1⟩(r₁+r₂) ≥ ⟨ρ,1⟩. □

*Novelty.* This is Hu, Hexagon 2610.00216 (13 Oct 2026), Cor 9.4 at 7/8, extended there to all
unitary Weil representations (Thm 1.1). Liu, Cor `vi:cor:consequences`(2), covers only monomial ρ.
The B♭ version is Hu's §9 argument with (L) as input.

### 3.2 Theorem B (brief b)
For L/K Galois and C a conjugacy class:

  |π_C(x) − (|C|/|G|)Li(x)| ≤ c₁(|C|/|G|)·x^{B♭}·δ♭^{−1}·log(Δ_L x^{n_L}),

with c₁ absolute and effective. This is FSW Theorem 1.1 (arXiv 2610.18491v2) with QRH(δ♭)
supplied by (L). Hu Cor 9.6 states it with x^{7/8+ε}; Cojocaru–Meyer 2023 Thm 4 states a
version without proof. Known; no new proof needed.

### 3.3 Theorem C (brief c)
There is an absolute effective C* with the following property. If ζ_L has no zero with
Re s > 1−δ, where 0 < δ ≤ 1/2, then for every C there is a prime 𝔭 of K, unramified in L,
of degree one over ℚ, with Frob_𝔭 = C and

  N𝔭 ≤ (C* log 3Δ_L)^{1/δ}.

Moreover the number of such 𝔭 with N𝔭 ∈ (x/2,x] is ≥ c(|C|/|G|)x/log x once
x ≥ (C* log 3Δ_L)^{1/δ}. With δ = δ♭ the exponent is 7.99275….

*Proof.* Fix g ∈ C, let H = ⟨g⟩ and E = L^H. Each χ ∈ Ĥ is a primitive Hecke character of E, and
ζ_L = Π_χ L(s,χ), so every L(s,χ) is zero-free on Re s > 1−δ. Put
W := |H|^{−1}Σ_χχ̄(g)S_χ(x). By Lemma 1 and (CD):

  |H|·W = xΦ(1) + O(x^{1−δ}(log Δ_L+n_L)).

Separate W into good and bad terms:
- *Good*: unramified 𝔓 ⊂ E with N𝔓 = p prime, m = 1, Frob_𝔓 = g, and 𝔓 not above a prime
  ramified in L/K.
- *Primes ramified in L/E*: the weight |H|^{−1}Σ_χχ̄(g)χ(𝔓^m) has modulus ≤ 1, and for a ramified
  𝔓, v_𝔓(d_{L/E}) ≥ |H|/2. So their total is ≤ ‖f‖·(2 log Δ_L/(|H| log 2))·log x.
- *E-primes above primes ramified in L/K*: the same bound, by v_𝔭(d_{L/K}) ≥ |G|/2 and [E:K]/|G| = 1/|H|.
- *Prime powers and higher-degree primes*: ≤ ‖f‖n_E π(√x)log x ≤ 2.6‖f‖n_E√x.

So |H|·Good ≥ xΦ(1) − Cx^{1−δ}(log Δ_L+n_L) − C(log Δ_L·log x + n_L√x). By (M), n_L ≤ 2 log 3Δ_L.
For x ≥ (C* log 3Δ_L)^{1/δ} ≥ (C* log 3Δ_L)², each negative term is ≤ xΦ(1)/4, so Good > 0.

A good 𝔓 has f(𝔓/𝔭) = 1 and 𝔭 = 𝔓∩K unramified in L. Then Frob_{𝔓'}(L/K) =
Frob_{𝔓'}(L/E) = g for 𝔓' | 𝔓, so Frob_𝔭 = C with N𝔭 = p ≤ x. For the count: each such 𝔭 lies
under exactly |G|/(|C||H|) good 𝔓, and each 𝔓 contributes at most ‖f‖log x to Good. □

*Novelty.* FSW Cor 1.2 has the extra factor (log log Δ_L)^{2/δ}; they ask whether it can be
removed ("as sketched at the end of [LO77]"). Hu (9.10) already removes it at δ = 1/8, giving
N𝔭 ≪ (log eΔ_L+n_L)^8 by the same smooth annular formula. Ours is the δ♭ substitution, so it
is not new.

## 4. Minor new corollaries (not stated in any source checked; routine deductions)

### 4.1 Theorem E (small generators of ray class groups)
Let K be a number field, 𝔪 a modulus and Cl_𝔪 the ray class group. Then Cl_𝔪 is generated by
the classes of degree-one primes 𝔭 ∤ 𝔪 with

  N𝔭 ≤ (C_E log(3Δ_K N𝔪))^{1/δ♭} = (C_E log(3Δ_K N𝔪))^{7.9928…},

with C_E absolute and effective. For comparison: under GRH, Bach gives 12(log Δ_K)² for 𝔪 = 1.
Theorem C applied to the ray class field only gives (h_𝔪 log(Δ_K N𝔪))^{7.99}.

*Proof.* Let H' be the subgroup generated by the classes of these primes, with x the norm bound.
If H' ≠ Cl_𝔪, choose a character χ ≠ 1 of Cl_𝔪 with χ|_{H'} = 1, and let χ* be its primitive
inducing character. Then log A(χ*) ≤ log(Δ_K N𝔪). Consider

  D(x) := Σ_𝔞Λ_K(𝔞)(1−Re χ*(𝔞))f(N𝔞/x) ≥ 0.

Terms 𝔞 = 𝔭 of degree one with 𝔭 ∤ 𝔪 and N𝔭 ≤ x vanish, since χ*(𝔭) = 1. Hence

  D(x) ≤ 2‖f‖(ω_K(𝔪)log x + 2.6n_K√x), with ω_K(𝔪) ≤ 1.45 log N𝔪.

On the other hand, Lemma 1 applies to ζ_K and to L(s,χ*), both zero-free on Re s > B♭ by (L):

  D(x) = S_1 − Re S_{χ*} ≥ xΦ(1) − 2Cx^{1−δ♭}(log(Δ_K N𝔪)+n_K).

With ℓ := log(3Δ_K N𝔪) and n_K ≤ 2ℓ, each error term is ≤ xΦ(1)/4 once x ≥ (C_Eℓ)^{1/δ♭},
because √x ≥ C_Eℓ. This is a contradiction. □

*Novelty.* FSW, Hu, OpenAI, CT26 and Liu contain no class-group generation statement. The only
"generated by" statements found are for special quadratic families (Hexagon 2610.00178, Lemma 23.2).

### 4.2 Theorem F (absolute effective residue bound; effective Brauer–Siegel)
Let K ≠ ℚ and suppose ζ_K has no zero with Re s > B, where B < 1. Then

  κ_K := Res_{s=1}ζ_K ≥ exp(−2.62 − ((2−B)/(4(1−B)))·(2+1/((1−B)log Δ_K))·(1+3/log Δ_K))/log Δ_K.

With B = B♭ from (L), this gives κ_K ≥ e^{−81}/log Δ_K for every K, and ≥ e^{−7.5}/log Δ_K once
log Δ_K ≥ 100. Hence h_K R_K ≥ e^{−81}w_K√Δ_K/(2^{r₁}(2π)^{r₂}log Δ_K) effectively. Together with
Landau's effective upper bound, log(h_K R_K) ~ log√Δ_K effectively along any family with
n_K/log Δ_K → 0, with no Galois hypothesis. CT26's 31/32 also suffices, with a worse constant.

*Proof.* Let d = Δ_K and G(σ) = (r₁/2)(ψ(σ/2)−log π) + r₂(ψ(σ)−log 2π). For σ ∈ [1,2],
−1.56n ≤ G(σ) < 0. The Hadamard factorisation (Stark 1974, Lemma 1) gives, for real σ > 1,

  −ζ_K'/ζ_K(σ) = ½log d + G(σ) + 1/σ + 1/(σ−1) − Σ_ρ Re 1/(σ−ρ),

where every term of the sum is positive.

Put F(σ) := log((σ−1)ζ_K(σ)), so F(1⁺) = log κ_K and F' = 1/(σ−1)+ζ'/ζ. Let σ₀ := 1+1/log d. Then

  log κ = F(σ₀) − ∫₁^{σ₀}F' ≥ −log log d + ½ − 1.56n/log d − Σ_ρ I_ρ,
  where I_ρ := ∫₁^{σ₀}Re(σ−ρ)^{−1}dσ = ½log(|σ₀−ρ|²/|1−ρ|²).

This uses F(σ₀) ≥ log(1/log d), since ζ_K(σ₀) ≥ 1. By (M), 1.56n/log d ≤ 3.12.

Bound I_ρ. Put u = 1−β ∈ [1−B, B] by (FE). Then

  I_ρ ≤ ½(σ₀−1)(2u+σ₀−1)/(u²+γ²) ≤ ½(σ₀−1)(2+(σ₀−1)/(1−B))·u/(u²+γ²).

Next, u/(u²+γ²) ≤ ((1+u)/u)·Re(2−ρ)^{−1} ≤ ((2−B)/(1−B))·Re(2−ρ)^{−1}. At σ = 2 the same formula,
with G(2) < 0 and ζ'/ζ(2) < 0, gives Σ_ρ Re(2−ρ)^{−1} ≤ ½log d + 3/2. Summing over ρ gives the
stated bound, since ½ − 3.12 = −2.62. For B♭ and d ≥ 3 the zero sum is ≤ 77.8, so
log κ ≥ −log log d − 80.5. □

*Novelty.* Stark 1974 and Cho–Lemke Oliver–Zaman (arXiv 2510.02309) give the same order with
constants depending on the degree, or with the exceptional factor ε(χ) or D^{−1/n} when a quadratic
subfield might carry a Siegel zero. With (L), CLOZ's ε(χ) ≍ 1 and their bounds lose the
exceptional case. Theorem F's absolute constant, for all K, is not stated in any 2026 source
checked: Hexagon 2610.00178 restricts to Dirichlet input; OpenAI 5 Oct does imaginary quadratic only.

## 6. Dead ends (NOGO candidates)

- The Murty–Murty–Saradha factor |C|^{1/2} cannot be reached unconditionally. Heilbronn characters
  give Σ_χχ̄(g)n_χ(ρ) = θ_{⟨g⟩}(g), whose modulus is ≤ ord_ρζ_L, which is exactly Lagarias–Odlyzko.
  The improvement needs Artin holomorphy inside the strip.
- Hooley's asymptotic for Artin's primitive-root conjecture remains out of reach. The half-plane
  controls index primes only up to x^{1−B♭} = x^{0.125}, and the gap (x^{1/8}, x^{1/2}) remains.
  The positive lower density is already on Hexagon (2610.00228).
- The least Chebotarev prime cannot go below (log Δ_L)^{1/δ} with present tools: that would need
  zero-density estimates on the log Δ scale, which do not exist.
- Lowering B (B♭ instead of 7/8) does not improve the Linnik exponent; the density maximum is at σ = 5/7.
