## A. Li200k (L l. 23–72, V)

A0. Sum formula. λ_n = Σ_ρ [1 − (1 − 1/ρ)^n] (Bombieri–Lagarias 1999, Thm 1; pairs ρ, ρ̄). Pair terms are real; on-line pair 1/2 ± iγ: z = 1 − 1/ρ = e^{iθ(γ)}, θ(t) = 2 arctan(1/(2t)) (arg(−1/2+iγ) − arg(1/2+iγ) = π − 2 arctan 2γ). Pair sums are absolutely summable (g(nθ) ≤ n²/γ²; off-line pair ≤ n·ℓ + n²φ²/2 = O(n²/γ²)), so splitting into M_n − (…) is a legal rearrangement. HOLDS.

A1. Per zero (L step 1, V l. 193–216 test). ρ = 1/2 + δ + iγ, 0 < δ ≤ a(γ), ρ* = 1 − ρ̄.
- r² = ((1/2−δ)² + γ²)/((1/2+δ)² + γ²), ℓ = −log r = ½ log(1 + 2δ/((1/2−δ)²+γ²)) ≤ δ/γ² ≤ a/γ². HOLDS.
- φ = arg z_ρ = arctan((1/2−δ)/γ) + arctan((1/2+δ)/γ), even in δ, φ(0) = θ(γ); Taylor with f(x) = arctan(x/γ), |f″(x)| = 2|x|γ/(γ²+x²)² ≤ 2|x|/γ³, |x| ≤ 1: |φ − θ| ≤ 2δ²/γ³. HOLDS. z_{ρ*} = r^{−1}e^{iφ}. HOLDS.
- Quartet: 4 − 2(r^n + r^{−n})cos nφ. It holds 2 ordinates γ > 0 (ρ and ρ*), so it is charged 2g(nθ) in M_n and 2q_n in Q_n. Needed: q_n ≥ 2cosh(nℓ)cos nφ − 2cos nθ = 2(cosh nℓ − 1)cos nφ + 2(cos nφ − cos nθ) ≤ 4 sinh²(nℓ/2) + 2n|φ−θ| ≤ 4 sinh²(na/(2γ²)) + 4na²/γ³ = q_n(γ). HOLDS (all directions checked).
- Monotonicity hypotheses (a/t², a²/t³ nonincreasing) are used only to make q_n(t) nonincreasing in t (step A2). For B, a = 1/2 − 1/(R log t): (a/t²)′ = t^{−3}(1/(R log²t) − 2a) < 0, (a²/t³)′ = a t^{−4}(2/(R log²t) − 3a) < 0. HOLDS.
