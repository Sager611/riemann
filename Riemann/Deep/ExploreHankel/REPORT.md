## Transfers, tests, verdicts
### T1 (N5): the AAK-native sup-norm Báez-Duarte problem — dead, blind
e_N := min_C sup_τ |1 − ζ(s)C(s)|/|s| over Dirichlet polynomials C of length N. At every on-line zero the error is exactly 1/|ρ|, so e_N ≥ 1/|ρ_1| = 0.0707101 for all N. An off-line zero ρ_0 adds only the interior Pick condition S(ρ_0) = 1 (S = 1 − ζC), i.e. e ≥ |W(ρ_0)| = 1/|ρ_0| < 1/|ρ_1|: never binding. For any outer weight W the off-line condition is dominated by the dense on-line zeros near Im ρ_0 (Poisson averaging), unless W oscillates on the zero-gap scale, i.e. is built from the zeros.
Test ([hinf.py](hinf.py), LP with a 32-gon, cutting planes, τ ≤ 250): e_1 = 1.28, e_2 = 0.290, and e_N ∈ [0.07071, 0.07100] for N = 5, 10, 20, 40 (lower end: the exact bound 1/|ρ_1|; upper end: sup of the LP solution on the grid), i.e. 1/|ρ_1| to 0.4% from N = 5 on.
Adversarial, Davenport-Heilbronn (DH: functional equation, no Euler product, zeros off the line): e_1 = 0.214, e_2 = 0.198, and e_N ∈ [0.19536, 0.19617] for N = 5-40, i.e. 1/|ρ_1^DH| = 0.1953644 (lowest DH zero 1/2 + 5.094160i) to 0.4%; its off-line zeros (1/|ρ| ≤ 0.0117) never matter. Same picture for both: the sup-norm problem cannot tell them apart. Known equivalent? None: it is simply blind.

### T2 (N5): the L² problem is Toeplitz/Beurling; its Hankel operators are trivial — reproduces known results
- In Mellin form d_N² = min_C ∫|1 − ζC|² dP (P = Cauchy(0, 1/2)). The dilation Hankel operator L²(0,1) → L²(1,∞) has rank one ({θ/t} = θ/t for θ < 1 < t; Kronecker: the pole of ζ(s)/s at s = 1). The reverse Hankel is linear in the symbol ζ(s)/s, which is analytic in Re s > 1/2: zeros are not its singularities.
- Cleanest transfer: the Beurling floor is a Hankel norm. With Φ = ζ(s)(s−1)/s² = I·O: lim_{λ→0} D(λ)² = ‖H_{conj I}((s−1)/s²)‖², where H_{conj I} is a partial isometry (H*H = projection onto the model space K_I): every nonzero singular value is 1 and the rank is the number of off-line zeros. So AAK yields only the zero count; RH ⟺ H_{conj I} = 0 is Beurling's theorem; the size of the floor is the Blaschke-residue formula Σ ≈ (2σ − 1)/|ρ|² (the control-theory cheap-tracking limit of Qiu-Davison type; the same Blaschke data as the Balazard-Saias-Yor Jensen identity). For DH's 8 known off-line zeros the finite section of H_{conj I} has singular values 1 (eight times) and 0, by Kronecker; the only number it yields is the floor 2.537·10⁻⁴ (below), against d_N² = 2.83·10⁻² at N = 400. On-line zeros sit in the outer factor; their effect is the finite-memory rate D(λ)² log(1/λ) ≥ Σ m²/|ρ|² (BBLS, Burnol), a boundary-zero effect of a truncated Wiener-Hopf problem that no Hankel operator sees.
- Báez-Duarte's natural numbers are the product order on Q₊* (infinite polydisc), where Nehari fails (Ortega-Cerdà–Seip). AAK is available for linearly ordered dictionaries (2006.12474), but those contain the Báez-Duarte dictionary, so they bound d_N from below only. RH needs the upper bound.
Tests: [nbgram.py](nbgram.py) (Vasyunin Gram checked against direct piecewise integration to 1e−8; float64 = 40-digit at N = 10, 30): d_N² log N = 0.0547 (10), 0.0494 (20), 0.0469 (40), 0.0481 (80), 0.0474 (160), 0.0459 (320), 0.0453 (640), 0.0455 (1280); 2611.03924's table (a constrained variant, ≥ ours) agrees to 0.2% at N = 40, 160, 640, 1280, and BBLS's fit 1/(21.99 log N) gives 0.0455 at 1280. Half-space relaxation ([farey.py](farey.py), all dilations a/b ∈ [1/N, 1] with b ≤ B, 40-digit): N = 10: 0.0382 (B = 10), 0.0290 (B = 20), 0.0280 (B = 30) against 0.0547; N = 20, B = 20: 0.0320 against 0.0494. The linearly ordered (AAK-friendly) problem is 30-49% smaller at these N and lies below C = 0.0462 (BBLS/Burnol force its liminf ≥ C): a loose lower bound, as predicted.
Adversarial, DH ([nbgram.py](nbgram.py), exact digamma Gram for dilates of A(1/t), A(x) = Σ_{n≤x} a_n; [dhconst.py](dhconst.py)): d_N² log N = 0.122 (10), 0.138 (20), 0.137 (40), 0.152 (80), 0.157 (160), 0.163 (300), 0.170 (400), climbing toward DH's own constant C_f = Σ 1/(ρ(1−ρ)) = 2ξ_f'/ξ_f(1) = 0.19527, exactly like an RH-true function. Its off-line zeros 0.80852 + 85.69935i, 0.65083 + 114.16334i, 0.57436 + 166.47931i, 0.72426 + 176.70246i (|f| < 1e−29) force lim d_N² ≥ 2.537·10⁻⁴ (Blaschke floor), which C_f/log N reaches only at log N ≈ 770 (N ≈ 10^334); at N = 400 the floor is 0.9% of d_N². For ζ a single off-line pair above height 3·10¹² (Re ρ ≤ 0.8734) would leave a floor below 2·10⁻²⁵. Known equivalent? Yes: Beurling, BBLS, Burnol, BSY.

### T3 (N1, N7, N13, N2): Wiener-Hopf factorization, partial indices, Krein, Pick — known or barrier (no numerics needed)
- Index theory needs the symbol invertible on the line (Douglas: T_φ Fredholm ⇒ φ invertible in L^∞). For σ > 1, ζ(σ+it) is invertible in the Wiener almost-periodic algebra with mean motion 0 (index 0, no zeros); for 1/2 < σ ≤ 1 it is unbounded above and below (Bohr-Landau, Voronin), so no bounded normalization of ζ on such a line is invertible in L^∞, no Toeplitz/Wiener-Hopf operator built from it is Fredholm, and no half-plane zero index exists; on σ = 1/2 it vanishes. Zero counting is left to bounded contours (Backlund/Turing). DH: identical.
- N1: Weil's window form is a truncated convolution operator whose symbol is the point measure Σ_γ δ_γ; a singular symbol has no spectral (Wiener-Hopf) factorization (Szegő-Krein need a log-integrable density); several L-functions decouple over characters (diagonal matrix symbol, partial indices = scalar ones). Window positivity stays Krein extension / frame bounds (explore8, R368).
- N13: Krein's prediction theory for |ζ|² dP reproduces Beurling exactly (1/ζ in the closure ⟺ trivial inner factor). N2/N6: Pick-function positivity of −Ξ'/Ξ is Lagarias' criterion (R20). N7/N10: Kronecker for ζ'/ζ on Re s = σ₀ gives (formally) rank 1 + #{ρ: Re ρ > σ₀}, i.e. Landau/Littlewood restated. Control: d_N is the H² step-tracking cost of the plant ζ with a finite-memory controller (delays log k ≤ log N); RH ⟺ the plant is minimum phase. Dictionary only.
