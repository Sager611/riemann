# Polylogarithmic effective isogeny theorem and Serre constant without GRH: derivation

Agent serrenum, 2026-11-06. Every numerical constant comes from `cert.py` (Arb ball arithmetic; log
`logs/cert_output.txt`), which imports the Arb kernel code of `../ChebExp/cert.py`. Section numbers (§) are referred
to in the comments of `cert.py`. "chebexp" = Riemann/Deep/ChebExp (REPORT.md, DERIVATION.md, cert.py).

## 0. Statements

Notation. E, E' are elliptic curves over ℚ, N_E their conductors, a_p(E) = p + 1 − #E(𝔽_p) for p ∤ N_E,
R := rad(2N_E N_E') (so R ≥ 2), ρ_{E,2}: G_ℚ → GL_2(ℤ_2) the 2-adic representation, ρ̄_{E,ℓ} the mod-ℓ one.
The only analytic input is H(1/32): ζ_L(s) ≠ 0 for Re s > 31/32, for every number field L
(Cureton–Thorner, Lean-checked; see chebexp DERIVATION §0). No GRH, no Artin conjecture.

**Theorem 1 (effective isogeny theorem).** If E and E' are not ℚ-isogenous, there is a prime p ∤ 2N_E N_E' with
a_p(E) ≠ a_p(E') and

  p ≤ (a_n log R + b_n)^32,

where (n; a_n, b_n) is read off from the mod-2 representations:

| case | condition on ρ̄_{E,2}, ρ̄_{E',2} | field L (§2) | n ≥ [L:ℚ] | a_n | b_n |
|---|---|---|---|---|---|
| (a) | tr ρ̄_{E,2}(σ) ≠ tr ρ̄_{E',2}(σ) for some σ ∈ G_ℚ | ℚ(E[2], E'[2]) | 36 | 3.5 | 17.5 |
| (b) | ρ̄_{E,2} ≅ ρ̄_{E',2} with image GL_2(𝔽_2) | fixed field of φ (§2.3) | 48 | 4.5 | 23.5 |
| (c) | both reducible (E(ℚ)[2] ≠ 0 ≠ E'(ℚ)[2]) | deviation field (§2.2) | 128 | 11.5 | 68 |
| (d) | all pairs (only needed when ρ̄_{E,2} ≅ ρ̄_{E',2} has image of order 3) | deviation field | 192 | 17 | 100 |

The four cases cover every pair (§2.5). So **p ≤ (17 log R + 100)^32 for every non-isogenous pair.**

**Theorem 2 (Serre's open image constant).** Let E/ℚ be without complex multiplication. Then ρ̄_{E,ℓ} is surjective
(and so is ρ_{E,ℓ}: G_ℚ → GL_2(ℤ_ℓ), Serre IV-23) for every prime

  ℓ > C(E) := 2(11.5 log rad(2N_E) + 68)^16,

and for ℓ > 2(4.5 log rad(2N_E) + 23.5)^16 if ρ̄_{E,2} is surjective.

## 2. Algebra: the auxiliary field L

### 2.1 Deviation quotient (Serre; Mayle–Wang Prop. 12 with ℓ = 2, r = 2)
Γ := Gal(ℚ(A[2^∞])/ℚ), ρ := ρ_{E,2} × ρ_{E',2}: Γ → GL_2(ℤ_2)², M := the ℤ_2-subalgebra of 𝓡 := M_2(ℤ_2)² generated by
ρ(Γ), δ: Γ → (M/2M)^× the reduction, G := δ(Γ). M is a free ℤ_2-module of rank ≤ 8, so |G| ≤ 2^8 − 1 = 255.
By I3, E, E' non-isogenous ⇒ V_2E ≇ V_2E', both semisimple ⇒ tr ρ_1(γ) ≠ tr ρ_2(γ) for some γ (Brauer–Nesbitt).
Let α be the largest integer with tr x_1 ≡ tr x_2 mod 2^α on ρ(Γ) (hence on M, by linearity), and
λ̄: M/2M → 𝔽_2, (x_1, x_2) ↦ 2^{−α}(tr x_2 − tr x_1) mod 2. C := G ∖ ker λ̄ is nonempty (γ_0 with the congruence
failing mod 2^{α+1}), closed under conjugation, and δ(γ) ∈ C ⇒ tr ρ_1(γ) ≠ tr ρ_2(γ). G ≠ 1, because the identity
has equal traces. δ is continuous with finite image; let L ⊂ ℚ(A[2^∞]) be its fixed field, Gal(L/ℚ) ≅ G.

### 2.2 Orders
(i) **Divisibility (Mayle–Wang).** L ⊂ ℚ(A[2^k]) for some k, so |G| divides |GL_2(ℤ/2^k)|² = 2^{8k−6}·3². The largest
2^a3^b ≤ 255 with b ≤ 2 is 192. **So n := [L:ℚ] ≤ 192 always.**
(ii) **Reducible residual images (new).** Let π: M/2M → 𝓡/2𝓡 = M_2(𝔽_2)² be reduction (well defined: 2M ⊂ 2𝓡).
π(δ(γ)) = (ρ̄_{E,2}(γ), ρ̄_{E',2}(γ)). The kernel I = (M ∩ 2𝓡)/2M is nil: with V = M ⊗ ℚ_2 and M' = 𝓡 ∩ V, both M ⊂ M'
are lattices in V, so 2^{k_0}M' ⊂ M for some k_0; for x ∈ M ∩ 2𝓡, x^j ∈ 2^j𝓡 ∩ V = 2^jM', so x^{k_0+1} ∈ 2M.
Hence the kernel of the group homomorphism π|_G: G → (𝓡/2𝓡)^× is G ∩ (1 + I): its elements are 1 + ν with ν ∈ I
nilpotent, and (1 + ν)^{2^j} = 1 + ν^{2^j} = 1 in characteristic 2. So this kernel is a 2-group, and
|G| = |(ρ̄_{E,2} × ρ̄_{E',2})(Γ)|·2^k. If both residual representations are reducible,
their joint image lies in B(𝔽_2)², of order ≤ 4, so |G| is a power of 2 and **n ≤ 128**.

### 2.3 The φ-quotient (Chen–Swidinsky 2501.00202 Prop. 4.3, Ignasi Prop. 2.2.1; needs I5)
Assume ρ̄_{E,2} ≅ ρ̄_{E',2} absolutely irreducible (image GL_2(𝔽_2)). Let β be the largest integer with ρ_1 ≡ Pρ_2P^{−1}
mod 2^β for some P ∈ GL_2(ℤ_2); β ≥ 1 and β ≤ α. I5 with A = ℤ/2^α, R = A[Γ] gives β ≥ α, so α = β. After conjugating
ρ_2, ρ_2(γ) = (I + 2^βθ(γ))ρ_1(γ) with θ(γ) ∈ M_2(ℤ_2), and φ(γ) := (θ(γ) mod 2, ρ̄_1(γ)) is a homomorphism to
M_2(𝔽_2) ⋊ GL_2(𝔽_2) (cocycle identity θ(γγ') ≡ θ(γ) + ρ_1(γ)θ(γ')ρ_1(γ)^{−1} mod 2^β). det ρ_1 = det ρ_2 (cyclotomic)
and det(I + 2^βθ) = 1 + 2^β tr θ + 2^{2β}det θ give tr θ ≡ 0 mod 2, so φ(Γ) ⊂ M_2^0(𝔽_2) ⋊ GL_2(𝔽_2), of order
8·6 = 48. With φ'(A, B) := tr(AB) mod 2, φ'(φ(γ)) = tr θ_γ mod 2 = 2^{−α}(tr ρ_2(γ) − tr ρ_1(γ)) mod 2 (θ_γ := θ(γ)ρ_1(γ)),
so C := {c ∈ φ(Γ): φ'(c) ≠ 0} is nonempty, conjugation-closed, and φ(γ) ∈ C ⇒ traces differ. **n ≤ 48.**

### 2.4 Case (a)
L = ℚ(E[2], E'[2]), Gal(L/ℚ) ⊂ GL_2(𝔽_2)², **n ≤ 36**; C = {σ: tr ρ̄_{E,2}(σ) ≠ tr ρ̄_{E',2}(σ)} (nonempty by assumption,
conjugation-closed). For p ∤ 2N_E N_E' with Frob_p ∈ C: a_p(E) ≢ a_p(E') mod 2.

### 2.5 Exhaustion
If the mod-2 traces agree everywhere, the residual semisimplifications are isomorphic (Brauer–Nesbitt over 𝔽_2; det = 1).
Then both are absolutely irreducible (case (b)), or both reducible (case (c)), or both irreducible with image C_3 and
isomorphic (case (d), only covered by §2.2(i)). Elements of GL_2(𝔽_2) ≅ S_3 have trace 1 iff they have order 3
(checked in cert.py).

### 2.6 Ramification and discriminant
All fields above lie in ℚ(A[2^∞]) or ℚ(E[2], E'[2]), so by I4 they are unramified outside 2N_E N_E': rad(d_L) | R.
**Hensel–Serre bound** (Serre 1981 Prop. 6; Mayle–Wang Lemma 7): for L/ℚ Galois of degree n, v_𝔭(𝔇) ≤ e − 1 + v_𝔭(e)
gives log Δ_L ≤ (n − 1) log rad(d_L) + n log n. Hence

  Λ := log Δ_L ≤ Λ_max(ρ) := (n_max − 1)ρ + n_max log n_max,  ρ := log R ≥ log 2.   (2.1)

## 3. Analysis: Chebotarev with excluded primes

### 3.1 Counting degree-one primes of F over a fixed p
**Lemma 3.1.** Let p be unramified in L with Frobenius class C_p. The number N_g(p) of primes 𝔓 of F = L^H above p
with f(𝔓/p) = 1 and Frob_𝔓(L/F) = g is |C_G(g)|/|H| if C_p = C, and 0 otherwise.
*Proof.* Fix 𝔔_0 | p in L, σ = Frob_{𝔔_0}. Primes of L above p are τ𝔔_0 (τ ∈ G), with Frob = τστ^{−1}. The prime 𝔓
of F below τ𝔔_0 has f(𝔓/p) = ord σ/|⟨τστ^{−1}⟩ ∩ H|, so f = 1 iff τστ^{−1} ∈ H, and then Frob_𝔓(L/F) = τστ^{−1}
(H abelian, so it does not depend on the prime above 𝔓). The set {τ: τστ^{−1} = g} is empty unless σ ∈ C, and then has
|C_G(g)| elements; it is a union of double cosets Hτ⟨σ⟩ (H abelian), each of size |H| (⟨τστ^{−1}⟩ ⊂ H), and each such
double coset is one prime 𝔓. ∎

### 3.2 The excluded-primes inequality
**Lemma 3.2.** Let m ≥ 1. Good_m(x) := the part of Good(x) with p ∤ m. Then
  |H|·(Good(x) − Good_m(x)) = |C_G(g)|·Σ_{p | m, p unram., C_p = C} log p·k(p/x) ≤ n_L‖k‖ log m,
since k ≤ ‖k‖ := max F and |C_G(g)| ≤ |G| = n_L. Hence

  |H|·Good_m(x)/x ≥ LHS_m(x) := LHS(x; Λ, n_L) − n_L‖k‖ log m / x,   (3.3)

and LHS_m(x) > 0 gives a prime p ∤ m, unramified in L, with Frob_p = C and p ≤ x (chebexp §4.1 applied to a good
term with p ∤ m). In the application m = R, so p ∤ 2N_E N_E'. (This replaces the doubling L(√m) of Mayle–Wang Cor. 6,
which would double n and Λ.)

### 3.3 Interval checks in ρ = log R (cert.py `lhs_interval_R`)
A chain is (n_max, a, b, ρ_0 ≤ log 2) with contiguous intervals [ρ_a, ρ_b], each with its own kernel (h, s*, σ_0).
For an interval put x := (aρ_a + b)^{32}. For a pair with log R ∈ [ρ_a, ρ_b] the field L of §2 has n_L ∈ [2, n_max],
Λ ≤ Λ_max(ρ_b) by (2.1), and log m = log R ≤ ρ_b. LHS_m is decreasing in Λ and in log m and affine in n_L, so it suffices
to check, with Λ_b := Λ_max(ρ_b):

  f(n) := Φ(1)⁻ − (x^{−δ}M_x)⁺·(½Λ_b + c_B − n g) − x^{−1}[(n−1)Φ(0) + nΦ(0)τ_x + 2Λ_bR_f + nP_k(x) + n‖k‖ρ_b]⁺ > 0

for n = 2 and n = n_max (⁻/⁺: Arb lower/upper bounds; the sign argument of chebexp §5.2 applies verbatim, since
B(σ_0; Λ_b, n_L) ≥ B(σ_0; Λ, n_L) ≥ Σ_ρ w(ρ) ≥ 0 for the actual field). Then p ≤ x ≤ (a log R + b)^{32}.

### 3.4 Tail (cert.py `lhs_tail_R`)
For ρ ≥ ρ_N use x(ρ) := (aρ + b)^{32} and one kernel. Bounds valid for all ρ ≥ ρ_N:
- zero term: x^{−δ}M_x B ≤ M_{x_N}·(αρ + β)/(aρ + b) with α = (n_max − 1)/2, β = ½n_max log n_max + c_B − 2g
  (n_L ≥ 2, g > 0 asserted); a Möbius function of ρ, so its sup on [ρ_N, ∞) is max(α/a, (αρ_N + β)/(aρ_N + b));
  M_x = max(A_1, x^{2δ−1}A_2) decreases in x;
- 1/x terms: Λ_max(ρ)/x(ρ) and ρ/x(ρ) decrease for ρ ≥ ρ_N when (n_max−1)b < (a/δ)·n_max log n_max + (1/δ − 1)a(n_max−1)ρ_N
  and b < (1/δ − 1)aρ_N (asserted; d log x/dρ = a/(δ(aρ + b))); R_f ≤ min(‖k‖(U + log 2), Φ(0) + ‖k‖ log 2)/log 2 for every x; τ_x decreases in x;
- P_k(x)/x ≤ 1.01624[x^{−1/2}(S_2 + Φ(½)/2) + x^{−2/3}(S_3 + Φ(⅓)/3) + 2 log x·x^{−3/4}(‖k‖ + Φ(0)/4)] (chebexp (4.3),
  J ≤ 2 log x for log x ≥ 2), decreasing in x.
So f(ρ) ≥ Φ(1) − M_{x_N}·max(α/a, (αρ_N+β)/(aρ_N+b)) − [n_maxΦ(0)(1 + τ_{x_N}) + 2Λ_max(ρ_N)R_f + n_max‖k‖ρ_N]/x_N
− n_max·(P_k/x)(x_N) > 0 is checked once.

## 4. Proof of Theorem 1
Take the case of (E, E') per §2.5 and its field L, n_L ≤ n, nonempty conjugation-closed C; pick a conjugacy class
C_0 ⊂ C (in case (b) C lives in Gal(L/ℚ) ≅ φ(Γ)). L ≠ ℚ because C is nonempty and does not contain the identity.
cert.py certifies, for each n ∈ {36, 48, 128, 192}, a chain covering log R ∈ [log 2, ∞) (§3.3–3.4). Lemma 3.2 with
m = R gives p ∤ 2N_E N_E' with Frob_p ∈ C_0 and p ≤ (a_n log R + b_n)^{32}. A Frobenius element γ ∈ Γ at p (p is unramified
in ℚ(A[2^∞]) by I4) maps into C, so tr ρ_{E,2}(γ) ≠ tr ρ_{E',2}(γ), i.e. a_p(E) ≠ a_p(E') (I4). In case (a) directly
a_p(E) ≢ a_p(E') mod 2. ∎

## 5. Proof of Theorem 2
Let ℓ > 37 with ρ̄_{E,ℓ} not surjective. By I6, image ⊂ C_ns^+(ℓ), ⊄ C_ns(ℓ); ε := ε_ℓ is a nontrivial quadratic
character, unramified outside N_E (I7), so ε = χ_D with D ≠ 1 squarefree, D | N_E. Put E' := E_D:
rad(2N_E N_{E'}) = rad(2N_E) (I8), E' not isogenous to E (I8), ρ̄_{E',2} ≅ ρ̄_{E,2}. Cases:
- ρ̄_{E,2} surjective: case (b), n = 48;
- ρ̄_{E,2} reducible: case (c), n = 128;
- ρ̄_{E,2} of image C_3: L = ℚ(E[2])·ℚ(√D) has group C_3 × C_2 (a cyclic cubic field has no quadratic subfield),
  n = 6 ≤ 128; class (3-cycle, −1); such p has a_p(E) odd, so a_p(E) ≠ 0, and χ_D(p) = −1.
In every case Lemma 3.2 (m = rad(2N_E)) gives p_0 ∤ 2N_E with a_{p_0}(E) ≠ a_{p_0}(E_D) and
p_0 ≤ (11.5 log rad(2N_E) + 68)^{32} (4.5, 23.5 if ρ̄_{E,2} is surjective). By I8, χ_D(p_0) = −1 and a_{p_0}(E) ≠ 0.
- If p_0 ≠ ℓ: ρ̄_{E,ℓ}(Frob_{p_0}) ∈ C_ns^+ ∖ C_ns has trace 0, so ℓ | a_{p_0}(E) ≠ 0 and ℓ ≤ 2√p_0 (I9).
- p_0 = ℓ is impossible (gap in Mayle–Wang's write-up, closed here): then E has good reduction at ℓ and
  0 < |a_ℓ| ≤ 2√ℓ < ℓ, so ℓ ∤ a_ℓ: ordinary. By I7, some τ ∈ I_ℓ has ρ̄_{E,ℓ}(τ) with eigenvalues ζ, 1, ζ of order ℓ − 1
  ≥ 4. Such a matrix is not in C_ns (whose elements are scalar or have eigenvalues outside 𝔽_ℓ) and not in
  C_ns^+ ∖ C_ns (trace 0 would force ζ = −1). Contradiction.
So ℓ ≤ 2(11.5 log rad(2N_E) + 68)^{16}; the right side exceeds 37. ∎
