# Adversarial novelty check: Gale's conjecture in R⁷, R⁸ and every n ≥ 5 (galenov, 2026-11-04, 22:13–22:30 UTC)

## Verdict
- R⁷ (84 points, 0.9434435130) and R⁸ (85 points, 0.9499470677): no set in either dimension found anywhere. Voronov's table stops at n = 6; its n = 7 row is commented out in the TeX.
- Every n ≥ 9 is not new. A Borsuk counterexample is a Gale counterexample (β_{n+1} = D > σₙD; Voronov §1 says so), and OpenAI's preprint gives compact Borsuk counterexamples in every d ≥ 9 (Cor. 7.1 adds s points to the projector set). Finite ones follow too: a finite ε-net F of such a set has β_{n+1}(F) ≥ D − 2ε (elementary, not stated in the sources). I checked the step: the projectors lie on a sphere of radius √(3/4) about I/4 with D = √2, so added points can sit at distance D from everything.
- Must be corrected (REPORT "Before this", NOTE result 3 and §6): "Borsuk counterexamples for n ≥ 64" should say n ≥ 9 (compact; finite: dimension 63, Ji arXiv 2608.12561); "first in R¹⁰…R⁶³" is wrong. For n ≥ 9 the family is new only as an explicit, elementary alternative.
- The template is not ours: vsvor/Gale-conjecture simplex_product_seed.py (22 Oct) builds exactly our five orbits (A = a·u − b·v, B = −c·u + d·v, C = e·u + f·v, poles on both simplices; 3(p+1)(q+1) + n + 2 points, p = ⌊n/2⌋) as search seeds for n = 5–8, "NOT a certificate". It has no 7- or 8-dimensional set, no proof, and no parameters that make the template itself a counterexample.
- New: the colouring lemma plus exact parameters, giving a proof with no SAT and no topology. This answers Voronov's Problem for n ≥ 5 (n = 3, 4 still need a computer). "Gale fails in every n ≥ 3" is new as a statement, because 7 and 8 were the only open dimensions. It does not depend on OpenAI: the family covers 5–1000 and classical Borsuk counterexamples cover n ≥ 64.
