## 8. MeanSq from classical inputs (derivation; answers reviewer round 2)
Statement (QH.meanSqK, AA/MeanSquareBounds/meanSqK.lean:51-54): ∃ C ∀ ε ∈ (0, 1], K ≥ 1 ∃ Y0 ∀ Y ≥ Y0, admitted (U, m0, a0), primes of m0 ≤ z or > Z := Y^{400K}: ∀ y ∈ [Y, Y^K], |κ| ≤ 1: Σ_{q ∈ P}|S|² ≤ C y log y |P|, S = Σ_{n ≤ Z} a_n (n/q), a_n = Λ(n) min(1, y/n) κ(n), P = PPset(m0, a0, U).
1. Expand: Σ_q|S|² = Σ_{n, m ≤ Z} a_n ā_m Σ_{q ∈ P}(nm/q); nm ≤ Z² < √U < q, so q ∤ nm.
2. Write nm = s·w·□ with s = product of the primes p ∤ m0 of odd exponent (squarefree, odd since 2 | m0) and w m0-smooth. (w/q) is fixed by q mod m0 (8 | m0), and (s/q) = ±(q/s) with the sign fixed by q mod 4: |Σ_{q ∈ P}(nm/q)| = |Σ_{q ∈ P}(q/s)| (QH abs_pair_sum_eq, JCS/MSqMain.lean:38-41).
3. s = 1 (nm = square × m0-smooth): pairs of powers of one prime with a + b even or p | m0, or two even powers / m0-primes: ≤ Σ_p sP(p)² + RR² (meanSq_abs), Σ_p sP(p)² ≤ Σ_{p > √y} (log p min(1, y/p)(1 + 2y/p²))² + π(√y)(log y + 2)² ≤ 3 y log y (Chebyshev; sP(p) ≈ log y for p ≤ √y); RR ≤ Σ_{p^{2k} ≤ Z} log p min(1, y/p^{2k}) + Σ_{p ≤ z, p^k ≤ Z} log p ≤ C√y + 2z log Z ≤ C'√y (z = Y^{ε/5} ≤ y^{1/5}; primes of m0 above z exceed Z and have no powers ≤ Z).
4. s = n* (the one exceptional modulus): only possible if n* has ≤ 2 prime factors; ≤ 2B² + 2B·RR with B = max_p sP(p) ≤ log y + 2 log p ≤ 3 log Z: O(log²Z + √y log Z).
5. Other s (1 < s ≤ Z², squarefree, odd, (s, m0) = 1): |Σ_{q ∈ P}(q/s)| ≤ Y^{−B'}|P| (QH.twistK). Proof: (·/s) is primitive mod s; split P by b mod m0 s; PNTAPRelW for M = m0 s: the principal main terms cancel by CRT (Σ_{c mod s}(c/s) = 0); an exceptional term survives only if the exceptional character has s-part (·/s); by Landau–Page at most one real primitive character of conductor ≤ m0 Z² has a zero > 1 − c/log(m0 Z²): its s-part is n*; every other exceptional term and the relative error are ≤ e^{−c log U/log(m0 s)} + e^{−√(c log U)} ≤ Y^{−B'} (stage 1: log U = z, log(m0 s) ≪ K log Y; stage 2: log U ≥ (1/4)log²Y·log m0, so ≤ e^{−c log²Y/5}).
6. Off-diagonal total ≤ Y^{−B'}(Σ_n |a_n|)² ≤ Y^{−B'} y²(400K log Y + 2)² ≤ y for B' = K + 1, Y ≥ Y0(ε, K).
Sum: Σ_q|S|² ≤ (3 y log y + C'' y + O(√y log Z))|P| ≤ 5 y log y |P|. Inputs: quadratic reciprocity, Chebyshev, Landau–Page (Davenport ch. 14), Gallagher's PNT in APs with Deuring–Heilbronn (PNTAPRelW). Uniform in m0 because only (s, m0) = 1 and the PNT range log U ≥ C0 log(m0 s) log log(m0 s) are used. Numerically (PROBES (a3)): mean = diagonal within 1–7 % at Z² < d. Same scheme as moments of L(1, χ) over quadratic families with Euler products of length (log)^A (Granville–Soundararajan 2003, GAFA 13; Montgomery–Vaughan 1999 [not re-read]).
