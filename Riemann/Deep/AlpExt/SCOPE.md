- Lemma (PROBES.md P0): for a finite-order Hecke character ψ of an imaginary quadratic F, its field lies in a CM field ⟺ ψ^c = ψ ⟺ ψ = χ∘N_{F/ℚ} for a Dirichlet χ ⟺ L(s,ψ) = L(s,χ)·L(s,χχ_F). So the host step admits exactly the Hecke L-functions already covered; the first one it misses is the cubic class-group character of ℚ(√−23) (P0 (3): D = −23 is the first fundamental discriminant whose class group has exponent > 2).
- Inert-blindness (P1 B): on primes inert in F, tr ρ = 0 and tr ρ(Frob²) = 2, as for 1 ⊕ χ_F; so an inert-prime sum relative to F itself (K := F) cannot separate L(s,ρ) from ζ·L(s,χ_F).
