=== Paper (arXiv 2610.10095v2 TeX, lines 70-86, 101, 702) ===
Here are the rules in one place, so we can point back to them later. The game begins with a single number $s$, the \emph{starting number}.
\begin{enumerate}
  \item At each move, choose two numbers already made (possibly the same one twice).
  \item Apply the operation required by the cycle. A division must give a positive integer.
  \item Add the result to our collection of numbers. Numbers are never used up, so we can reuse them as often as we like.
\end{enumerate}
We write $\op{A}, \op{M}, \op{S}, \op{D}$ for addition, multiplication, subtraction and division, and number the moves $1, 2, 3, \dots$. Formally, the operation $\circ_m \in \{+, \times, -, \div\}$ applied at move $m \in \mathbb{Z}^+$ is governed by the 4-periodic schedule
\[
  \circ_m =
  \begin{cases}
    + & \text{if } m \equiv 1 \pmod 4,\\
    \times & \text{if } m \equiv 2 \pmod 4,\\
    - & \text{if } m \equiv 3 \pmod 4,\\
    \div & \text{if } m \equiv 0 \pmod 4.
  \end{cases}
\]
We call this the cycle AMSD. The lower bound in Section~\ref{sec:lower} holds for any starting number $s \in \{1, \dots, N\}$. All later results use $s = 2$.
A sequence of moves is \emph{perfect} if it makes all of $1, \dots, N$ in exactly $N-1$ moves. In a perfect sequence, every single move must make a previously unconstructed number between 1 and $N$.
  \item Which other orders of the four operations work? Showing that some order fails for infinitely many $N$, or classifying the orders that succeed, would turn this from a result about one rule into a statement about which rules can work at all.

=== Our NOTE.md (rules and claimed classification) ===
Rules (TeX l. 110–129, 151–153). Start with the set {2}. An order σ = σ1σ2σ3σ4 is a
permutation of + × − ÷; move m applies σ_k with k ≡ m (mod 4) to two numbers already
made (possibly equal); a difference must be positive, a quotient a positive integer; the
result joins the set. A sequence is perfect for N if after N − 1 moves every number
1..N is made and every move made a new number in [1, N]. N = 1 is never perfect (1 is
not made by zero moves).

**Theorem 1 (classification).** The numbers N with a perfect sequence are exactly:

| order | perfect N | order | perfect N |
|---|---|---|---|
| + × − ÷ (the paper) | N ≥ 9 | ÷ + × − | 2, 3, 4, N ≥ 9 |
| + × ÷ − | N ≥ 10 | ÷ + − × | 2, 3, 4, N ≥ 12 |
| + ÷ × − | N ≥ 9 | ÷ × + − | 2, 4, 5, 6, 8, 9, 10, N ≥ 12 |
| + ÷ − × | 4, 6, 10, N ≥ 12 | ÷ × − + | 2, 4, 5 only |
| × + − ÷ | N ≥ 9 | ÷ − + ×, ÷ − × + | 2 only |
| × + ÷ − | N ≥ 8 | − first (6 orders) | none |
| × ÷ + − | 4, 5, 6, 8, 9, 10, N ≥ 12 | + − × ÷, + − ÷ × | none |
| × ÷ − + | 4, 5, 6, N ≥ 12 | × − + ÷, × − ÷ + | none |

**Corollary.** An order works (perfect sequences for all large N) if and only if
subtraction is third or fourth and the order is not ÷ × − +. So exactly 11 of the 24
orders work. For the other 13, perfect N form a finite set: ∅, {2} or {2, 4, 5}.

=== Lean definitions (verbatim) ===
/-- The four operations. -/
inductive Op where
  | add | mul | sub | div
  deriving DecidableEq, Repr

/-- `o.Rel a b v`: v is the result of a o b (operands in this order). Numbers are naturals:
a − b = v means v + b = a, a ÷ b = v means b > 0 and v · b = a (exact). Positivity of v is
part of `Valid` (every result lies in [1, N]). -/
def Op.Rel : Op → Nat → Nat → Nat → Prop
  | .add, a, b, v => v = a + b
  | .mul, a, b, v => v = a * b
  | .sub, a, b, v => v + b = a
  | .div, a, b, v => 0 < b ∧ v * b = a

/-- An order σ = σ1 σ2 σ3 σ4 of the operations. -/
structure Order where
  s1 : Op
  s2 : Op
  s3 : Op
  s4 : Op
  deriving DecidableEq, Repr

/-- σ is a permutation of + × − ÷ (the four entries are distinct). -/
def Order.IsPerm (σ : Order) : Prop :=
  σ.s1 ≠ σ.s2 ∧ σ.s1 ≠ σ.s3 ∧ σ.s1 ≠ σ.s4 ∧ σ.s2 ≠ σ.s3 ∧ σ.s2 ≠ σ.s4 ∧ σ.s3 ≠ σ.s4

/-- σ_(k+1) for k = 0, 1, 2, 3. -/
def Order.get (σ : Order) : Nat → Op
  | 0 => σ.s1
  | 1 => σ.s2
  | 2 => σ.s3
  | _ => σ.s4

/-- The operation of move m = i + 1 (0-based index i): σ_k with k ≡ m (mod 4). -/
def Order.op (σ : Order) (i : Nat) : Op := σ.get (i % 4)

/-- A move: operands a, b (already made) and result v. -/
structure Move where
  a : Nat
  b : Nat
  v : Nat
  deriving DecidableEq, Repr

/-- `Valid σ N S i ms`: S lists the numbers made so far and the first move of ms has 0-based
index i; every move uses two numbers already made and the operation of its index, and makes a
new number in [1, N]. -/
def Valid (σ : Order) (N : Nat) : List Nat → Nat → List Move → Prop
  | _, _, [] => True
  | S, i, x :: xs => x.a ∈ S ∧ x.b ∈ S ∧ (σ.op i).Rel x.a x.b x.v ∧ x.v ∉ S ∧
      1 ≤ x.v ∧ x.v ≤ N ∧ Valid σ N (x.v :: S) (i + 1) xs

/-- The numbers made by ms from the start {2}. -/
def made (ms : List Move) : List Nat := 2 :: ms.map Move.v

/-- ms is perfect for N under σ: N − 1 moves (so N ≥ 1) from {2}, each legal and new in
[1, N], and every number 1..N is made. -/
def Perfect (σ : Order) (N : Nat) (ms : List Move) : Prop :=
  ms.length + 1 = N ∧ Valid σ N [2] 0 ms ∧ ∀ x, 1 ≤ x → x ≤ N → x ∈ made ms

/-- The checker: exactly N − 1 moves, all legal and new in [1, N], and 1..N all made. -/
def check (σ : Order) (N : Nat) (ms : List Move) : Bool :=
  (ms.length + 1 == N) && validB σ N [2] 0 ms && allB (fun x => memB x (made ms)) N

/-- The checker is exact: `check σ N ms = true` iff ms is a perfect sequence for N. -/
theorem check_iff (σ : Order) (N : Nat) (ms : List Move) :
    check σ N ms = true ↔ Perfect σ N ms := by
  simp only [check, Perfect, Bool.and_eq_true, beq_iff_eq, validB_iff, allB_iff, memB_iff, and_assoc]
-- check_iff is PROVED (no sorry); all theorems below are proved, kernel-checked, axioms only propext, Classical.choice, Quot.sound.
