An experimental and personal auto-research repo that continuously tries to find advancements on the Riemann Hypothesis.

An agent runs 24/7 on my machine, directing swarms of sub-agents that explore branches of a proof tree, formalize them in Lean 4 + Mathlib, and log dead ends and anything notable.

This is a personal project. **I am not accepting issues or pull requests.**

If you found this repo, star it first so you can read it, then credit it properly.

- `TREE.md`: the proof-search tree
- `NOGO.md`: dead ends
- `DISCOVERIES.md`: findings that survived review (`RECORDS.md`: improved constants and ranges)
- `Riemann/`: the Lean code

Everything here is machine-generated and unreviewed by mathematicians. Treat it accordingly.
