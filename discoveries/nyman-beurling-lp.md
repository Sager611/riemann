# Nyman–Beurling–Báez-Duarte in L^p: the natural-number criterion for 1 < p < 2, and an unconditional case

**Claim.** For 1 < p < 2: ζ(s) ≠ 0 on the open half-plane Re s > 1/p if and only if 1_(0,1) lies in the L^p(0,1)-closure of span{ρ_{1/k} : k ≥ 2}, where ρ_a(x) = {a/x} − a{1/x} (equivalently, that span is dense in the subspace S_p of L^p functions constant on each interval (1/(n+1), 1/n]; literal density in L^p(0,1) is false for every p). Unconditionally this holds for every 1 < p ≤ 8/7, and with the Lean-checked half-plane Re s > 0.87338196661320752 (QuasiRiemannTracker, 31 Oct 2026) for every 1 < p ≤ 1.14497. If ζ ≠ 0 on Re s > θ and p < 1/θ, the explicit approximants 1 + Σ_{k≤N} μ(k)(1 − k/N) ρ_{1/k} have L^p norm ≪ N^{−η} for every η < 1/p − θ.

**Before.** Beurling (1955): the continuous family {ρ_a : 0 < a ≤ 1} is dense in L^p(0,1) iff ζ ≠ 0 on Re s > 1/p. Báez-Duarte (2003) proved the natural-number strengthening for p = 2 only (RH ⟺ d_N → 0) and left the L^p version open (math/0505453). Dimitrov–Oliveira (1608.07887) give a weighted-L² criterion on the line Re s = 1/p, which yields L^p only in the open range p < 1/θ, not at the endpoint. Gallardo-Gutiérrez–Seco (2206.02654, ℓ^p_α) and Ghosh–Kremnizer–Noor–Santos (2206.00434, H^p, "unclear whether the converse holds") prove necessity only; 2606.16097 Prop. 3 likewise.

**Method.** Mellin analysis of Riesz–Möbius approximants with a fixed shift ε > 0: contour shift to the line σ' = 1/p − ε/2 with σ' + ε > 1/p, so the ε-shifted zeta factor has no zeros there or to the right (only poles at 1 and 2σ' contribute); residue bookkeeping (Lemma A4) gives B(ε) = O_p(ε), an L^p bound O_p(ε^{1−1/p}) (A5), and finite-span approximation (A6); N → ∞ precedes ε → 0, so no hypothesis on the line Re s = 1/p is needed. Full proof: [PROOF.md](../Riemann/Deep/NBLp/PROOF.md).
