# Unit-generated real quadratic orders with 2-torsion class group: Kopp–Lagarias Problem 1.7 solved (node N11)

**Claim.** Let O_Δ = ℤ[ε] run over the unit-generated real quadratic orders, i.e. Δ = n² − 4 (n ≥ 3) or Δ = n² + 4 (n ≥ 1) (Kopp–Lagarias Prop. 2.3). Then
- Cl(O_Δ) = Cl(O_Δ)[2] holds exactly for the 53 discriminants n² − 4 and the 37 discriminants n² + 4 of Kopp–Lagarias Tables 2A/2B: 89 distinct orders (Δ = 5 in both families; 60 maximal, 29 non-maximal), the largest Δ = 68640 = 262² − 4 (conductor 2, Cl ≅ (ℤ/2)⁴, Cl⁺ ≅ (ℤ/2)⁵);
- one class per genus, Cl⁺(O_Δ) = Cl⁺(O_Δ)[2], holds for exactly 84 of them: all except Δ = 221, 725, 1517 (Cl⁺ ≅ ℤ/4) and 3965, 7565 (Cl⁺ ≅ ℤ/2 × ℤ/4).

Inputs: for Δ < 10¹⁸ only elementary algebra and an exact computation (no GRH, no zero-free region); for larger Δ our Littlewood bound |L(1, χ)| ≥ 0.11/max(3, log log q) for every primitive χ mod q ≥ 3 ([page](littlewood-half-plane.md), from Bebel's Lean-checked half-plane); any constant ≥ 0.037 in place of 0.11 suffices.

**Before.** Kopp–Lagarias (arXiv 2512.11311 v3, Apr 2026) proved finiteness only ineffectively (Hua's Siegel-type theorem), tabulated the orders with Δ < 10¹⁰ ("conjecturally complete", TeX l. 145), posed Problem 1.7 (l. 329–336: "Determine all unit-generated real quadratic orders O_Δ having one class per genus, that is, having Cl⁺(O_Δ) = Cl⁺(O_Δ)[2]. More generally, determine all such orders having Cl(O_Δ) = Cl(O_Δ)[2].") and wrote (l. 1743) "The complete classification of unit-generated orders with 2-torsion class group seems out of reach at this time, in parallel with the idoneal number problem being unsolved." For maximal orders of extended Richaud–Degert type, Louboutin–Mollin–Williams (1993) had the exponent-2 list with one possible exception (none under GRH). The imaginary analogue (Euler's idoneal numbers) was completed in October 2026 from the same half-plane (OpenAI QRH note; Jaswal, Zenodo).

**Method.** (1) Lemma A (elementary): for Δ = n² ∓ 4 ≥ 100, a primitive α ∈ O_Δ with |N(α)| < √Δ/2 is a unit (normalise by powers of ε; size and parity then force α = yε). (2) Corollary B: if Cl(O_Δ) is 2-torsion, no prime p with p² < √Δ/2 splits in O_Δ (𝔭² would be principal and primitive of norm p²). (3) Effective bound: the class number formula for orders, R(O) ≤ log ε < ½ log(Δ + 4), φ(f)/f ≥ 1/P_{ω(Δ)} and the Littlewood bound give h(O) > 0.11 √Δ/(log(Δ + 4) · max(3, log log Δ) · P_{ω(Δ)}), while genus theory gives h ≤ 2^{ω(Δ)} for a 2-torsion class group; splitting by k = ω(Δ) (Δ ≥ p₁⋯p_k) gives Δ < D₀ = 20,485,358,601,780,401 ≈ 2.05·10¹⁶ (k = 14 is the worst; k ≥ 15 is excluded by an induction that uses only Euclid's p_{k+1} ≤ p₁⋯p_k + 1). (4) Sieve every n with Δ < 10¹⁸ (n ≤ 10⁹) by Corollary B: 82 survivors with n > 1000, all n ≤ 5968. (5) Exact class groups (reduced indefinite forms, cycles, composition; integer arithmetic) of all 2080 orders with n ≤ 1000 or surviving.
