# A hard-core inequality crosses the floor of Lamzouri's small-gap criterion: D(λ) > 0 for every λ ≥ 0.768

**Claim.** (Computer-assisted.) Let D(λ) be the lower density of consecutive normalised gaps (γ_{n+1} − γ_n)·log T/2π that are ≤ λ. Theorem 1: let 1/2 < θ < 4/7, 0 < λ ≤ 1, λ < U ≤ 3λ, f even, f ≥ 0, Schwartz, f^ ≤ 0 on [U, ∞), A: [λ, ∞) → ℝ bounded, β ≥ 0, c ∈ ℝ with (H) f^(x) + f^(x + y) + A(x) − A(y) + β(1 − x) ≤ c for all x, y ≥ λ. If J_θ(f) = f(0) + 2∫_0^θ f(α)α dα > f^(0) + 2c, then D(λ) > 0. (A = β = c = 0, U = λ is Lamzouri's Thm Main2.) Corollary: D(λ) > 0 for every λ ≥ 0.768, unconditionally.

**Before.** λ ≥ 0.7851 (ours, smallgap, 11 Nov 2026, Thm Main2 with an SDP-optimised test function), λ ≥ 0.7892 (Lamzouri, arXiv 2611.14486, Thm Main); Thm Main2 alone can never go below 0.775 (ours, [small-gap-floor](small-gap-floor.md)); under RH λ > 1/2 (Durkan–Pearce-Crump 2610.28527).

**Method.** (explore40; [DERIVATION.md](../Riemann/Deep/ExplorePointProc/DERIVATION.md) §4.) Lamzouri's argument removes the zeros with a neighbour within λ (and the off-line and multiple ones; density δ → 0 if D(λ) = 0) and lower-bounds the pair sum of the rest, Z_0, by (J_θ(f) + o(1))N; Thm Main2 then bounds its off-diagonal part by 0. Z_0 is a hard-core set of density 1 (gaps g_i > λ, mean gap 1), so pairs at index distance ≥ 3 are ≥ 3λ ≥ U apart (f^ ≤ 0: dropped) and the nearest and next-nearest pairs are bounded by summing (H) at (g_i, g_{i+1}): A telescopes and the β-term is the mean-gap constraint, giving Σ ≤ (f^(0) + 2c + o(1))N. (H) is the dual of the 1D ground-state problem sup E[f^(g_1) + f^(g_1 + g_2)] over stationary gap processes with g ≥ λ, E g = 1, the realizability condition that the pair-only LP duals violate (μ(2λ) ≥ 2μ(λ) − 1 fails by 0.15 on the floor's duals). A truncation lemma makes the Schwartz f admissible: F = f h_R + c_r G is C_c², even, ≥ 0, and Lamzouri's own proof of Thm Main2 (TeX l.418–440: Prop SmallSetZeros for ψ_ε f, then positivity) covers compactly supported F.
