# Counterexamples to seven published conjectures of Z.-W. Sun

[Back to DISCOVERIES](../DISCOVERIES.md)

Elementary and small; each certified by exhaustive search. "1309.1679" is Sun's "Some new problems in additive combinatorics" (Nanjing Univ. J. Math. Biquarterly 36 (2019); arXiv 1309.1679), with printed conjecture numbers.

| Conjecture | Counterexample |
|---|---|
| 1309.1679, Conj. 3.2 | Z/6Z, (a₁, …, a₄) = (0, 1, 3, 5): after the prescribed first element, a coset of order 3 forces two equal differences |
| 1309.1679, Conj. 3.4(i) | every 5-subset of Z/7Z: no circular order makes all a_i + 2a_{i+1} distinct |
| 1309.1679, Conj. 3.10(ii) | {2, 3, 4, 6}, since 2·6 = 3·4 |
| arXiv 1811.10503, Conj. 4.9 (also MathOverflow 316142) | n = 2 and every 3-term progression, e.g. A = {0, 1, 2} over Q or any F_p with p ≥ 5: \|S(A)\| = 4 < 5 |
| MathOverflow 316143 (the bound) | λ = (1, 1, 2), A = {0, 1, 2, 3}: the sums are {3, 4, 5, 7, 8, 9}, so 6 < 7 over Q |
| OEIS A228766 (general form, in a comment) | Z/6Z, {0, 1, 3, 4} |
| OEIS A228728 (comment) | {0, 1, 2, 3, 4, 5, 8} |

**Excluded as not new.**
- Conjecture 3.8 of 1309.1679 fails exactly at (q, a₀) = (11, 2). Found here independently, but first posted by an anonymous Zenodo preprint (10.5281/zenodo.23307915, 2026-10-12).
- 3.3(ii) is corrected in the printed version.
- A229827(ii) fails on {0, 1, 2}, as Sun's own Remark 1.3 notes.

**Review.** Every certificate correct; each counterexample minor; one entry for all seven.

**Novelty.** Nothing found reporting them (OEIS, MathOverflow answers, arXiv, Zenodo, Sun's homepage); novelty is provisional ([novelty](../Riemann/Deep/SunPrim/NOVELTY.md)).
