# A prime in (x, x + x^{0.856}] for every real x ≥ 1 (node N10)

**Claim.** Theorem A: for every real x ≥ 1 the interval (x, x + x^{0.856}] contains a prime. Inputs: ζ(s) ≠ 0 for Re s > B = 0.8733819666132076 (Bebel, Lean-kernel-checked); RH up to height 3·10^{12} (Platt–Trudgian); Kadiri–Lumley–Ng's explicit zero density (JMAA 2018, Lemma 4.14) evaluated with their RH height replaced by 3·10^{12}, as Cully-Hugill–Johnston (IJNT 2023) did; the explicit zero count of Hasanalizade–Shen–Wong; prime gaps ≤ 1476 below 4·10^{18} (Oliveira e Silva–Herzog–Pardi); a sieve to 10^7. No RH above 3·10^{12} and no unrefereed zero count. 0.856 is the least multiple of 0.001 this pipeline certifies (at 0.855 the bound reaches 1.152 near log x = 190.6). It implies our earlier k = 7 result, since (n+1)^7 − n^7 > 7n^6 > (n^7)^{0.856}.
Theorem B (conditional): if the zero density of Chourasiya–Simonič (arXiv 2507.15184 v2, Cor. 1.1; unrefereed; audited line by line on 12 Nov 2026, AUDIT PASSED with the corrected b₄, [CSAudit](../Riemann/Deep/CSAudit/REPORT.md)) holds with its B₁ raised for the constant that Ramaré–Zuniga Alterman (arXiv 2603.25961, Thm 1.2) actually prove, then (x, x + x^{0.842}] contains a prime for every x ≥ 1, (n^6, (n+1)^6) contains a prime for every n ≥ 1, and (n^k, (n+1)^k) does for n ≥ e^{45.584} (k = 5), e^{91.18} (k = 4), e^{468.43} (k = 3).

**Before.** For every x: x^{7/8} (ours, routine, R323, [ShortPrimes](../Riemann/Deep/ShortPrimes/REPORT.md); Visser 2610.20058 states the same interval). Log-power intervals x/(111 log² x) (Trudgian) and x/(5000 log² x) (Dusart). Not explicit: x^{0.525} for large x (Baker–Harman–Pintz). Consecutive powers: [our k = 7 result and the cube thresholds](primes-between-powers.md).

**Method.** Ingham3's pipeline (weighted explicit formula, ρ ↔ 1 − ρ̄ pairing, KLN in 144 σ-cells on [0.515, B]) with δ = log(1 + x^{θ−1}), so that the weight sits exactly on [x, x + x^θ], and two changes: a trapezoid weight (the convolution of the indicators of [0, 1/10] and [0, 9/10]) instead of the triangle, and KLN evaluated with RH(3·10^{12}) instead of RH(3.06·10^{10}) (one of their parameter rows becomes inadmissible and is dropped; our σ = 0.98 value matches Cully-Hugill–Johnston's within 0.06%). Cell scheme: 1 ≤ x < 2 (2 is in the interval); 2 ≤ x < 9999991 by the 22 maximal-gap records below 10^7 (worst ratio log g/log p = 0.712 at p = 7); up to e^{42} by the gap bound 1476 (Bertrand keeps the gap below 4·10^{18}); 4932 cells on log x ∈ [42, 300] (maximum 0.9711 at log x = 191.82); a tail lemma for log x ≥ 300, proved non-increasing (bound 0.0142). Theorem B adds the Chourasiya–Simonič bound in every σ-cell (concave exponents, tangent lines).

**Certificate.** `uv run --no-project --with python-flint --with mpmath --with sympy python3 Riemann/Deep/Ingham4/cert.py` (Arb, 128 bits, four parts in separate processes, about 11 min, peak 164 MB). Rerun by the orchestrator on a copy in /tmp: cert_result.json identical (only the memory figures differ); the final version (after the two rounding fixes below) rerun as well.

**Checks.** Independent float quadrature (exact KLN and CS shapes, true kernel envelope, no moment tables): certificate/direct = 1.012–1.207 at 19 points. Code audit (CODE-AUDIT.md, code_audit.py, logs/code_audit.log): 36 moment-table entries recomputed at 256 bits from the definition lie below the stored values (ratio 1.0015–1.0021); kernel values, the p-grid and the KLN rows checked at 256 bits; 14 cell bounds recomputed without tables are at most the certified bounds (ratio 1.017–1.037). Two rounding weaknesses inherited from Ingham3's code (a table index from a rounded float; maxima chosen by float comparison) were made exact; no result changed. Round R410 authenticated the inputs in the TeX: KLN's Lemma 4.14 holds for every δ > 0 with RH(H₀) a stated hypothesis (only their Theorem 1.1 is printed with δ ≥ 1; with δ = 1 throughout the exponent is 0.861), Cully-Hugill–Johnston's H₀ = 3·10^{12} substitution, Hasanalizade–Shen–Wong's constants.
