# At least 0.6724 of the zeta zeros are isolated, for every c ≤ 0.00476 (node N8)

**Claim.** For every c ≤ 0.00476, liminf_{T→∞} B_0(T,c)/N(T) ≥ 0.6724, unconditionally. B_0(T,c) counts the zeros ρ = β + iγ, 0 < γ ≤ T, whose two neighbouring ordinates are more than 2πc/log T away (Lamzouri's c-isolated zeros, arXiv 2610.26841 Thm 1.1); such zeros are simple and on the critical line; zeros are counted with multiplicity. At c = 0.001 the certified bound is 0.672487. Further certified values: ≥ 0.672 for c ≤ 0.01106, ≥ 0.67 for c ≤ 0.02485, ≥ 0.66 for c ≤ 0.05495, Lamzouri's 0.6552 for every c ≤ 0.06427, and ≥ 0.5247 at c = 1/6 (paper: 0.50875).

**Before.** Lamzouri (arXiv 2610.26841v2, 26 Oct 2026): ≥ 0.6552 for some c > 0 that is never given; explicit only 0.50875 at c = 1/6. Lee (Zenodo 23719902 and 23807772 v1.1, 28 and 30 Oct 2026, unrefereed): explicit 0.655208 at c = 0.00577; Lee's Zenodo 23922845 (3 Nov) is conditional on its own local-block hypotheses (0.5329 at c = 1/6). Angón–Ross–Tang–Zhao (arXiv 2610.22927): ≥ 0.3450 for every c ≤ 1/4.

**Method.** Lamzouri's Hilbert-space inequality with every error term made explicit (cluster loss λ ≈ 12.2c² per clustered zero, witness error π²c²/2), plus a new hinge bound for off-line zeros. Littlewood's lemma for ζψ⁺ at σ⁺ = ½ + 2πρ/log T, with Conrey's mollified mean value (Crelle 399, 1989, Thm 2, θ < 4/7) moved to the right of the line by the functional equation and the optimal mollifier P = sinh(bx)/sinh b, gives Σ_{β>1/2} ((β − ½) log T/2π − ρ)^+ ≤ (B(ρ) + o(1)) N(T) with B(ρ) = (1/4π) log(1 + (1 − e^{−4πρ})/(e^{16πρ/7} − 1)), so B(1.2) = 1.44·10⁻⁵. Off-line zeros within normalised distance ρ_max ≈ 1.22 of the line cost nothing (the deficiency H_τ − 3λ is negative there), and higher ones are exponentially rare: the off-line loss falls from Lamzouri's 0.0806·α_0 = 0.0173 to α_ρ B(ρ) ≤ 9.5·10⁻⁶. By-product: Lamzouri's unproved input (Conrey's announced Σ(β − ½) ≤ 0.0806 T) follows from Conrey's published Theorem 2 as the case ρ → 0, with (1/4π) log(11/4) = 0.0805006.

**Novelty.** arXiv listings math.NT and math.CA, Oct–Nov 2026 (lst.py 'isolated|gaps between|moderate gaps|simple zeros|critical line'): only 2610.26841 and 2610.22927 give isolated-zero proportions. Zenodo '"isolated zeros"': Lee's four records, all at most 0.655208 or conditional. HAL: no hit for "isolated zeros" with zeta. GXL evidence API (agent): no passage on the constant. Our files: no earlier isolated-zero result (ZetaZeros, N8Opt and N8Fam treat simple and on-line proportions). The integrated density bound behind B(ρ) is classical in kind (Conrey's N(σ,T) ≪ T^{1−8(σ−½)/7} log T); its explicit form and its use against the isolation deficiency are new as far as these searches reach.

**Caveat.** liminf only; the o(1) terms are not explicit. Same footing as Lamzouri's paper: his 2609.02882 Lemma 3.2 (2026 preprint; refereed sound by lamz2audit, 11 Nov 2026, [LamzAudit2](../Riemann/Deep/LamzAudit2/REPORT.md); Axiom's Lean ZetaZerosV2 claims a formal proof) on top of Baluyot–Goldston–Suriajaya–Turnage-Butterbaugh (Acta Arith. 2024).
