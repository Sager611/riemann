# Explicit Kim–Lee wedge: Riemann's Jensen polynomials are hyperbolic for n ≥ 9.99·10^11 and d ≤ 6.45 n²/log² n (node N6)

**Claim.** Let J^{d,n}(X) = Σ_j binom(d, j) γ(n + j) X^j, where 8ξ(1/2 + z) = Σ_m γ(m) z^{2m}/m! (the family of our N6 records; Θ(w) = 8ξ(1/2 + √w)). Let u(n) solve u(πe^{2u} − 9/4) = n, n_* = ⌈Z(12)⌉ = 998,616,377,771, R_n = (9/10)(n − 1/2)²/(u(n) + 1)², and a = 0.37338196661320752 (Lean-checked: every zero has |Re ρ − 1/2| ≤ a).
1. For every n ≥ n_*, Θ^{(n)} has no zero w with (Im w)² ≤ 4a²(a² − Re w) and Re w ≥ −R_n.
2. Hence J^{d,n} is hyperbolic for every d ≤ D_n = R_n²/(4a²(R_n + a²)), in particular for every d ≤ 6.45 n²/log² n.
3. Kim–Lee shape with numbers: J^{d,n} is hyperbolic for every d ≥ 1 and every n ≥ max(n_*, C d^c), with (c, C) = (0.51, 7.6890), (0.55, 0.87160), (0.6, 0.069829), (1, 1.1853·10⁻¹⁰).
With the classical strip only (a = 1/2): d ≤ 3.59 n²/log² n.

**Before.** Explicit: J^{d,n} hyperbolic whenever n² log(n + 2) ≥ 24 d³ (ours, the two-thirds wedge, [page](jensen-two-thirds-wedge.md)), plus d ≤ 1.6141·10^25 for all n. Best shape: Kim–Lee (arXiv 2105.05386, Thm 1): n ≫ d^{1/2+ε} suffices, but ineffective through Y.-O. Kim's 1996 theorems on zeros of derivatives (R413: no effective version known). Just beyond the all-n range, at d = D_all + 1 with D_all = 16,140,857,488,599,731,839,205,676, the two-thirds wedge needs n ≥ 3.42·10^37 and the new region n ≥ 4.70·10^13 (D_n > D_all for every n ≥ 4.6974173·10^13). Given the all-n range, the new region contains the two-thirds region for every d; without it, for every d > 1.0471·10^8. At n = 10^30 it covers d ≤ 1.46·10^57 (two-thirds wedge: 1.42·10^20).

**Method.** Kim–Lee's chain is: zero location of the derivatives (Kim 1996, ineffective), then Obreschkoff's sector theorem (Kim–Lee Thm 3), then hyperbolicity. The agent keeps the Obreschkoff step and replaces Kim's theorem, for ξ only, by an explicit zero-free region. (1) Gauss–Lucas for genus 0: the zeros of every Θ^{(n)} lie in the convex parabola P = {(Im w)² ≤ 4a²(a² − Re w)} that holds the zeros of Θ; so if Θ^{(n)} has no zero in P with Re w ≥ −R, every zero lies in the sector |Im w|/|w| ≤ 2a√(R + a²)/R, and Obreschkoff gives hyperbolicity for d ≤ R²/(4a²(R + a²)). (2) A mixture identity from Riemann's integral: Θ^{(n)}(w) = γ(n) E_n[₀F₁(; n + 1/2; t²w/4)], an average of dilates of one Bessel function (zeros beyond (n − 1/2)²/(4t²)·4) over the probability density p_n ∝ t^{2n}φ(t), which peaks at t = u(n) with relative width about n^{−1/2}. (3) Explicit Laplace bounds: concavity of the tilted log-density, a peak bracket [u − 17/25, u + 1/n] uniform in w, a window of half-width 2η (η ≤ 6.86·10⁻⁶) on which the phase of ₀F₁ turns by at most 1.26·10⁻⁴ rad, tangent-line bounds for the side tails, and a crude bound beyond t = 1.0435(u + 1) where p_n is doubly exponentially small; so the average of nearly equal-phase nonzero values cannot vanish. (4) Every inequality is reduced to monotone majorants in u = u(n) and certified at u = 12. Derivation: [DERIVATION.md](../Riemann/Deep/KimEff/DERIVATION.md).
