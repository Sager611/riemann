# Every modulus covered by O(log Q) small primes, with numbers (node N11)

**Claim.** From the Lean-checked zero-free half-plane (ζ(s) and every Dirichlet L(s, χ) are nonzero for Re s > B = 0.8733819666132076, which follows from Bebel's Lean-kernel-checked Re s > B₂ + 2.2·10⁻²⁵⁴, B₂ = (777 − √1081)/852): for every Q ≥ 3 there is a set P of at most **2.1067 log Q + 58** primes, all in (e⁻⁷y, y] with y = (820·max(log Q, log 9))^{7.8978}, such that for every 2 ≤ q ≤ Q the subset products of the primes of P not dividing q are all of (ℤ/qℤ)^×. This is (1/log 2 + 0.664) log Q + 58; with 820000 in place of 820 it is 1.9492 log Q + 98. Least certified counts per Q: 10³: 27; 10⁶: 44; 10¹²: 77 (primes ≤ 10^33.33); 10³⁰: 164; 10¹⁰⁰: 498 (≤ 10^39.91); 10¹⁰⁰⁰: 4858. Any covering set needs at least log₂ φ(q) primes. Exactly: the first 17 primes 2, …, 59 cover every q ≤ 2000. P is shown to exist only (a random draw from the method's law works with probability ≥ 0.45).

**Before.** Klurman–Shparlinski–Teräväinen (arXiv 2609.25393, Thm 1.1): (log Q)^{1+ε} primes ≤ (log Q)^{C(A+1)} covering all but O(Q(log Q)^{−A}) moduli, C not computed, the exceptional set "unavoidable with present technology"; under GRH a sketch covers every q with polylogarithmically many primes. Hughes (arXiv 2610.04678): (1/log 2 + o(1)) log Q primes for all but O_A(Q(log Q)^{−A}) moduli, and 2 log Q/log 2 + O(log Q/log log Q) for every q outside an analytic exceptional set, without effectivity. No statement for every modulus with O(log Q) primes and numbers, and no all-moduli constant below 2/log 2 = 2.885, existed.

**Method.** Draw primes from ν(p) ∝ log p·w(p/y) (the kernel of [linnik-numeric](linnik-numeric.md)). Lemma D: the half-plane gives Re E[ψ(g_j) | past] ≤ δ = 10⁻³ for every nonprincipal ψ modulo every q ≤ Q and every step (explicit formula with all zeros in Re s ≤ B; 664 Arb cells plus a monotone tail), which empties Hughes's exceptional set. Lemma C: the fourth moment of Hughes's collision count over exactly enumerated closed relation classes (2340 sets in 57 classes) cuts the collision stage to (1 + 1/k) log₂ Q; the hole stage is Hughes's contraction; a union over q ≤ Q with explicit torsion and divisor sums; certified supremum over all Q ≥ 3 of the failure sum ≤ 0.5464 < 1.
