# Numeric Linnik bound and explicit power-saving prime number theorem in progressions, for every modulus (nodes N10, N11)

**Claim.** Assume H: ζ(s) and every Dirichlet L(s, χ) have no zeros with Re s > B = 0.8733819666132076. H is a Lean-kernel-checked theorem (J. Bebel's QuasiRiemannTracker submission of 1 Nov 2026: Re s > B₂ + 2.2·10⁻²⁵⁴, B₂ = (777 − √1081)/852 < B; unrefereed). Then, with 1/(1 − B) = 7.8978 and no other unproved input, for every q ≥ 1 and (a, q) = 1:
1. |ψ(x; q, a) − x/φ(q)| ≤ 1.5 x^B log²(qx) for all x ≥ 2 (constant 0.174 for x ≥ 64, 0.0324 for x ≥ e¹⁰; limit 0.0076).
2. The least prime p ≡ a (mod q) is ≤ (q log q)^{7.8978} for every q ≥ 2, ≤ (0.72 q log q)^{7.8978} for q ≥ 10⁴ (limit constant 0.45331), and ≤ (φ(q) log q)^{7.8978} for q ≥ 3.
3. Every nonprincipal character χ mod q ≥ 3 has χ(n) ∉ {0, 1} for some prime n ≤ (log q)^{7.8978}.
4. (routine, COROLLARIES) |L'/L(1, χ)| ≤ 7.8978 log log q + 10.53 for every primitive χ mod q ≥ 3.

**Before.** Numeric bounds valid for every q were exponential: Bennett–Martin–O'Bryant–Rechnitzer (Illinois J. Math. 2018, arXiv 1802.00085) give |θ(x; q, a) − x/φ(q)| < x/(160 log x) only for x ≥ exp(8√q log³ q). Polynomial Linnik bounds carry unspecified constants (Xylouris L = 5; Pollack, Hexagon 2610.00545, "effectively computable"; Naslund, Hexagon 2610.00018, q^{3.99} for q ≥ q₀ "we do not compute q₀"; ours L ≤ 7/3 with ≪_ε, COROLLARIES). Power-saving PNT in progressions from the 2026 half-planes existed only with unspecified constants (Zenodo 23608576; OpenAI, 5 Oct); Platt–Trudgian (2610.29018) said an explicit version "could be improved almost instantly". Polylogarithmic non-residue bounds: GRH (Bach) or unspecified C (OpenAI, 30 Sep: C(log p)³²).

**Method.** Explicit formula for weights supported in a compact subset of (0, ∞) (no pole at s = 0, no left-line bound for L'/L); the zeros of each L(s, χ) are symmetric under ρ ↦ 1 − ρ̄, so every zero with β > ½ (weight x^B under H) pairs with one with β < ½ (weight x^{1/2}); kernel majorants for β ∈ [½, B]; zero sums by partial summation against the refereed explicit zero count of Bennett–Martin–O'Bryant–Rechnitzer (Math. Comp. 2021), with all zeros below height 5/7 put at height 0; triangle kernels in log n for the least prime and the non-residue; for the PNT a sandwich with trapezoid weights, orthogonality over the φ(q) characters, 7307 certified cells in (log q, log x) for 64 ≤ x ≤ e⁶⁰ and an explicit tail beyond; small q (q < 100) by an exact integer sieve.

Exact checks: worst log p/log((q log q)^{7.8978}) = 0.426 (q = 2); max |E|/(x^B log² qx) = 1.4848 at q = 1, x = 2.

Verdict: SIGNIFICANT (first numeric all-modulus polynomial bounds). The main input was authenticated in the TeX by an R395 scout: BMOR's Theorem 1.1 (2005.02989, l. 163–176: conductor q > 1, T ≥ 5/7, ℓ > 1.567, constants 0.22737, 2, −0.5; N(T, χ) counts 0 < β < 1, |γ| ≤ T). The agent's own self-review fixed one rigor slip (a max() used as a lower bound for φ(q)).

**Novelty.** arXiv listings math.NT Oct–Nov 2026 (lst.py 'progression|Linnik|least prime|non-?residue'; agent: also 'explicit|quasi-Riemann|zero-free|half-plane|Siegel|Dirichlet L|primes in'); the 6 Nov listing; Hexagon full-text search and the TeX of Hexagon 2610.00178 (a survey of half-plane consequences: no numeric Linnik, progression or non-residue bound); Zenodo ('"arithmetic progressions"', '"Linnik"', 7 more agent queries); HAL ('Linnik', 'least prime in an arithmetic progression': nothing in number theory); GXL evidence API; Tao's optimisation-constants page and expdb; our COROLLARIES (Linnik ≤ 7/3 with ≪_ε) and ArtinHalfPlane. Nothing gives a numeric polynomial Linnik bound for all q or an explicit power-saving PNT in progressions uniform in q.

**Caveat.** Conditional only on H, which is Lean-kernel-checked but unrefereed (with OpenAI's 7/8 the same code gives exponent 8, not run). Unrefereed. The constants are far from optimal (72% of the leading coefficient comes from the ≈ 0.455 log q zeros below height 5/7 placed at height 0). The exponent 7.90 is worse than the non-numeric records (L = 5; ours 7/3 + ε); the gain is that every constant is a number. Theorem 1 says nothing new for small x.

**RH relevance:** N10 (explicit prime-error bounds: the first explicit power-saving PNT in progressions uniform in q) and N11 (GRH families: the half-plane for every Dirichlet L-function turned into numeric Linnik and non-residue bounds).
